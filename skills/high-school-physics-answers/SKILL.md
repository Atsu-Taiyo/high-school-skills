# 高校物理の答案を書く

## 目的

高校物理の答案らしい文章を書く。採点する先生が読んで，そのまま答案として減点されないものにする。答の式が合うだけでは足りず，**どの物体に，どの向きを正として，どの法則を使ったか**を文で書く。

**求められない限り，方針・解説・別解・参考は書かず，解答と答だけを書く。**

## 範囲

物理基礎・物理（平成30年告示）の教科書にある方法だけで解く。問題の科目より先の道具を使わない（物理基礎の問題を運動量保存・円運動・状態方程式で解かない）。微分・積分は使わず，変化の割合は $\dfrac{\Delta x}{\Delta t}$，仕事や変位はグラフの面積で書く。ローレンツ力は大きさ $\lvert q\rvert vB$ とフレミングの左手の法則（負電荷は逆向き）で書き，右ねじの法則は電流がつくる磁場の向きだけに使う。範囲外の方法の書き換えは `references/scope.md`。問題文が与えた仮定・近似はそのまま使う。

## 記号・単位・数値

- 問題文の記号・用語をそのまま使い，公式の文字も合わせる。自分でおく文字は最小限にし，「…を $N$ とする」と定義する。書く前に問題文の名前と量記号の衝突を調べる（物体 $\mathrm{F}$ と力 $F$，周期と温度の $T$）。
- 空欄の記号を数式に入れない（`\text{ア}=…` としない）。「アは $mg\sin\theta$」と文で書く。
- 量記号は斜体，単位・物体の名前は立体（$v_{\mathrm{A}}=3.0\ \mathrm{m/s}$）。文字式に単位を付けず，数値の式は両辺で単位の有無をそろえる。
- 有効数字は与えられた数値に合わせ，丸めは最後に1回。丸めた結果は `\fallingdotseq`。
- 近似は条件と近似式を先に書き（「$\lvert x\rvert\ll1$ のとき」），何を何とみなしたかを書く。
- 用語は教科書のもの（熱力学第一法則，力学的エネルギー保存の法則，コンデンサー，電場）。詳細は `references/notation-units.md`。

## 式を立てる前に書くこと

1. **対象**：どの物体（物体の組）についての式か。
2. **正の向き**：同じ座標系の間は変えない。逆向きの量は大きさでおく。取り直すときは明示する。
3. **法則名と使える理由**：「水平方向に外力がはたらかないから，運動量保存の法則により」。結論に効く条件だけを書く。電気量保存はどの極板の和かを書く。
4. **観測者**：地面から見るか，加速する観測者から見る（慣性力を含める）かを1つに決める。

接触・張力の条件は $N\geqq0$ などの式で示す。回転する剛体は「力のモーメントの和が 0」と書く。

## 答案の形と出力形式

**解答** の後に本文を書き，独立した行の「**答**　…」で閉じる。**答** の後に確認や補足を続けず，検算は本文に載せない。文体は「である」体，句読点は「，」「。」。本文に箇条書きを使わない。

- Markdown＋LaTeX（文中 `$...$`，別行 `$$...$$`，複数行は `aligned`）。分数は `\dfrac`，不等号は `\leqq`。`align`・`\tag` は使わない。説明文を数式に入れない。
- 式番号は後で参照する式だけ：`　$mv_{0}=(m+M)V$　……①`（丸数字は数式の外）。番号つきの式がある導出では，1行の式をすべてこの字下げの形にそろえる。問題文に丸数字の選択肢があれば (a)(b)… にし，1題の中で変えない。
- 「そのまま貼れる形で」と求められたら本文だけを出し，全体をコードブロックで囲まない。
- 呼び出し側が形式を指定したらそれに従う。詳しい LaTeX の書き方は，必要なら high-school-math-answers の `references/notation.md`。

## 問いの形ごとの答え方

- **答**：与えられた文字だけで表す。数値には単位と有効数字，向きを問われたら向きも。選択肢は「②（左向き）」と番号と内容。
- **向き・符号**：使った法則と法則に入れた向きを書き，正の向き・選択肢と照らす。大きさは符号を決めた式を示してから正の量で答える。
- **数値**：文字式で答を出してから代入の式を1行書く。
- **論述**：結論を先に，理由を法則名を入れて1〜2文。**答** の1か所に書く。
- **空欄補充**：冒頭に答の一覧表を置き，各まとまりの **答** と一致させる。

詳細は `references/answer-style.md`，見本は `references/examples.md`。

## 図

図は svg-figures で作る。問題に図があれば解答の図は「解図1 …」とし，問題の図は「問題の図1」と書く。問題の図に記入して答える図も解図とし，「（問題の図5に記入したもの）」と添える。`![解図1](fig1.svg)`（代替テキストは図の名前だけ）の直下に図題と記号の説明（⊗，⊙）を1〜2文で書く。図中の点は本文で定義してから使い，図は参照する文の直後に置く。式に現れる力（慣性力を含む）と向きの根拠（磁場，電荷の符号，正の向き）は図に描き，省いた素子はキャプションに挙げる。

## 検査を回す

シェルで Python 3 が使えるときは，答案に同梱の検査をかける。`S` はこの SKILL.md のフォルダ（Claude Code では `${CLAUDE_SKILL_DIR}`，Codex の `.agents/skills/…` などでは読み込んだ SKILL.md の場所）。

```sh
python3 "$S/scripts/hs_check.py" run --subject physics --final answer.md --problem problem.md
python3 "$S/scripts/hs_check.py" verify --final answer.md
```

ファイルを作らないときは `--final -`（標準入力）。

1. `run` の出力の1行目に従う。候補を1つずつ答案と規則に照らし，当たっているものだけを1回でまとめて直す。WARN は文脈で決める。検査を消すためだけの言い換えはしない。
2. 直したら `run` をもう一度実行し，その後は本文を変えない。
3. 提出の直前に，本文を変えずに `verify` を1回実行する。合わなければ `run` と `verify` をやり直す。

検査が見るのは機械的に判定できる書式・記号・語だけで，正しさの合格ではない（下の点検は省かない）。答案と同じフォルダの図には svg-figures の lint もかかる。シェルが使えない環境（アプリ内の AI など）では下の点検で目視し，検査は実行していないと報告する。

検査の結果は答案に書かない。返答では本文の後に `---` で区切って「検査：ERROR 0 件・WARN 1 件（残した理由）」の1行だけを添える（本文だけを求められたら聞かれたときに伝える）。`verify` に渡すのは区切りより前の本文。

## 出力前の点検

1. 式の前に対象・正の向き・法則名と使える理由がある。
2. 正の向きと答の符号が合う。
3. 次元が両辺で合い，数値に単位と有効数字がある。近似の条件を書いた。
4. 範囲外の方法がない。答が与えられた文字だけで，**答** で閉じている。
5. 頼まれていない方針・解説・別解・参考がない。
