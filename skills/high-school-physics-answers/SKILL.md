# 高校物理の答案を書く

## 目的

高校物理の答案らしい文章を書く。採点する先生が読んで，そのまま答案として減点されないものにする。答の式が合うだけでは足りず，**どの物体に，どの向きを正として，どの法則を使ったか**を文で書く。

**求められない限り，方針・解説・別解・参考は書かず，解答と答だけを書く。**

**記号と書式の細かい規則は検査が教える。書いたら必ず run する**（「検査を回す」）。この本文には，検査では判定できないことだけを書く。

## 範囲

物理基礎・物理（平成30年告示）の教科書にある方法だけで解く。問題の科目より先の道具を使わない（物理基礎の問題を運動量保存・円運動・状態方程式で解かない）。微分・積分は使わず，変化の割合はグラフの傾き，仕事や変位はグラフの面積で書く。ローレンツ力は大きさとフレミングの左手の法則（負電荷は逆向き）で書き，右ねじの法則は電流がつくる磁場の向きだけに使う。問題文が与えた仮定・近似はそのまま使う。

**範囲外の解き方は，書く前に避ける。** 次の方法は答案に使わず，括弧内の高校の書き方にする。

- 微分方程式，導関数で書いた運動方程式・誘導起電力（$ma=F$ と $\Delta$，グラフの傾き・面積，単振動・電気振動の公式）
- 外積で書くローレンツ力・力のモーメント（大きさとフレミングの左手の法則，力の大きさ × うでの長さ）
- 慣性モーメント・回転の運動方程式・角運動量保存（力のモーメントのつり合い，面積速度一定の法則）
- ガウスの法則・アンペールの法則の積分形，電位の積分（電気力線の本数，教科書の公式，$V=Ed$）
- 複素インピーダンス・複素数のフェーザ，過渡現象の指数関数（素子ごとの電圧と電流の関係と位相，直後と十分時間後の2つの状態）
- テイラー展開（$\lvert x\rvert\ll1$ のときの教科書の近似式）
- 換算質量・重心系，コリオリの力（運動量保存の法則と反発係数の式，静止した観測者から見る）

書き換えの詳細は `references/scope.md`。

## 記号・単位・数値

- 問題文の記号・用語をそのまま使い，公式の文字も合わせる。自分でおく文字は最小限にし，「…を $N$ とする」と定義する。書く前に問題文の名前と量記号の衝突を調べる（物体 $\mathrm{F}$ と力 $F$，周期と温度の $T$）。
- 空欄の答は文で書く（「アは $mg\sin\theta$」）。
- 文字式に単位を付けず，数値の式は両辺で単位の有無をそろえる。
- 有効数字は与えられた数値に合わせ，丸めは最後に1回。
- 近似は条件と近似式を先に書き（「$\lvert x\rvert\ll1$ のとき」），何を何とみなしたかを書く。
- 詳細は `references/notation-units.md`。

## 式を立てる前に書くこと

1. **対象**：どの物体（物体の組）についての式か。
2. **正の向き**：同じ座標系の間は変えない。逆向きの量は大きさでおく。取り直すときは明示する。
3. **法則名と使える理由**：「水平方向に外力がはたらかないから，運動量保存の法則により」。結論に効く条件だけを書く。電気量保存はどの極板の和かを書く。
4. **観測者**：地面から見るか，加速する観測者から見る（慣性力を含める）かを1つに決める。

接触・張力の条件は $N\geqq0$ などの式で示す。回転する剛体は「力のモーメントの和が 0」と書く。

## 答案の形と出力形式

文体は「である」体。答は1か所にまとめ，答の後に確認や補足を続けず，検算は本文に載せない。

- 指定がなければ Markdown＋LaTeX（KaTeX と MathJax の両方で描画できる命令だけ）。呼び出し側が形式を指定したらそれに従う（検査は `--format other`）。
- 式番号は後で参照する式だけに付け，問題文の番号と衝突しない系列を1題の中で変えずに使う。
- **答案の前後に，作業報告（「answer.md に保存しました」「スキルを使って」など）・検査の経過・解き方の説明を書かない。** 返答は答案から始め，検査の結果は「検査を回す」に書いた末尾の1行だけにする。
- 「そのまま貼れる形で」と求められたら本文だけを出す。

## 問いの形ごとの答え方

- **答**：与えられた文字だけで表す。数値には単位と有効数字，向きを問われたら向きも。選択肢は「②（左向き）」と番号と内容。
- **向き・符号**：使った法則と法則に入れた向きを書き，正の向き・選択肢と照らす。大きさは符号を決めた式を示してから正の量で答える。
- **数値**：文字式で答を出してから代入の式を1行書く。
- **論述**：結論を先に，理由を法則名を入れて1〜2文。答の1か所に書く。
- **空欄補充**：冒頭に答の一覧表を置き，各まとまりの答と一致させる。

詳細は `references/answer-style.md`，見本は `references/examples.md`。

## 図

図は svg-figures で作る。問題に図があれば解答の図は「解図1 …」とし，問題の図は「問題の図1」と書く。問題の図に記入して答える図も解図とし，「（問題の図5に記入したもの）」と添える。画像の直下に図題と記号の説明（⊗，⊙）を1〜2文で書く。図中の点は本文で定義してから使い，図は参照する文の直後に置く。式に現れる力（慣性力を含む）と向きの根拠（磁場，電荷の符号，正の向き）は図に描き，省いた素子はキャプションに挙げる。

## 検査を回す

**書いたら必ず検査を run する。** 記号・命令・書式（数式の区切り，単位の書体，式番号，答の行など）・範囲外の語や用語の規則はこの検査が正本で，出力の各行が「なぜだめか → 何に直すか」を示す。`S` はこの SKILL.md のフォルダ（Claude Code では `${CLAUDE_SKILL_DIR}`，Codex の `.agents/skills/…` などでは読み込んだ SKILL.md の場所）。

```sh
python3 "$S/scripts/hs_check.py" run --subject physics --final answer.md --problem problem.md
python3 "$S/scripts/hs_check.py" verify --final answer.md
```

ファイルを作らないときは `--final -`（標準入力）。

1. `run` の出力の1行目に従う。候補を1つずつ答案と照らし，当たっているものだけを1回でまとめて直す。WARN は文脈で決める。検査を消すためだけの言い換えはしない。範囲外の語が出たら，語を変えるのでなく解き方を高校の方法に書き換える。
2. 直したら `run` をもう一度実行し，その後は本文を変えない。
3. 提出の直前に，本文を変えずに `verify` を1回実行する。合わなければ `run` と `verify` をやり直す。

検査が見るのは機械的に判定できることだけで，正しさの合格ではない（下の点検は省かない）。答案と同じフォルダの図には svg-figures の lint もかかる。シェルで Python が使えない環境（アプリ内の AI など）では，`references/check-rules.md`（同じ規則の一覧）で目視し，検査は実行していないと報告する。

検査の結果は答案に書かない。返答では本文の後に `---` で区切って「検査：ERROR 0 件・WARN 1 件」の1行だけを添える。この行は件数だけにし，保存先・ファイル名・verify したことなどを書かない（本文だけを求められたら，聞かれたときに伝える）。`verify` に渡すのは区切りより前の本文。

## 出力前の点検

1. 式の前に対象・正の向き・法則名と使える理由がある。
2. 正の向きと答の符号が合う。
3. 次元が両辺で合い，数値に単位と有効数字がある。近似の条件を書いた。
4. 範囲外の方法がない。答が与えられた文字だけで書かれている。
5. 頼まれていない方針・解説・別解・参考がない。
6. 検査を run し，最後に verify した（できない環境では check-rules.md で目視した）。
