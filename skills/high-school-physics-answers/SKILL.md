# 高校物理の解答・解説を書く

## 目的

読者は高校生と，その答案を採点する先生である。教科書の知識だけで読めて，そのまま答案として書いても減点されない解答・解説を作る。物理の答案は答の式が合うだけでは足りない。**どの物体に，どの向きを正として，どの法則を使ったか**が書かれていなければ，符号の根拠が読み手に伝わらない。

## 数学スキルとの分担

high-school-math-answers の SKILL.md のうち，次の節だけを共通の正本として使う。

- 「出力形式」：Markdown＋LaTeX，式番号の書式と系列，`\varphi`・`\vec{e}_1`，貼り付け用の出力。
- 「答案の構成」：方針／解答／**答** の形，**答** で閉じること，解説・参考の置き方，記号の衝突の調べ方，箇条書きを使わないこと。
- 「図」：解図の番号，代替テキスト，キャプション。

違いが1つある。数学は答案に使えない近道を「参考」に書いてよいが，**物理は「参考」でも範囲外の方法を書かない**（「範囲外だが」と断っても書かない）。

## 範囲

平成30年告示の学習指導要領（2022年度入学生から）の物理基礎・物理。分野ごとの内容は `references/scope.md` 1節。

**問題の科目より先の道具を使わない。** 物理基礎の問題を，運動量保存・円運動・力のモーメント・気体の状態方程式で解かない。

**教科書にない方法を使わない。** 高校の物理は微分・積分を使わずに組み立てられている（変化の割合は $\dfrac{\Delta x}{\Delta t}$，仕事や変位はグラフの面積）。代表例を挙げる。一覧と書き換えは `references/scope.md`（正本）。

| 使わない | 高校での書き方 |
|---|---|
| 微分方程式を解く | 運動方程式を $a=-\omega^{2}x$ の形にして「単振動」と読み，$T=\dfrac{2\pi}{\omega}$ |
| 慣性モーメント，角運動量保存 | 力のモーメントのつり合い（静止した剛体），面積速度一定 |
| 外積 $q\vec{v}\times\vec{B}$ | 大きさ $\lvert q\rvert vB$（$\vec{v}\perp\vec{B}$ のとき。なす角 $\theta$ なら $\lvert q\rvert vB\sin\theta$）。向きはフレミングの左手の法則（正電荷の速度を電流の向きとみる。負電荷は逆向き） |
| ガウスの法則の積分形 | 「電荷 $Q$ から出る電気力線は $4\pi kQ$ 本」 |
| 複素インピーダンス | リアクタンスと，電圧・電流の位相のずれ |
| 虚物体・符号つきのレンズの式 | 光の逆進，作図，1枚ずつ像を求める |

右ねじの法則は，電流とそれがつくる磁場の向きの対応に使う。力の向き（フレミングの左手の法則）とは用途を分けて書く。問題文が与えた仮定や近似は，そのまま使い，証明し直さない。

## 記号・単位・数値

- **問題文の記号・用語をそのまま使う**（$l$ と $\ell$，「電荷」「電界」も問題文どおり）。公式を引くときも文字を合わせる（問題が $\ell$ なら $F=IB\ell$）。自分でおく文字は最小限にし，「…を $N$ とする」と定義する。
- **記号の衝突**は数学スキルの方法で調べる。物理では物体・端子の名前と量記号（物体 $\mathrm{F}$ と力 $F$），同じ文字の別の量（周期と温度の $T$）が衝突しやすい。「した仕事」「された仕事」の記号は最初に1通り決めて宣言する。
- **空欄の記号を数式に入れない**（`\text{ア}=…`，$v_{\text{ウ}}$ としない）。「アは $mg\sin\theta$」と文で書くか，量に $v_{1}$ などの名前を付ける。
- **量記号は斜体，単位・点や物体の名前（添字を含む）は立体。** $v_{\mathrm{A}}=3.0\ \mathrm{m/s}$。数値と単位の間は空ける（`\ `）。
- **単位**：文字式には単位を付けない。数値計算の式は両辺で単位の有無をそろえる（左辺が数だけで右辺だけ単位つき，としない）。換算は式に入る前に済ませる。
- **有効数字**：与えられた数値に合わせる。途中は1桁多く持ち，丸めた値を次の計算に使わない。答は $5.0\times10^{2}\ \mathrm{J}$ のように桁が分かる形で。丸めた結果への等号は `\fallingdotseq`。
- **近似**：使う前に条件と近似式を書く（「$\lvert x\rvert\ll1$ のとき $(1+x)^{n}\fallingdotseq1+nx$」）。何を何とみなしたかをその場で1回書く。項を落とすときは主要な項との比で次数を述べ，1次の項どうしを比べて落とさない。
- 用語は教科書のもの（熱力学第一法則，力学的エネルギー保存の法則，キルヒホッフの第2法則，電気量保存の法則，コンデンサー，電場，磁束密度）。

詳細は `references/notation-units.md`（書体1節，単位2節，有効数字3節，添字4節，近似7節，量記号8節）。必要な節だけを読む。

## 式を立てる前に書くこと

1. **対象**：どの物体（物体の組）についての式か。
2. **正の向き**：「右向きを正とする」。同じ座標系を使う間は変えない。逆向きの量は「左向きの速さを $u$ とする」と大きさでおく。小問で座標を取り直すときは，取り直すことを明示し，前の記号を符号ごと持ち込まない。
3. **法則名と，それが使える理由**：「水平方向には外力がはたらかないから，運動量保存の法則により」「摩擦がなく垂直抗力は仕事をしないから」。電気量保存では，どの極板の和か（孤立した部分）を書く。公式は記号の式（$F=IBl$）で示す。
4. **観測者**：円運動・加速する台では「地面から見ると」か「台とともに動く観測者から見ると（慣性力を含める）」かを1つに決める。
5. **近似**：近似して立てる式は，近似を先に言う。

回転する剛体の定常条件は「回転軸のまわりの力のモーメントの和が 0」と書く（「力が 0」と書かない）。接触が続く・糸がたるまない条件は $N\geqq0$，$T\geqq0$ の式で示す。条件を求める問いは必要性と十分性を分ける。根拠には結論に効く条件だけを書く。

## 問いの形ごとの答え方

- **答**：文字式は問題文で与えられた文字だけで表す。数値には単位と有効数字。向きを問われたら向きも答える。選択肢は番号と内容の両方（「②（左向き）」）。
- **向き・符号**：使った法則と，法則に入れた向き（「電流は P から Q の向き，磁場は鉛直上向きであるから」）を書き，問題の選択肢・正の向きとの対応を述べる。問題の図に選択肢の矢印があれば，同じ視点の解図で示す。
- **数値**：文字式で答を出してから代入の式を1行書き，最後に1回だけ丸める。
- **論述**：結論を先に，理由を法則・量の名前を入れて1〜2文で。答は **答** の1か所に書く。
- **空欄補充**：冒頭に答の一覧表を置き，各まとまりの **答** と一致させる。

詳細は `references/answer-style.md`（空欄1節，導出2節，向き3節，論述4節，数値5節，グラフ6節）。体裁の見本は `references/examples.md`。

## 図

図は svg-figures スキルで作り，番号・キャプションは数学スキル「図」に従う（物理の問題にはほぼ図があるので，解答の図は「解図1 …」になる）。物理で加えること：

- つり合いの式・運動方程式に現れる力は，慣性力も含めて全部図に描く。
- 向きの根拠になる図には，前提（磁場の ⊗ と $B$，速度，電荷の符号，正の向き，電源の＋−）も入れる。
- 問題の図から省いた素子はキャプションに全部挙げ，本文で参照する端子名は図に残す。

## 出力前の点検

1. **対象と法則**：式の前に対象・正の向き・法則名があり，法則が使える条件（外力・摩擦・孤立した極板・観測者）を確かめた。
2. **符号**：正の向きの約束と答の符号が合う。大きさを問われたら正の量で答えた。
3. **近似**：条件と，何を何とみなしたかを書いた。
4. **単位**：次元が両辺で合う。数値に単位と正しい有効数字がある。書体（斜体・立体）が正しい。
5. **範囲**：範囲外の方法が本文にも参考にもない。答が与えられた文字だけで表されている。
