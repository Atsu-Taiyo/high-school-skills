# 物理の答案作法

つなぎの言葉，必要条件と十分条件の言い分け，場合分けなど，数学と共通の作法は high-school-math-answers の `references/answer-style.md` に従う。ここには物理の問題の形式ごとの書き方をまとめる。

## 目次

1. 空欄補充（答の一覧表と本文）
2. 導出問題（対象・正の向き・法則）
3. 向き・符号を答える問い
4. 説明・論述問題
5. 数値を求める問い
6. グラフ・図を描く問い
7. 答の明示
8. 図の番号と参照
9. 解説・参考の書き方
10. 減点されやすい書き方

## 1. 空欄補充（答の一覧表と本文）

空欄が多い大問（ア〜セ，イ〜レ）は，冒頭に答の一覧表を置き，そのあと小問のまとまりごとに導出を書く。

```markdown
## 解答一覧

| 空欄 | 答 |
|---|---|
| ア | $vBl$ |
| イ | $\dfrac{vBl}{R}$ |
| ウ | ②（運動の向きと逆向き） |
| 問1 | $h'=\Bigl(\dfrac{M}{M+m}\Bigr)^{2}h$ |
```

- 式だけでは何の量か分からない欄には，量の名前を添える（「力のモーメントの大きさ」「コンデンサーのエネルギー」）。選択肢の欄は番号と内容を書き，本文の **答** にも同じ内容を書く。
- **一覧表と本文の答を一致させる。** 式の形（$\dfrac{1}{\sin\theta}\sqrt{\dfrac{2h}{g}}$ か $\sqrt{\dfrac{2h}{g\sin^{2}\theta}}$ か），文言とも同じにする。本文を直したら表も直す。
- 選択肢で答える空欄は，番号と内容を並べる：「②（運動の向きと逆向き）」。丸数字は数式の外に書く。
- 表の中の式に縦線を書かない（絶対値は `\lvert x\rvert`）。長い文の答（論述）は表に入れず，「本文」と書いて小問の番号だけ載せる。グラフを描く問いは「解図4」と図の名前を書く。
- 答を示すのは**一覧表と各小問の末尾の2回まで**。最後に「まとめの表」をもう一度置かない。
- **本文では，空欄の記号を数式に入れない。** 次のどちらかで書く。

  > …斜面に沿って上向きを正とすると，斜面に沿う方向の力の成分は $-mg\sin\theta$ である。
  >
  > **答**　ア：$-mg\sin\theta$

  または，量に名前を付ける：「床に達したときの速さを $v_{1}$ とすると … $v_{1}=\sqrt{2gh}$ である。**答**　ウ：$\sqrt{2gh}$」。

  `$$\text{ア}=-mg\sin\theta$$` や $v_{\text{ウ}}$ とは書かない。
- 1つの導出で続けて決まる空欄は，まとめて導いてから「**答**　イ：…，ウ：…」と並べてよい。
- 空欄の前後の問題文の言葉（「大きさは」「向きは」「〜倍」）に合う形で答える。「大きさ」を問われたら正の量，「$x$ 成分」「速度」を問われたら符号つき。
- 空欄補充でも，式の根拠（対象・正の向き・法則）は省かない。ただし導出は短く，1空欄あたり数行を目安にする。

## 2. 導出問題（対象・正の向き・法則）

「導出の過程も示せ」「求めよ」という問いの答案は，次の順に書く。

0. **記号の衝突を調べる**：問題文全体の記号と番号を拾い，自分でおく文字・式番号の系列が重ならないようにする（選択肢が丸数字なら式番号は (a)(b)…）。
1. **設定**：正の向き，自分でおく文字の定義，問題文の語の読み（「静かに放す」＝初速度 0），問題文の状況が成り立つための大小関係（「後ろの A のほうが速いから，A は B に追いつく」）。
2. **対象と法則**：どの物体（物体の組）に，どの法則を使うか。使える理由。
3. **式**：法則をそのまま書いた式。後で参照する式には番号（丸数字は数式の外）。
4. **計算**：連立・代入・整理。途中を飛ばしすぎない。
5. **答**：与えられた文字だけで表す。

型（運動量と力学的エネルギー）：

> 右向きを正とする。小球 A と台 B を合わせた全体には，水平方向の外力がはたらかない。よって，水平方向について運動量保存の法則が成り立つ。A が最高点に達したとき，A と B の速度は等しい。この速度を $V$ とすると
>
> 　$mv_{0}=(m+M)V$　……①
>
> また，面はなめらかで，垂直抗力は A と B の全体に対して仕事をしないから，力学的エネルギー保存の法則が成り立つ。最高点の高さを $h$ とすると
>
> 　$\dfrac{1}{2}mv_{0}^{2}=\dfrac{1}{2}(m+M)V^{2}+mgh$　……②
>
> ① より $V=\dfrac{m}{m+M}v_{0}$ である。これを ② に代入して整理すると
>
> 　$h=\dfrac{Mv_{0}^{2}}{2(m+M)g}$
>
> **答**　$h=\dfrac{Mv_{0}^{2}}{2(m+M)g}$

守ること。

- **式の組み方をそろえる。** 上の型のように，番号つきの式がある導出では，番号の無い1行の式も同じ字下げの形で書く（`$$` は複数行の `aligned` だけ）。解答本体に箇条書きを使わない。
- **対象を述べる。** 「A について」「A と B を合わせた全体について」「ピストンについて」「閉回路 abcd について」。複数の物体があるとき，対象を書かない式は読めない。
- **正の向きは最初に1回宣言し，1題を通して変えない。** 途中で左向きの量が主役になっても，「この問いでは左向きを正とする」と切り替えない。「衝突後の A の左向きの速さを $u$ とする（速度は $-u$）」と大きさで表す。小問ごとに座標を取り直す必要があるときは，取り直すことをはっきり書き，前の小問の記号を符号ごと持ち込まない。
- **法則名を書く。** 「運動方程式」「力のつり合い」「力のモーメントのつり合い」「力学的エネルギー保存の法則」「仕事と運動エネルギーの関係」「運動量保存の法則」「反発係数の式」「ボイル・シャルルの法則」「状態方程式」「熱力学第一法則」「屈折の法則」「レンズの式」「クーロンの法則」「オームの法則」「キルヒホッフの第1法則・第2法則」「電気量保存の法則」「ファラデーの電磁誘導の法則」「レンツの法則」。
- **回路の式**は，キルヒホッフの第2法則なら「閉回路をどの向きに一周したか」，電気量保存の法則なら「**どの極板の電気量の和か**（導線でつながり，ほかから孤立している部分）」を書く。

  > スイッチを切り替えたあと，$C_{1}$ の上側の極板と $C_{2}$ の上側の極板は，抵抗を通してつながり，ほかの部分から孤立している。よって，この2枚の極板の電気量の和は保存される（電気量保存の法則）。
- **近似して立てる式は，物体・向き・近似を先に言う。** 円弧上の運動を直線の運動として扱う，微小角で接線方向を軸方向とみなす，ほかの部分の質量を無視して1つの物体だけの運動方程式にする，といったときは，その読み替えを式の前に書く：「糸とばねの質量は無視できるから，小球について運動方程式を立てる。角が微小なので，円弧の接線方向は $x$ 軸方向とみなせる。」
- **回転する剛体の条件は力のモーメントで述べる。** 一定の角速度で回る・回り始めない，の条件は「回転軸のまわりの力のモーメントの和が 0」。軸も力を及ぼすので，「はたらく力が 0」「合力が 0」とは書かない。
- **根拠に無関係な条件を混ぜない。** 理由として挙げる条件は，その結論を実際に左右するものだけにする。問題文のただし書きを理由に流用する前に，それが結論に効くかを物理的に確かめる（力の分布を決めるのは電流と磁場であって，導体の質量の分布ではない，など）。
- **前の設問の結果を別の設定に使うときは，条件が同じであることを述べる。**（「この場合も中心を通る光は直進し，像までの距離も同じであるから，(2) の関係が成り立つ。」）
- **最高点・最接近など「速度が等しい」と言うときは，どの成分が等しく，残りの成分がどうなるかまで書く**（「A は台に対して静止するので，A の速度は水平成分だけになり，台の速度に等しい」）。
- **周期的に変わる量**（交流，回転するコイルの起電力）の向き・符号は，$0<\omega t<\pi$ のような1周期目の範囲ではなく，$\sin\omega t>0$，$\sin\omega t<0$ で場合を分ける。
- **熱の出入りの符号**を過程全体の値だけで判断しない。過程の途中で吸熱と放熱が入れ替わらないことを一言確かめる。
- **電荷の符号の約束を書く。** どちらの極板が正か（電源の正極につながる側）を述べてから電気量の式を書く。
- **使う公式は記号の式で示す。** 文字は問題文に合わせる（問題が $\ell$ なら $F=IB\ell$）。「（電流）×（磁束密度）×（長さ）」ではなく $F=IBl$。直線電流のつくる磁場は $H=\dfrac{I}{2\pi r}$，$B=\mu H$ と教科書の順に書く。
- **観測者の立場**を宣言する（円運動・加速する台・回転台）。「地面から見ると，A は半径 $r$ の等速円運動をしているから，向心方向の運動方程式は」／「台とともに回る観測者から見ると，A は静止しているから，遠心力を含めた力のつり合いは」。1つの小問の中で2つの立場を混ぜない。
- **接触・拘束が続くこと**は，垂直抗力・張力・支えからの力が $0$ 以上であることを式で示す：「板が台から受ける垂直抗力は $N=mg-kx\geqq0$ であるから，板は台から離れない」。
- **条件を求める問い**（「〜するための条件」）は，必要性と十分性を分けて書く：「達するためには … が必要である。逆に … ならば，… であるから必ず達する。」
- **力の作用点・合力の扱い**に根拠を書く：「力は棒に一様にはたらくので，合力は中点に作用する」。
- 記号の重複を避ける。同じ文字を別の量に使わない（`notation-units.md` 8節）。

## 3. 向き・符号を答える問い

向き（①か②か，時計回りか）や符号（起電力は正か負か）は，結論だけでは根拠にならない。次の3つを書く。

1. **使った法則**：フレミングの左手の法則，右ねじの法則，レンツの法則，ローレンツ力，力のつり合い。
2. **法則に入れた向き**：「電流は P から Q の向き，磁場は紙面の裏から表の向きであるから」。
3. **結論と，問題の選択肢・正の向きとの対応**：「力は左向きである。これは問題の図2(b) の矢印 ② の向きである」「求めた電流は P→Q の向きで，問題が正とした破線の矢印（Q→P）と逆であるから，起電力は負である」。

- 問題の図が横から見た図（側面図）で矢印を与えているなら，**同じ視点の解図**を描き，選択肢の矢印と求めた向きを並べて示す。真上から見た図だけで文章で済ませない。
- 言い回しは，視点と向きが一意に決まるように書く。「磁場を手前に見て時計回り」ではなく「磁場が紙面の裏から表の向きのとき，正の電荷は紙面上で時計回りに回る」。
- 回路の電流の向きは，電源の正極から出て負極に戻る経路を順に追う：「電源の正極 → X → レール → 棒（レール側から回転軸へ）→ 回転軸 → 電源の負極」。電源の極性は図にも記入する。
- 符号つきで答える量（速度，加速度の成分，起電力，仕事）は，最初に決めた正の向きと照らして符号を決め，その照合を1文書く。
- **符号つきの量から「大きさ」を答えるときは，符号を決めた式を示してから絶対値をとる。** 「$-ky=F$ より $y=-\dfrac{F}{k}$ である。求める大きさは $\lvert y\rvert=\dfrac{F}{k}$。」途中を飛ばして大きさだけを書かない。
- 「正とした向き」を別の向きに読み替えるときは主語を書く：「正とした反時計回りの向きは，この位置では $y$ 軸の正の向きとみなせる」。
- レンツの法則で決めた向きを，ローレンツ力でも確かめる，といった二重の説明は書かない（どちらか一方。もう一方は出力前の点検に使う）。

## 4. 説明・論述問題

「簡潔に述べよ」「理由を説明せよ」「〜字程度で」という問い。

- **結論を先に，理由を1〜2文で。** 指定がなければ全体で1〜3文，60〜100字を目安にする。字数の指定があれば，その 8 割以上で超えない。
- **理由には法則・量の名前を入れる。** 「〜の法則により」「〜が保存されるから」「〜の力が仕事をしないから」。「エネルギー的に得だから」のようなあいまいな言い方をしない。
- **答は1か所に書く。** **解答** で説明し，**答** で同じ文をもう一度書く，ということをしない。論述問題では，答そのものを **答** の行に1回書き，補足が要るときだけその前に短い導入を書く。
- **答の枠内だけで完結させる。** 説明に使う文字の定義や式（レンズの式など）も **答** の文章の中に入れ，枠の外に半分，中に半分，と分けない。
- 根拠に前の小問の結果を使うなら，番号を引く：「(2) より，この組み合わせレンズは焦点距離 $f$ の1枚の凸レンズと同じはたらきをする。」
- 答の一覧表に載せるなら，本文と同じ文言にする（要約して言い方を変えない）。長ければ表には「本文」とだけ書く。
- 式で示せることは式を1つ添える。ただし論述の中心は文で，式の羅列にしない。
- 断定の強さを議論の精度に合わせる。2本の光の議論だけなら「暗くなり始める目安になる」。
- 比較を問われたら，比較の結果（大きい・小さい・等しい）と，何と何を比べたかを書く。

型：

> **答**　定常波の腹は管口よりわずかに外側にできるため，管口から最初の節までの距離は $\dfrac{\lambda}{4}$ より短くなるから。

## 5. 数値を求める問い

- 文字式のまま答の式を出し，最後に数値を代入する（途中で数値を入れると，検算も部分点の判断もしにくい）。
- 代入の式を1行書く。単位は両辺でそろえる（`notation-units.md` 2節）。
- 有効数字は与えられた数値に合わせ，丸めは最後に1回。前の小問の丸めた答を使わず，丸める前の値を使う。
- 答は「**答**　$3.4\times10^{2}\ \mathrm{m/s}$」のように，単位と，有効数字が分かる表記で書く。
- 向きのある量は，数値に向きを添える：「右向きに $2.0\ \mathrm{m/s}$」。

## 6. グラフ・図を描く問い

- 答の図は svg-figures で作り，解図として番号を付ける。問題が「図5を描き写して記入せよ」としていれば，「解図4（問題の図5に記入したもの）」と対応を書く。
- 本文には，グラフの**特徴を言葉と数値で**書く：式（$x=A\cos\omega t$），最大・最小の値とそのときの時刻，軸との交点，傾き，漸近する値。図だけを置いて終わらない。
- 問題が求めている要素（「状態変化の向きを示す矢印」「$P_{1}$〜$P_{4}$ の値」「軸の目盛り」）を数え上げ，全部が図に入っていることを確かめる。
- 軌道・軌跡の図は，中心・半径・通過点・回る向きを本文に書く：「点 P を通り，中心が O，半径 $r$ の円を時計回りに回る。」

## 7. 答の明示

| 問いの形 | 答の形 |
|---|---|
| 式で求めよ | 「**答**　$v=\sqrt{2gh}$」。与えられた文字だけで表す |
| 空欄 | 「**答**　ア：$-mg\sin\theta$」 |
| 複数の量 | 「**答**　$w=V$，$V_{1}=v$」 |
| 数値 | 「**答**　$6.5\times10^{-7}\ \mathrm{m}$」 |
| 向きと大きさ | 「**答**　左向きに大きさ $\dfrac{vB^{2}l^{2}}{R}$」 |
| 選択肢 | 「**答**　②」「**答**　(あ)」（丸数字・括弧つきの記号は数式の外） |
| 論述 | 「**答**　…であるから。」（1〜2文） |
| グラフ・図 | 「**答**　解図4」と，特徴を述べた文 |

- 説明問題にも **答** の印を付け，結論の文を示す（ほかの小問と体裁をそろえる）。
- **書式を1題の中でそろえる。** 求める量に記号がある問いは「記号 $=$ 式」，空欄は「ア：式」，と決めて混ぜない。選択肢の問いは「②（左向き）」のように，番号だけでなく内容も本文に書く。
- 2通りの表し方があるとき（$\alpha$ を使うか使わないか）は，問題の指定に合う形を1つだけ答にする。「どちらで答えてもよい」と書かない。
- **答** の後ろに「（確認：…）」「なお…」を続けない。答案は **答** で終える。
- 同値な形のうち，問題文の与え方に近く，簡単な形を選ぶ（展開しすぎない。$(v-V)^{2}$ を展開しない）。
- 括弧は一重なら（ ），その外側が { }，さらに外が [ ]。大きさは `\Bigl( \Bigr)` で合わせる。

## 8. 図の番号と参照

- **解答の図は「解図1，解図2 …」。** 問題の図（図1〜図5）と同じ番号系列を使わない。
- 問題の図を引くときは必ず「問題の図3(b)」と書く。「図3(b) では」と裸で書かない。
- 問題の図番号の表記（「図2―1」のダッシュ，「図3－2」）は問題文に合わせる。
- 画像は `![解図2](fig2.svg)`。代替テキストは名前だけ。
- 図の直下に，図題と説明を本文で書く：

  > 解図2　真上から見た図。⊗ は紙面の表から裏の向きの磁場を表し，導線に近いほど磁場は強い。

- 記号の説明（⊗，⊙），線種の区別（実線：置き換え後，破線：置き換え前），状況（「スイッチを閉じて十分時間が経過した後」），誇張の断り（「角は誇張して描いてある」）は，すべてこのキャプションに書く。図の中には書かない。
- 本文で使う記号（軸，角 $\varphi$，力，電流の向き，問題文の丸囲みの記号）が図にあることを確かめる。図にしか無い記号，本文にしか無い記号を作らない。
- **図中の点・記号は本文で定義してから使う。** 「解図3 より」と書く前に，「2本の光線の延長の交点を T とする」と本文で定義する。定義をキャプションや解説だけに置かない。**図は，それを参照する文の直後に置く**（式の後ろに回さない）。
- **つり合いの式・運動方程式に現れる力は，慣性力も含めて全部図に描く。** 向きの根拠になる図には，磁場（⊗ と $B$），速度，電荷の符号，正の向きの矢印を入れる。圧力の式に入る量（大気圧 $P_{0}$）も図に記入する。
- **省いた素子はキャプションに全部挙げる**（「電池，スイッチ，電流計は省略」）。本文で参照する端子名は図に残す。
- 視点の都合で力や速度の向きが実際と違って見える図は，キャプションで向きを補う。

## 9. 解説・参考の書き方

- **解説は，解答にない着眼点だけ**を書く：なぜその物体（の組）に着目するか，なぜその法則が使えるか（使えないか），典型的な誤り，問題の誘導の意図。解答の手順をなぞり直さない。
- 分量は，解説・参考を合わせて**解答本文の半分以下**。空欄補充の短い小問には解説を付けない。数行で終わる小問に「方針」を付けない。
- **検算・確認を本文に書かない。** 「（確認：鉛直方向の力を直接足すと … となり一致する）」「検算：$\sum Q=W$」は出力前の点検であり，読者には見せない。理解の助けになる確かめ（極端な場合など）を1つだけ残すなら，「参考」と見出しを付けて小問の外にまとめ，1〜2行にとどめる。
- 別解・参考は小問につき1つまで，本解より短く。本解と同じ結論を別の言い方で二度説明しない（「エネルギーで」と「力で」の両方を書かない）。
- **参考欄にも範囲外の方法を書かない**（`scope.md`）。
- 問題文が与えた仮定を証明しない。

## 10. 減点されやすい書き方

| 書き方 | 直し方 |
|---|---|
| 式だけが並び，どの物体のどの法則か分からない | 「A について，運動方程式は」と対象と法則を書く |
| 正の向きが書かれていない／途中で変わる | 最初に宣言し，変えない。逆向きの量は大きさでおく |
| 符号の根拠がない（$-$ が突然付く） | 正の向きと照らした1文を書く |
| 「運動量保存より」とだけ書き，使える理由がない | 「水平方向に外力がはたらかないから」 |
| 「エネルギー保存」で何のエネルギーか分からない | 力学的エネルギーか，熱を含むか，静電エネルギーかを書く。摩擦や抵抗で失われる分を明示する |
| 「電気量保存より $C_{1}V'+C_{2}V'=C_{2}V$」 | どの極板の和かを先に書く |
| 仕事 $W$ が，したのか，されたのか分からない | 「気体が外部にした仕事を $W'$ とする」 |
| 速さと速度，大きさと成分の取り違え | 問いの語を確かめ，符号つきか大きさかを決める |
| 答に，与えられていない文字（自分でおいた $N$，$a$，$T$）が残っている | 消去して，与えられた文字だけにする |
| 数値の答に単位がない／有効数字が合わない | 単位を付け，$\times10^{n}$ で桁を示す |
| 左辺が数値だけ，右辺だけ単位つき | 単位の有無を両辺でそろえる |
| 近似の条件を書かずに $\fallingdotseq$ | 「$\lvert x\rvert\ll1$ のとき」と条件を先に書く |
| 向きの答が結論だけ | 法則名と，入れた向きを書く。問題の図と同じ視点の解図を付ける |
| 空欄記号を式に入れる（$\text{ア}=\cdots$） | 文で書く |
| 解答の図を「図1」と呼ぶ | 「解図1」。問題の図は「問題の図1」 |
| **答** の後に「（確認：…）」が続く | 削る |
| 円運動で「遠心力」と「向心力」を同じ式に入れる | 観測者の立場を1つに決める |
| 物体 F がある問題で力を $F$ とおく | 問題文の記号を先に調べ，$f$ などにする |
| 式番号 ⑦ と選択肢の答 ⑦ が並ぶ | 式番号を (a)(b)… にする |
| 解答本体が箇条書き（`-`） | 文でつなぐか (i)(ii) の文章に |
| 「一定の角速度だから力が 0」 | 「回転軸のまわりの力のモーメントの和が 0」 |
| 近似で落とす項を，別の1次の項と比べる | 主要な項（定数項）との比で次数を述べる |
| 断りなく大きさ（絶対値）で答える | 符号を決めた式を示してから絶対値 |
| 問題文のただし書きを，効かない結論の理由にする | 結論に効く物理的な理由を書く |
| つり合いの式にある力が図に無い | 慣性力も含めて全部描く |
| 論述で同じ内容を2回書く | **答** に1回 |
| 参考欄で範囲外の式を紹介する | 書かない |
