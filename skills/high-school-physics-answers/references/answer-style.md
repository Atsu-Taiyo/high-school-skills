# 物理の答案作法

SKILL.md の原則1〜4（範囲，対象・向き・法則，適用条件，符号）の判断の基準と，問いの形ごとの書き方。答案の形（方針／解答／**答**，**答** で閉じる，解説・参考の置き方，記号の衝突），式番号，図の番号は high-school-math-answers の SKILL.md「答案の構成」「出力形式」「図」が正本。

## 1. 導出の組み立て

順序：**設定**（正の向き，自分でおく文字の定義，問題文の語の読み，状況が成り立つための前提）→ **対象と法則**（どの物体・物体の組に，どの法則を，なぜ）→ **式**（法則をそのまま書いた式。後で参照する式に番号）→ **計算** → **答**（与えられた文字だけで表す）。

型：

> 右向きを正とする。小球 A と台 B を合わせた全体には，水平方向の外力がはたらかない。よって，水平方向について運動量保存の法則が成り立つ。A が最高点に達したとき，A と B の速度は等しい。この速度を $V$ とすると
>
> 　$mv_{0}=(m+M)V$　……①
>
> また，面はなめらかで，垂直抗力は A と B の全体に対して仕事をしないから，力学的エネルギー保存の法則が成り立つ。最高点の高さを $h$ とすると
>
> 　$\dfrac{1}{2}mv_{0}^{2}=\dfrac{1}{2}(m+M)V^{2}+mgh$　……②

## 2. 判断の基準

### 対象と法則

- 式ごとに対象を述べる。物体が複数あるとき，対象を書かない式は読めない。
- 法則は名前で書き，使う公式は記号の式で示す（文字は問題文に合わせる）。
- **適用条件は結論に効くものだけ**を書く：保存則なら「何が保存されるのは，何が無いからか」（外力，摩擦，仕事をしない力，孤立した部分），回路なら「どの閉回路をどの向きに一周したか」「どの極板の和か」。問題文のただし書きを理由に流用する前に，それが結論を物理的に左右するかを確かめる。
- 状態を同一視するとき（最高点で「速度が等しい」，十分時間が経過した後）は，どの成分・どの量が等しく，残りがどうなるかまで書く。
- 前の設問の結果を別の設定に使うときは，条件が同じであることを述べる。

### 観測者

- 静止した観測者から見て運動方程式を書くか，加速・回転する観測者から見て慣性力を含めたつり合いを書くかを宣言し，1つの小問の中で混ぜない。
- 回転する剛体の定常条件は「回転軸のまわりの力のモーメントの和が 0」（軸からも力を受けるので「力が 0」とは書かない）。合力の作用点を使うときは根拠を書く。

### 条件を求める問い

- 接触・拘束が続くことは，垂直抗力・張力などが 0 以上であることを式で示す。
- 「〜するための条件」は必要性と十分性を分けて書く。

### 符号

- 符号つきで答える量は，最初に決めた正の向きと照らして符号を決め，その照合を1文書く。正とした向きを別の言い方に読み替えるときは主語を書く。
- 周期的に変わる量の符号は，特定の時間範囲ではなく，その量を決める関数（$\sin\omega t$ など）の符号で場合を分ける。
- 過程の途中で符号が変わりうる量（熱の出入りなど）は，全体の値だけで判断せず，途中で入れ替わらないことを確かめる。

## 3. 問いの形ごとの書き方

**空欄補充**：冒頭に答の一覧表を置き，各まとまりの末尾の **答** と式の形・文言まで一致させる（答を示すのはこの2か所まで）。式だけでは何の量か分からない欄には量の名前を，選択肢の欄には番号と内容を書く。表の中の式に縦線を書かず，長い文の答は表に「本文」と書く。空欄補充でも式の根拠は省かないが，導出は短くする。空欄の前後の言葉（「大きさは」「向きは」）に合う形で答える。

**向き・符号**：(1) 使った法則，(2) 法則に入れた向き，(3) 結論と問題の選択肢・正の向きとの対応，の3つを書く。問題の図に選択肢の矢印があれば，同じ視点の解図に選択肢の矢印と求めた向きを並べる。回路の電流の向きは，電源の正極から負極までの経路を順に追い，電源の極性を図にも入れる。

**論述**：結論を先に，理由を1〜2文で，法則・量の名前を入れて書く。字数の指定があればその8割以上で超えない（指定がなければ1〜3文）。答は **答** の1か所に，説明に使う文字の定義もその中に入れる。断定の強さを議論の精度に合わせる。比較を問われたら，何と何を比べてどうなったかを書く。

**数値**：文字式で答を出してから代入の式を1行書き，最後に1回丸める。向きのある量は数値に向きを添える。

**グラフ・図を描く**：解図に番号を付け，本文にはグラフの特徴（式，最大・最小とその時刻，軸との交点，傾き，漸近する値）を言葉と数値で書く。問題が求める要素（向きの矢印，指定された値，目盛り）を数え上げ，全部が図にあることを確かめる。

## 4. 答の書式

| 問いの形 | 答の形 |
|---|---|
| 式で求めよ | 「**答**　$v=\sqrt{2gh}$」（与えられた文字だけ） |
| 空欄 | 「**答**　ア：…，イ：…」 |
| 数値 | 単位と，有効数字が分かる表記 |
| 向きと大きさ | 「左向きに大きさ …」 |
| 選択肢 | 「②（左向き）」（丸数字は数式の外） |
| 論述 | 結論の文（1〜2文） |
| グラフ・図 | 解図の名前と，特徴を述べた文 |

- 1題の中で書式をそろえる。2通りの表し方があるときは，問題の指定に合う形を1つだけ答にする。
- 同値な形のうち，問題文の与え方に近く簡単な形を選ぶ（展開しすぎない）。

## 5. 解説・参考

- 解説は解答にない着眼点だけ（なぜその物体・法則か，典型的な誤り，誘導の意図）。短い小問に解説や方針を付けない。
- 検算・確認を本文に載せない。理解の助けになる確かめを残すなら「参考」として小問の外に短く置く。本解と同じ結論を別の言い方で二度説明しない。
- 参考欄にも範囲外の方法を書かない。問題文が与えた仮定を証明しない。
