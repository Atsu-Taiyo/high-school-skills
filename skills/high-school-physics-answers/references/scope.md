# 範囲と，範囲外の方法の書き換え

平成30年告示の学習指導要領（2022年度入学生から）の「物理基礎」「物理」に従う。範囲外の方法を思いついたら，ここで高校での書き方を確かめて書き直す。範囲外の方法は自分の検算に使ってよいが，**答案には書かない**。「範囲外だが」「発展」と断っても書かない（答案の手本にならない）。

## 1. 科目と内容

## 2. 全分野に共通すること（微分・積分を使わない）

高校の物理の教科書は，微分・積分の記号を使わずに書かれている。数学Ⅲを学んでいる生徒でも，物理の答案で微積分を使う義務はなく，教科書の作法（グラフの傾き・面積，$\Delta$）で書いたものが標準になる。

| 使わない | 高校での書き方 |
|---|---|
| $v=\dfrac{dx}{dt}$，$a=\dfrac{dv}{dt}$ | $v=\dfrac{\Delta x}{\Delta t}$（$x$-$t$ グラフの傾き），$a=\dfrac{\Delta v}{\Delta t}$（$v$-$t$ グラフの傾き） |
| 積分で変位・仕事・力積を求める | $v$-$t$ グラフの面積が変位，$F$-$x$ グラフの面積が仕事，$F$-$t$ グラフの面積が力積，$p$-$V$ グラフの面積が気体のする仕事 |
| 微分方程式を立てて解く | 等加速度直線運動の3公式，単振動の公式，問題文が与える関係式 |
| $x=A\sin\omega t$ を微分して $v$，$a$ を出す | 教科書の公式 $v=A\omega\cos\omega t$，$a=-A\omega^{2}\sin\omega t=-\omega^{2}x$ を「等速円運動の正射影」として使う |
| 運動方程式を積分してエネルギー保存を導く | 仕事と運動エネルギーの関係，力学的エネルギー保存の法則をそのまま使う |
| テイラー展開，高次の近似 | $\lvert x\rvert\ll1$ のとき $(1+x)^{n}\fallingdotseq1+nx$，$\sin\theta\fallingdotseq\theta$（`notation-units.md` 7節） |
| 偏微分，ナブラ，線積分・面積分 | 範囲外。その方法ごと避ける |
| 行列，固有値，複素数の指数関数 | 範囲外 |

ばねの弾性力の仕事 $\dfrac{1}{2}kx^{2}$，万有引力による位置エネルギー $-G\dfrac{Mm}{r}$，コンデンサーの静電エネルギー $\dfrac{1}{2}CV^{2}$，コイルのエネルギー $\dfrac{1}{2}LI^{2}$ は，教科書の公式としてそのまま使う（導出を求められたら，グラフの面積で説明する）。

## 3. 力学

| 使わない | 高校での書き方 |
|---|---|
| 微分方程式 $m\ddot{x}=-kx$ を解く | 運動方程式 $ma=-kx$ を $a=-\dfrac{k}{m}x$ と書き，「$a=-\omega^{2}x$ の形であるから，角振動数 $\omega=\sqrt{\dfrac{k}{m}}$ の単振動」と読む。周期は $T=\dfrac{2\pi}{\omega}$。位置と時刻の関係は，振動の中心・振幅・初めの位置から $x=A\sin\omega t$ や $x=A\cos\omega t$ を選ぶ |
| 振動の中心を「平衡点のまわりの展開」で求める | 力のつり合いの位置を $x_{0}$ とし，$a=-\omega^{2}(x-x_{0})$ の形に直して「$x=x_{0}$ を中心とする単振動」 |
| 慣性モーメント，回転の運動方程式，回転の運動エネルギー | 範囲外。剛体は**静止している（つり合っている）場合だけ**を扱い，「力のつり合い」と「任意の点のまわりの力のモーメントのつり合い」の2つで書く。転がる球・回る棒の運動は，問題文が与える関係式だけで解く。**一定の角速度で回り続ける条件は「回転軸のまわりの力のモーメントの和が 0」と書く**（軸からも力を受けるので「力が 0」とは書かない） |
| 角運動量，角運動量保存の法則 | 惑星・人工衛星は「面積速度一定の法則（ケプラーの第2法則）」$\dfrac{1}{2}r_{1}v_{1}=\dfrac{1}{2}r_{2}v_{2}$（近日点と遠日点）。糸で引かれて回る小球などは，問題文の誘導に従う |
| 力のモーメントをベクトルの外積で書く | 「力の大きさ × うでの長さ」。反時計回りを正などと向きを決める |
| 換算質量，重心系への変換 | 運動量保存の法則と力学的エネルギー保存の法則（または反発係数の式）の連立。重心の速度が一定であることを使うときは，「外力がはたらかないので運動量の和は一定であり，重心の速度 $\dfrac{m_{1}v_{1}+m_{2}v_{2}}{m_{1}+m_{2}}$ は一定である」と運動量保存から述べる |
| ラグランジアン，ハミルトニアン，仮想仕事の原理 | 運動方程式とつり合いの式 |
| コリオリの力 | 範囲外。回転する観測者の立場で運動を追う解法を避け，静止した観測者から見て解く |
| 有効ポテンシャル，脱出速度の導出に積分 | 力学的エネルギー保存の法則と $U=-G\dfrac{Mm}{r}$ |
| 非慣性系での一般の議論 | 「加速度 $a$ で動く観測者から見ると，質量 $m$ の物体に，加速度と逆向きに大きさ $ma$ の慣性力がはたらく」（等速円運動する観測者なら遠心力 $mr\omega^{2}$） |
| 空気抵抗 $kv$ の運動を指数関数で解く | 終端速度（力のつり合い $mg=kv$）と，$v$-$t$ グラフの定性的な形 |
| 束縛条件を微分して加速度の関係を出す | 「糸の長さが一定であるから，A が $x$ 動くと B は $2x$ 動く。よって加速度の大きさも2倍」と変位で述べる |

そのほかの注意。

- 衝突は「運動量保存の法則」と「反発係数の式」。弾性衝突でエネルギー保存を使うなら，そのことを述べる。
- 摩擦のある運動は，「動摩擦力のした仕事の分だけ力学的エネルギーが変化する」と書く。
- 円運動は，地面から見て「向心方向の運動方程式 $m\dfrac{v^{2}}{r}=F$」と書くか，物体とともに回る立場で「遠心力を含めたつり合い」と書くか，どちらかを最初に宣言する。
- 鉛直面内の円運動は，力学的エネルギー保存の法則と，各点での向心方向の運動方程式。糸がたるまない・面から離れない条件は $T\geqq0$，$N\geqq0$。

## 4. 熱

| 使わない | 高校での書き方 |
|---|---|
| 等温変化の仕事 $nRT\log\dfrac{V_{2}}{V_{1}}$（積分） | 範囲外。$p$-$V$ グラフの面積として大小を比べるか，熱力学第一法則 $Q=W'$（$\Delta U=0$）で熱量と結ぶ。式の値が要る問題では問題文が与える |
| ポアソンの法則 $pV^{\gamma}=\text{一定}$ の導出 | 問題文や教科書の式として使う（導出しない）。断熱変化の仕事は熱力学第一法則から $W'=-\Delta U=-nC_{V}\Delta T$ |
| エントロピー，カルノーサイクルの効率の導出，熱力学第二法則の定量的な式 | 範囲外。熱効率は，1サイクルで吸収した熱量 $Q_{1}$ と外部にした正味の仕事 $W'$ から $e=\dfrac{W'}{Q_{1}}$ と，各過程の熱量を計算して求める |
| マクスウェル分布，エネルギー等分配則（自由度） | 単原子分子理想気体の $U=\dfrac{3}{2}nRT$。二原子分子の $\dfrac{5}{2}$ は問題文が与えたときだけ |
| 微小変化 $dU=nC_{V}dT$ などの微分形 | $\Delta U=nC_{V}\Delta T$，$W'=p\Delta V$（定圧） |
| ファンデルワールスの状態方程式 | 範囲外 |

- 気体の変化は，各状態の $(p, V, T)$ を状態方程式で求め，過程ごとに $\Delta U$，$W'$，$Q$ を表にまとめるとよい。
- 仕事の符号は，「気体が外部にした仕事」か「気体が外部からされた仕事」かを必ず言葉で書く（`notation-units.md` 8節）。
- ピストンのつり合いは「ピストンにはたらく力のつり合い」と対象を述べ，大気圧・重力・ばねの力・気体の圧力による力をすべて挙げる。

## 5. 波

| 使わない | 高校での書き方 |
|---|---|
| 波動方程式，複素数による波の表示 $e^{i(kx-\omega t)}$ | 正弦波の式 $y=A\sin2\pi\Bigl(\dfrac{t}{T}-\dfrac{x}{\lambda}\Bigr)$ |
| 波数 $k$，角振動数だけで書いた $y=A\sin(kx-\omega t)$ | 問題文が使っていなければ $T$，$\lambda$，$f$，$v$ で書く |
| フーリエ級数，群速度，分散関係 | 範囲外 |
| 三角関数の和積の公式を説明なしに使う定常波・うなりの導出 | 数学Ⅱの加法定理から導ける範囲で書くか，重ね合わせの作図で説明する |
| 虚物体を使う符号つきのレンズの式（$a<0$） | 組み合わせレンズは，1枚目の像を求め，2枚目については**光の逆進**（像と物体を入れ替えて考える）か作図で処理する。教科書のレンズの式 $\dfrac{1}{a}+\dfrac{1}{b}=\dfrac{1}{f}$ は，実物体（$a>0$）に対して，虚像を $b<0$，凹レンズを $f<0$ とする範囲で使う |
| レンズメーカーの式，球面収差，行列光学 | 範囲外 |
| フレネルの式，反射率 | 反射での位相の変化（屈折率の小さい媒質から大きい媒質への反射で $\pi$ ずれる）だけを使う |
| 回折の強度分布（積分），単スリットの暗線の一般論 | 2本の光の経路差による明暗の条件。全体の明暗を2本だけで断定せず，「暗くなり始める目安」のように書く |
| 相対論的ドップラー効果，斜め方向の一般公式 | 音源・観測者の速度の，両者を結ぶ直線方向の成分を使って，1直線上の公式 $f'=\dfrac{V-v_{\mathrm{O}}}{V-v_{\mathrm{S}}}f$ に入れる |

- 干渉の条件は「経路差（光路差）$=m\lambda$ で強め合い，$=\Bigl(m+\dfrac{1}{2}\Bigr)\lambda$ で弱め合う（$m=0,1,2,\cdots$）」と，$m$ の範囲と位相の反転の有無を書く。
- 経路差の近似（ヤングの実験の $\dfrac{dx}{L}$ など）は，近似の条件（$d\ll L$，$x\ll L$）を書いてから使う。

## 6. 電磁気

| 使わない | 高校での書き方 |
|---|---|
| 外積によるローレンツ力 $q\vec{v}\times\vec{B}$，$I\vec{l}\times\vec{B}$ | 大きさ $f=\lvert q\rvert vB$，$F=IBl$（速度・電流が磁場と垂直のとき。なす角が $\theta$ なら $\sin\theta$ を掛ける）。向きは**フレミングの左手の法則**（正電荷の速度の向きを電流の向きとみる。負の電荷は逆向き）。どの指をどの向きに当てたかを書く。右ねじの法則は電流がつくる磁場の向きに使うもので，力の向きには使わない |
| 電流がつくる磁場の向きを外積・ビオ・サバールの法則で | **右ねじの法則**。大きさは公式：直線電流 $H=\dfrac{I}{2\pi r}$，円形電流の中心 $H=\dfrac{I}{2r}$，ソレノイド $H=nI$。磁束密度は $B=\mu H$ |
| アンペールの法則の積分形 | 上の3つの公式 |
| ガウスの法則の積分形 $\oint\vec{E}\cdot d\vec{S}=\dfrac{Q}{\varepsilon_{0}}$ | 「電気量 $Q$ の電荷から出る電気力線の総数は $4\pi kQ$ 本」「電場の強さ $E$ の所では，電場に垂直な単位面積を $E$ 本の電気力線が貫く」。平行板なら，面積 $S$ を $4\pi kQ$ 本が一様に貫くから $E=\dfrac{4\pi kQ}{S}$ |
| $E=-\dfrac{dV}{dx}$，電位を積分で求める | 一様な電場で $V=Ed$。点電荷の電位 $V=k\dfrac{Q}{r}$ は公式として使う。電場は等電位面に垂直で，電位の高い方から低い方へ向かう |
| 複素インピーダンス，フェーザを複素数で | 抵抗・コイル・コンデンサーそれぞれの，電圧と電流の最大値の関係（$V_{0}=RI_{0}$，$V_{0}=\omega LI_{0}$，$V_{0}=\dfrac{I_{0}}{\omega C}$）と位相（コイルは電流が $\dfrac{\pi}{2}$ 遅れ，コンデンサーは $\dfrac{\pi}{2}$ 進む）。RLC 直列は教科書の $Z=\sqrt{R^{2}+\Bigl(\omega L-\dfrac{1}{\omega C}\Bigr)^{2}}$ |
| RC・RL 回路の過渡現象を指数関数で（時定数） | 「スイッチを入れた直後」（コンデンサーの電圧・コイルの電流は直前と同じ）と「十分時間が経過した後」（コンデンサーの電流 0，コイルの起電力 0）の2つの状態で論じる。途中はグラフの定性的な形 |
| LC 回路の微分方程式 | 電気振動の周期 $T=2\pi\sqrt{LC}$（公式）と，エネルギーの保存 $\dfrac{1}{2}CV^{2}+\dfrac{1}{2}LI^{2}=\text{一定}$ |
| $V=-\dfrac{d\Phi}{dt}$，$V=-L\dfrac{dI}{dt}$ | $V=-N\dfrac{\Delta\Phi}{\Delta t}$，$V=-L\dfrac{\Delta I}{\Delta t}$。動く導体棒は $V=vBl$ |
| 回転する導体棒・円板の起電力を積分で | 「微小時間 $\Delta t$ に棒が通過する面積 $\dfrac{1}{2}l^{2}\omega\Delta t$ を貫く磁束」から $V=\dfrac{1}{2}Bl^{2}\omega$，または棒の中点の速さ $\dfrac{l\omega}{2}$（平均の速さ）を使って $V=\dfrac{l\omega}{2}Bl$ |
| 回転の運動方程式（導体棒・コイルの角加速度），力積のモーメント | 範囲外。問題文が与える関係（「電気量の和は変化しないと考えてよい」など）をそのまま使い，証明し直さない |
| マクスウェル方程式，変位電流，ポインティングベクトル | 範囲外 |
| 電気影像法 | 範囲外 |
| 磁気モーメント，磁気双極子 | コイルの各辺が受ける力と，その力のモーメント |

- 回路の式には，法則名（キルヒホッフの第2法則，電気量保存の法則）と，**どの閉回路を・どの向きに一周したか**，**どの極板の電気量の和か**を書く。
- 誘導起電力の向きは「レンツの法則」（磁束の変化を妨げる向き）か，導体中の電荷にはたらく「ローレンツ力」のどちらで決めたかを書く。
- 電池の記号は長い線が正極。電流の向きを論じる図には電源を描き，＋−を記入する（svg-figures）。

| 使わない | 高校での書き方 |
|---|---|
| シュレーディンガー方程式，波動関数，不確定性原理の式 | ボーアの量子条件 $2\pi r=n\lambda$（$mvr=n\dfrac{h}{2\pi}$）と振動数条件 $h\nu=E_{n}-E_{n'}$ |

## 8. 問題文が与えたものの扱い

- 問題文が与えた仮定・近似・関係式は，**証明せずにそのまま使う**。「…と考えてよい」とされたことを，範囲外の方法で確かめ直さない。使うときは「問題文より」と書く。
- 問題文が範囲外に見える量や式を定義して与えているとき（慣性モーメントに当たる定数 $\beta$，断熱変化の関係式など）は，その定義の範囲で使う。名前を補って一般論を展開しない。
- 入試問題の誘導（空欄の順序）は，その順に使う道具を示している。誘導と別の方法で一気に解かず，空欄の流れに沿って導く。
- 高校の範囲で2通りの解き方があるとき（エネルギーで解くか，運動方程式と等加速度の式で解くか）は，問題の誘導に合う方を本解にする。
