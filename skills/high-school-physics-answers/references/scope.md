# 範囲，範囲外の方法の書き換え，固有の約束

平成30年告示の学習指導要領（2022年度入学生から）の「物理基礎」「物理」に従う。範囲外の方法は自分の検算に使ってよいが，**解答にも，解説にも，「参考」にも書かない**（断っても書かない）。依頼者が発展的な内容を明示的に求めたときだけ，本解と分けて書く。

## 1. 科目と内容

| 科目 | 内容 |
|---|---|
| 物理基礎 | 運動の表し方（直線運動，相対速度，$v$-$t$ グラフ），さまざまな力，力のつり合い，作用反作用，運動方程式，落下運動，仕事と力学的エネルギー／熱と温度，熱量の保存，熱と仕事（熱力学第一法則，熱効率）／波の性質，重ね合わせ，定常波，音（うなり，弦，気柱）／静電気，電流と抵抗，電力，交流と電磁波（定性的）／エネルギーの利用，放射線 |
| 物理 | 平面内の運動，放物運動，剛体のつり合い（力のモーメント），運動量と力積，反発係数，円運動，慣性力，単振動，万有引力／気体分子の運動，気体の状態変化，モル比熱／波の式，干渉・回折，ドップラー効果，光（反射・屈折・レンズ・干渉・偏光）／電場と電位，コンデンサー，直流回路（キルヒホッフの法則），半導体，電流と磁場，ローレンツ力，電磁誘導，自己・相互誘導，交流回路，電気振動，電磁波／電子，光の粒子性，物質波，原子の構造，原子核，素粒子 |

**科目の境界**：物理基礎の問題を，物理で習う道具（運動量保存の法則，円運動の式，力のモーメント，気体の状態方程式，$V=Ed$，キルヒホッフの法則）で解かない。

## 2. 範囲外の方法と高校での書き方

原則：**微分・積分を使わない**。変化の割合は $\Delta$ とグラフの傾き，累積はグラフの面積，運動の形は運動方程式を教科書の形（$a=-\omega^{2}x$ など）に直して読む。

| 使わない | 高校での書き方 |
|---|---|
| $\dfrac{dx}{dt}$，積分で変位・仕事・力積を求める | $\dfrac{\Delta x}{\Delta t}$（グラフの傾き），$v$-$t$・$F$-$x$・$F$-$t$・$p$-$V$ グラフの面積 |
| 微分方程式を解く（単振動，空気抵抗，RC・RL 回路，LC 回路，放射性崩壊） | 運動方程式を $a=-\omega^{2}(x-x_{0})$ の形にして「$x_{0}$ を中心とする単振動」と読む。過渡現象は直後と十分時間が経過した後の2状態と定性的なグラフ。電気振動は $T=2\pi\sqrt{LC}$ とエネルギー保存。崩壊は半減期の式 |
| テイラー展開，高次の近似 | $\lvert x\rvert\ll1$ のとき $(1+x)^{n}\fallingdotseq1+nx$，$\sin\theta\fallingdotseq\tan\theta\fallingdotseq\theta$ |
| 慣性モーメント，回転の運動方程式，角運動量保存 | 剛体は静止（つり合い）だけを扱い，力のつり合いと力のモーメントのつり合いで書く。惑星は面積速度一定 |
| 外積（力のモーメント，ローレンツ力，電流が受ける力） | 大きさの式と，向きの法則（下の固有の約束） |
| 換算質量，重心系，ラグランジアン，コリオリの力 | 運動量保存・エネルギー保存・運動方程式を静止した観測者から |
| 束縛条件の微分 | 変位の関係で述べ，加速度も同じ比になると書く |
| 等温変化の仕事の積分，エントロピー，エネルギー等分配 | $p$-$V$ グラフの面積と熱力学第一法則。単原子分子の $U=\dfrac{3}{2}nRT$（それ以外の係数は問題文が与えたときだけ） |
| 波動方程式，複素数の波，波数だけの表示 | $y=A\sin2\pi\Bigl(\dfrac{t}{T}-\dfrac{x}{\lambda}\Bigr)$。問題文が使っていなければ $T$，$\lambda$，$f$，$v$ で書く |
| 虚物体を使う符号つきのレンズの式 | 1枚ずつ像を求め，光の逆進か作図で処理する |
| 回折の強度分布，斜め方向のドップラー効果の一般式 | 2本の光の経路差の条件（全体の明暗は「目安」と書く）。速度の，音源と観測者を結ぶ方向の成分を1直線の公式に入れる |
| ガウスの法則・アンペールの法則の積分形，ビオ・サバールの法則，$E=-\dfrac{dV}{dx}$ | 電気力線の本数（電荷 $Q$ から $4\pi kQ$ 本，単位面積を $E$ 本），直線電流・円形電流・ソレノイドの磁場の公式，一様な電場で $V=Ed$ |
| 複素インピーダンス | 各素子の電圧と電流の最大値の関係と位相のずれ，RLC 直列の $Z=\sqrt{R^{2}+\Bigl(\omega L-\dfrac{1}{\omega C}\Bigr)^{2}}$ |
| $V=-\dfrac{d\Phi}{dt}$，回転する導体の起電力を積分で | $V=-N\dfrac{\Delta\Phi}{\Delta t}$，$V=vBl$。回転する棒は微小時間に横切る面積の磁束か，平均の速さで求める |
| シュレーディンガー方程式，相対論的なエネルギーの一般式 | ボーアの量子条件と振動数条件，光子の $E=h\nu$，$p=\dfrac{h}{\lambda}$，$E=mc^{2}$ |

ばねの弾性エネルギー，万有引力の位置エネルギー，コンデンサー・コイルのエネルギーは教科書の公式としてそのまま使う。

## 3. 固有の約束

教科書の定義・決まりとして覚えておくもの（原則からは導けない）。

| 内容 | 約束 |
|---|---|
| ローレンツ力・電流が受ける力 | 大きさは $f=\lvert q\rvert vB$，$F=IBl$（速度・電流が磁場と垂直のとき。なす角が $\theta$ なら $\sin\theta$ を掛ける）。向きは**フレミングの左手の法則**（正電荷の速度の向きを電流の向きとみる。負電荷は逆向き）。どの指をどの向きに当てたかを書く |
| 電流がつくる磁場 | 向きは**右ねじの法則**（力の向きには使わない）。大きさは $H=\dfrac{I}{2\pi r}$，$\dfrac{I}{2r}$，$nI$ と $B=\mu H$ の順に書く |
| 誘導起電力の向き | レンツの法則（磁束の変化を妨げる向き）か，導体中の電荷にはたらくローレンツ力のどちらで決めたかを書く。二重に説明しない |
| 熱力学第一法則 | 「気体が外部からされた仕事 $W$」なら $\Delta U=Q+W$，「外部にした仕事 $W'$」なら $Q=\Delta U+W'$。どちらかを言葉で定義する |
| レンズの式 | $\dfrac{1}{a}+\dfrac{1}{b}=\dfrac{1}{f}$ は実物体（$a>0$）に対して，虚像を $b<0$，凹レンズを $f<0$ とする範囲で使う |
| 干渉の条件 | 経路差（光路差）が $m\lambda$ で強め合い，$\Bigl(m+\dfrac{1}{2}\Bigr)\lambda$ で弱め合う。$m$ の範囲と，反射による位相の反転（屈折率の小さい媒質から大きい媒質への反射で $\pi$）の有無を書く |
| 正弦波・単振動 | $v=A\omega\cos\omega t$，$a=-\omega^{2}x$ は等速円運動の正射影として使う |
| 電池・コンデンサー | 電池の記号は長い線が正極。電気量保存は「どの極板の和か（導線でつながり，ほかから孤立した部分）」を書く |
| 状態の読み | 「静かに放す」は初速度 0，「なめらか」は摩擦なし，「軽い」は質量を無視，「十分時間が経過した」はコンデンサーの電流 0・コイルの起電力 0 |
