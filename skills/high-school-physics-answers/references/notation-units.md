# 記号・単位・数値の書き方

SKILL.md の原則5〜7（近似，単位と数値，記号と言葉）の判断の基準と，教科書の表記の約束。数式の出力形式（`$...$`，式番号，`\varphi`）は high-school-math-answers の SKILL.md「出力形式」に従う。

## 1. 書体

**基準**：量・定数・変数は斜体，それ以外（単位，点・物体・端子・素子の名前，元素記号，数字，関数名）は立体。添字も同じ規則で，名前を表す添字は立体（$v_{\mathrm{A}}$），量や成分を表す添字は斜体（$v_{x}$，$C_{V}$），番号は数字（$v_{0}$）。同じ文字でも役割で書体が変わる（点 $\mathrm{A}$ と振幅 $A$）。問題文の字形（$\ell$ と $l$）に合わせ，混ぜない。

## 2. 単位

- SI を使い，数値と単位の間を空ける（`3.0\ \mathrm{m/s}`）。組立単位の斜線は1つ（$\mathrm{J/(mol\cdot K)}$），積は `\cdot`。角度は $30^{\circ}$，セルシウス温度は $20\ {}^{\circ}\mathrm{C}$。
- **基準**：等号の両辺は同じ種類のもの（数どうし，量どうし）にする。文字式には単位を付けない（量の定義を引くときは「速さ $v$〔m/s〕」）。数値の式は，すべての数値に単位を付けるか，単位を省いて計算し結果を文で述べる。換算は式に入る前に済ませる。
- 例：$\lambda=\dfrac{340\ \mathrm{m/s}}{500\ \mathrm{Hz}}=0.680\ \mathrm{m}$ はよいが，$\dfrac{340}{500}=0.680\ \mathrm{m}$ は左辺が数で右辺が長さなので誤り。

## 3. 有効数字

- 掛け算・割り算は有効数字の桁数が最も少ないものに，足し算・引き算は末位が最も高いものに合わせる。式の中の整数や $\pi$ は数えない（$\pi$，$\sqrt{2}$ の値は指示がなければ必要な桁より1桁多く取る）。
- **基準**：丸めは最後に1回。途中は1桁多く持ち，前の小問の丸めた答ではなく丸める前の値（または文字式）から計算する。
- 答は桁が分かる形（$5.0\times10^{2}\ \mathrm{J}$）。末尾の 0 は落とさない。丸めた結果への等号は `\fallingdotseq`。
- 文字式で答える問題では数値を持ち込まない。

## 4. 向き・符号・変化量

- 直線上の量は正の向きを決めて符号つきの数で表す。「速度・加速度・力」は向きを含み，「速さ・大きさ」は 0 以上。問いがどちらを求めているかを確かめる。
- 向きは言葉で一意に書く（「鉛直下向き」「P から Q の向き」「紙面の裏から表の向き」「上から見て反時計回り」）。視点が要る言い方は視点も書く。
- ベクトルは $\vec{v}$（太字にしない），大きさは $v$。式はほとんど成分か大きさで書き，内積・外積の記号は使わない（向きの法則は `scope.md` 3節）。
- 変化量は「後 − 前」（$\Delta U=U_{2}-U_{1}$）。減少量を正の量として使うときは断る。微小量の高次の項を無視するときは，何を無視するかを書く。

## 5. 近似

- **基準**：近似は「何が何に比べて十分小さいか」を文字でおいて示してから，近似式を使う。何を何とみなしたか（円弧を弦とみなす，など）をその場で1回書く。項を落とすときは主要な項（多くは定数項）でくくり，残りの次数で判断する。同じ次数の項どうしを比べて落とさない（一方が 0 に近い配置で破綻する）。
- 近似の前に厳密な式を書き，どの段階で近似したかが分かるようにする。問題文が近似式を与えていれば，その式だけを使う。
- 近似的な議論の結論は，断定の強さを議論の精度に合わせる。
- `\ll`，`\gg`，`\fallingdotseq` を使う（`\approx`，`\simeq` は使わない）。

## 6. 主な量記号

問題文の記号が優先。問題文にない量を自分でおくときに使う。1題の中で同じ文字が別の量として出るとき（時間と温度の $t$，周期・温度・張力の $T$，起電力・電場・エネルギーの $E$，仕事と仕事関数の $W$）は，添字か別の文字で区別して定義する。

| 分野 | 量と記号 |
|---|---|
| 力学 | 位置 $x$，速度 $v$，加速度 $a$，重力加速度の大きさ $g$，質量 $m$，力 $F$，垂直抗力 $N$，張力 $T$，静止摩擦係数 $\mu$，動摩擦係数 $\mu'$，ばね定数 $k$，仕事 $W$，仕事率 $P$，運動エネルギー $K$，位置エネルギー $U$，運動量 $p$，力積 $I$，反発係数 $e$，角速度 $\omega$，周期 $T$，振動数 $f$，万有引力定数 $G$ |
| 熱 | 絶対温度 $T$，熱量 $Q$，比熱 $c$，熱容量 $C$，圧力 $p$，体積 $V$，物質量 $n$，気体定数 $R$，内部エネルギー $U$，モル比熱 $C_{V}$，$C_{p}$，比熱比 $\gamma$，熱効率 $e$ |
| 波 | 変位 $y$，振幅 $A$，波長 $\lambda$，振動数 $f$，周期 $T$，波の速さ $v$，音速 $V$，屈折率 $n$，光の速さ $c$，焦点距離 $f$，物体・像までの距離 $a$，$b$ |
| 電磁気 | 電気量 $q$，$Q$，電場 $E$，電位 $V$，電気容量 $C$，誘電率 $\varepsilon$，電流 $I$，抵抗 $R$，抵抗率 $\rho$，起電力 $E$，内部抵抗 $r$，磁場 $H$，磁束密度 $B$，磁束 $\Phi$，透磁率 $\mu$，インダクタンス $L$，$M$，角周波数 $\omega$，インピーダンス $Z$ |
| 原子 | 電気素量 $e$，プランク定数 $h$，仕事関数 $W$，質量数 $A$，原子番号 $Z$，半減期 $T$ |

## 7. 用語

問題文の用語・表記があればそれに合わせる。下は手がかりが無いときの既定。

| 避ける | 使う |
|---|---|
| 熱力学第1法則 | 熱力学第一法則 |
| エネルギー保存則，運動量保存則 | 力学的エネルギー保存の法則，運動量保存の法則 |
| キルヒホッフ則 | キルヒホッフの第1法則（電流），第2法則（電圧） |
| 電荷保存 | 電気量保存の法則 |
| コンデンサ，キャパシタ | コンデンサー |
| はねかえり係数，電界，磁界 | 反発係数，電場，磁場 |
| 抗力（垂直抗力の意味で） | 垂直抗力（抗力は垂直抗力と摩擦力の合力） |

動詞も教科書に合わせる：力は「はたらく」，仕事は「する／される」，熱は「吸収する／放出する」，電荷は「たくわえられる」。

## 8. 描画できなくなる書き方（物理に固有のもの）

共通の規則は high-school-math-answers の `references/notation.md` 13節。

| 書いてはいけない | 代わり |
|---|---|
| 空欄の記号を数式に入れる（`\text{ア}=…`，`v_{\text{ウ}}`），日本語の添字 | 文で「アは …」。量には $v_{1}$ などの名前を付けて定義する |
| `3.0 m/s`（単位が斜体），`3.0\mathrm{m/s}`（空きがない） | `3.0\ \mathrm{m/s}` |
| `\si{}`，`\SI{}{}`，`\unit{}`，`\degree`，`\celsius`，`\ohm` | `\mathrm{}`，`^{\circ}`，`{}^{\circ}\mathrm{C}`，`\Omega` |
| `\bm{F}`，`\mathbf{F}`，`\vec{v_A}` | `\vec{F}`，`\vec{v}_{\mathrm{A}}` |
| `\dot{x}`，`\ddot{x}` | $v$，$a$ と文字でおく |
