## 1. 書体：斜体と立体

| 立体（`\mathrm{}`） | 斜体（そのまま） |
|---|---|
| 単位：$\mathrm{m}$，$\mathrm{kg}$，$\mathrm{N}$，$\mathrm{J}$ | 量記号：$m$，$v$，$F$，$T$，$V$，$I$，$R$ |
| 点・物体・端子の名前：$\mathrm{A}$，$\mathrm{P}$，$\mathrm{O}$ | 定数：$g$，$G$，$k$，$R$，$c$，$h$，$e$ |
| 元素記号，粒子の名前：$\mathrm{He}$，${}^{4}_{2}\mathrm{He}$ | 角：$\theta$，$\varphi$，$\alpha$ |
| 数字，$\sin$，$\cos$，$\log$ | 添字のうち量を表すもの：$v_{x}$，$C_{V}$ |
| 添字のうち名前を表すもの：$v_{\mathrm{A}}$ | |

- 同じ文字でも，点 $\mathrm{A}$ は立体，面積・振幅の $A$ は斜体。電流計の A，単位の $\mathrm{A}$ は立体。
- 問題文が筆記体風の $\ell$（`\ell`）を使っていればそれに合わせ，$l$ と混ぜない。

## 2. 単位

- SI を使う。数値と単位の間は空白1つ（`\ `）：`3.0\ \mathrm{m/s}` → $3.0\ \mathrm{m/s}$。
- 組立単位は斜線で書く：$\mathrm{m/s^{2}}$，$\mathrm{N/m}$，$\mathrm{J/(mol\cdot K)}$，$\mathrm{kg/m^{3}}$。斜線は1つだけ（$\mathrm{J/mol/K}$ と書かない）。積は `\cdot`：$\mathrm{N\cdot m}$。
- 角度は $30^{\circ}$（`30^{\circ}`。数値と ° の間は空けない）。弧度法は単位を付けないか $\mathrm{rad}$。セルシウス温度は $20\ {}^{\circ}\mathrm{C}$（`20\ {}^{\circ}\mathrm{C}`），絶対温度は $293\ \mathrm{K}$。
- 抵抗は $10\ \Omega$（`10\ \Omega`），接頭語つきは $2.0\ \mathrm{k\Omega}$，$1.0\ \mu\mathrm{F}$（`1.0\ \mu\mathrm{F}`），$500\ \mathrm{nm}$。
- **文字式には単位を付けない。** $v=\sqrt{2gh}$ と書き，$\sqrt{2gh}\ \mathrm{m/s}$ としない。問題文が「$v$〔m/s〕」のように単位を添えて量を定義していても，答の式には付けない。量の定義を引くときは「速さ $v$〔m/s〕」と亀甲括弧（または問題文の括弧）で書く。
- **数値計算の式は，両辺で単位の有無をそろえる。**

  良い例（数値にすべて単位を付けるか，最後の結果にだけ付けることを等号でつながずに示す）：

  $$\lambda=\dfrac{v}{f}=\dfrac{340\ \mathrm{m/s}}{500\ \mathrm{Hz}}=0.680\ \mathrm{m}$$

  または，単位を省いて計算し，結果を文で述べる：「$\dfrac{340}{500}=0.680$ より，$\lambda=0.680\ \mathrm{m}$ である。」

  悪い例：$\dfrac{340}{500}=0.680\ \mathrm{m}$（左辺は数，右辺は長さ）。
- 単位の換算は式に入る前に済ませる：「$16.0\ \mathrm{cm}=0.160\ \mathrm{m}$」。

## 3. 数値と有効数字

- **与えられた数値の有効数字に合わせて答える。** 掛け算・割り算は，有効数字の桁数が最も少ないものに合わせる。足し算・引き算は，末位が最も高いものに合わせる。
- **途中の計算は1桁多く持つ。** 丸めた値を次の小問に使わず，丸める前の値（または文字式）から計算し直す。例：$W=199.2\ \mathrm{J}$，$\Delta U=298.8\ \mathrm{J}$ のとき，$Q=\Delta U+W=498\ \mathrm{J}\fallingdotseq5.0\times10^{2}\ \mathrm{J}$（丸めた $2.0\times10^{2}$ と $3.0\times10^{2}$ を足しても同じになるとは限らない）。
- 最後に四捨五入し，有効数字がはっきり分かる形で書く：$5.0\times10^{2}\ \mathrm{J}$（$500\ \mathrm{J}$ では有効数字が分からない）。指数表記は `5.0\times10^{2}`。$1$ 以上 $10$ 未満の数 $\times10^{n}$。
- 末尾の 0 は有効数字なので落とさない（$2.0\ \mathrm{m}$ を $2\ \mathrm{m}$ と書かない）。
- 式の中の整数（$\dfrac{1}{2}mv^{2}$ の 2）や $\pi$ は有効数字に数えない。$\pi$，$\sqrt{2}$ の値は問題文の指示に従い，指示がなければ必要な桁より1桁多く（$\pi=3.14$，$\sqrt{2}=1.41$）取る。
- 丸めた結果への等号は $\fallingdotseq$（`\fallingdotseq`）。`\approx`，`\simeq` は使わない。
- 文字式で答える問題では，数値を持ち込まない（$g=9.8$ を勝手に代入しない）。分数は約分し，根号の中は簡単にし，分母の有理化は問題の解答例に合わせる（物理では $\dfrac{1}{\sqrt{2}}$ のままでもよい）。

## 4. 添字

| 種類 | 書き方 | 例 |
|---|---|---|
| 物体・点の名前 | 立体 | $v_{\mathrm{A}}$，$T_{\mathrm{B}}$，$I_{\mathrm{R}}$，$V_{\mathrm{PQ}}$ |
| 成分・変数 | 斜体 | $v_{x}$，$F_{y}$，$C_{V}$，$C_{p}$ |
| 番号・初期値 | 数字 | $v_{0}$，$T_{1}$，$R_{2}$ |
| 言葉の略 | 立体 | $v_{\mathrm{max}}$，$E_{\mathrm{k}}$（問題文にある場合） |

- **空欄の記号（ア，イ）や小問番号を添字にしない。** $v_{\text{ウ}}$ ではなく $v_{1}$ とおいて「この $v_{1}$ がウの答である」と書く。
- 日本語の添字（$W_{\text{正味}}$）は避け，$W'$ や $W_{0}$ とおいて「1サイクルで気体が外部にした正味の仕事を $W_{0}$ とする」と定義する。
- 衝突後の量はプライム（$v'$，$v_{\mathrm{A}}'$）。プライムつきの文字の2乗は `{v'}^{2}`。

## 5. ベクトル・成分・向き

- ベクトルは $\vec{v}$，$\vec{F}$，$\vec{a}$（`\vec{v}`）。太字は使わない。添字は矢印の外（`\vec{v}_{\mathrm{A}}`）。
- 大きさは $v$，$F$ と矢印なしで書く。「速さ $v$」「力の大きさ $F$」。
- 高校の物理では，ほとんどの式を**成分**か**大きさ**で書く。直線上の運動は，正の向きを決めて符号つきの数（速度 $v$）で表す。
- 「速度」は向きを含み（符号つき），「速さ」は大きさ（0 以上）。「加速度」と「加速度の大きさ」，「力」と「力の大きさ」も同じ。答がどちらを求めているかを確かめる。
- 向きは言葉で書く：「右向き」「鉛直下向き」「斜面に沿って上向き」「$x$ 軸の正の向き」「P から Q の向き」「紙面の裏から表の向き」「上から見て反時計回り」。
- 内積・外積の記号を使わない。仕事は $W=Fs\cos\theta$。ローレンツ力は大きさ $\lvert q\rvert vB$（速度と磁場が垂直のとき。なす角が $\theta$ なら $\lvert q\rvert vB\sin\theta$）と，フレミングの左手の法則による向き（負電荷は正電荷と逆向き）。右ねじの法則は電流がつくる磁場の向きに使い，力の向きには使わない。

## 6. 変化量 Δ と微小量

- 変化量は「後の値 − 前の値」：$\Delta U=U_{2}-U_{1}$（`\Delta U`）。減少したなら負になる。「減少量」を正の量として使うときは，そう断る。$\Delta$ と量記号の間は空けない。
- 平均の速度 $\bar{v}=\dfrac{\Delta x}{\Delta t}$，誘導起電力 $V=-N\dfrac{\Delta\Phi}{\Delta t}$，自己誘導 $V=-L\dfrac{\Delta I}{\Delta t}$。$\dfrac{dx}{dt}$ とは書かない（`scope.md`）。
- 「微小な時間 $\Delta t$ の間」「$\Delta t$ が十分小さいとき」と断って，$\Delta t$ の2次の項を無視する。無視する前に，何を無視するかを書く：「$(\Delta x)^{2}$ の項は $\Delta x$ の項に比べて十分小さいので無視すると」。
- 2つの $\Delta$ の積・商は括弧で誤解を防ぐ：$(\Delta x)^{2}$，$\dfrac{\Delta v}{\Delta t}$。

## 7. 近似

近似式は，**条件を書いてから**使う。条件を書かずに $\fallingdotseq$ でつなぐと，等式の誤りと区別が付かない。

| 条件 | 近似式 | 備考 |
|---|---|---|
| $\lvert x\rvert\ll1$ | $(1+x)^{n}\fallingdotseq1+nx$ | $n$ は実数。$\sqrt{1+x}\fallingdotseq1+\dfrac{x}{2}$，$\dfrac{1}{1+x}\fallingdotseq1-x$ はこの特別な場合 |
| $\lvert\theta\rvert\ll1$（$\theta$ は弧度法） | $\sin\theta\fallingdotseq\theta$，$\tan\theta\fallingdotseq\theta$ | したがって $\sin\theta\fallingdotseq\tan\theta$（ヤングの実験，単振り子） |
| $\lvert\theta\rvert\ll1$ | $\cos\theta\fallingdotseq1$ | $\cos\theta\fallingdotseq1-\dfrac{\theta^{2}}{2}$ は，問題文で与えられたときか，半角の公式 $1-\cos\theta=2\sin^{2}\dfrac{\theta}{2}$ から導いて使う |

書き方の型：

> $d\ll L$ であるから，$x=\dfrac{d}{L}$ とおくと $\lvert x\rvert\ll1$ である。$\lvert x\rvert\ll1$ のとき $(1+x)^{n}\fallingdotseq1+nx$ が成り立つから
> $$\sqrt{L^{2}+d^{2}}=L\Bigl(1+\dfrac{d^{2}}{L^{2}}\Bigr)^{\frac{1}{2}}\fallingdotseq L\Bigl(1+\dfrac{d^{2}}{2L^{2}}\Bigr)$$

- **何が 1 に比べて小さいか**を，文字でおいて示す（上の $x$）。長い式なら $\varepsilon=\cdots$ とおき $\lvert\varepsilon\rvert\ll1$ を確かめる。
- **項を落とすときは，主要な項との比で述べる。** 根号や括弧の中を主要な項（多くは定数項。$d^{2}$ など）でくくり，残りが「$\dfrac{x}{d}$ の1次」「$\dfrac{x}{d}$ の2次」のどれかを見て，「2次の微小量なので無視する」と書く。同じ次数の項どうし（1次の項と1次の項）を比べて一方を落とさない。その比較は，一方が 0 に近い配置では成り立たない。
- **何を何とみなしたかを，その場で1回書く。** 「角が微小なので，円弧の長さを弦の長さとみなす」「円弧に沿う変位を $y$ 軸方向の変位とみなす」「接線方向を $y$ 軸方向とみなす」。グラフの面積や公式に当てはめる前に書く。
- 問題文が近似式を与えているときは，その式だけを使う。与えられていない高次の近似（テイラー展開）を持ち込まない。
- 近似する前に厳密な式を書き，どの段階で近似したかが分かるようにする。途中で落とした項（$y^{2}$ など）は「$y^{2}$ の項を無視すると」と書く。
- 十分小さい・十分大きいは `\ll`，`\gg`。
- 2本の光だけの議論で全体の明暗を断定するなど，近似的な議論の結論は「…の目安になる」と強さを合わせる。

## 8. 主な量記号

問題文の記号が優先。問題文にない量を自分でおくときに，教科書の記号を使う。

| 分野 | 量と記号 |
|---|---|
| 力学 | 位置 $x$，変位 $\Delta x$，速度 $v$，初速度 $v_{0}$，加速度 $a$，重力加速度の大きさ $g$，質量 $m$，力 $F$，垂直抗力 $N$，張力 $T$，静止摩擦係数 $\mu$，動摩擦係数 $\mu'$，ばね定数 $k$，仕事 $W$，仕事率 $P$，運動エネルギー $K$，位置エネルギー $U$，運動量 $p$（$mv$ と書くほうが紛れない），力積 $I$（$F\Delta t$），反発係数 $e$，角速度 $\omega$，周期 $T$，回転数・振動数 $f$，万有引力定数 $G$ |
| 熱 | 絶対温度 $T$，セルシウス温度 $t$，熱量 $Q$，比熱 $c$，熱容量 $C$，圧力 $p$，体積 $V$，物質量 $n$，気体定数 $R$，内部エネルギー $U$，定積モル比熱 $C_{V}$，定圧モル比熱 $C_{p}$，比熱比 $\gamma$，熱効率 $e$，アボガドロ定数 $N_{\mathrm{A}}$，ボルツマン定数 $k$ |
| 波 | 変位 $y$，振幅 $A$，波長 $\lambda$，振動数 $f$，周期 $T$，波の速さ $v$，音速 $V$，屈折率 $n$，光の速さ $c$，焦点距離 $f$，レンズから物体・像までの距離 $a$，$b$ |
| 電磁気 | 電気量 $q$，$Q$，電場 $E$，電位 $V$，電気容量 $C$，誘電率 $\varepsilon$，電流 $I$，抵抗 $R$，抵抗率 $\rho$，起電力 $E$，内部抵抗 $r$，電力 $P$，磁場 $H$，磁束密度 $B$，磁束 $\Phi$，透磁率 $\mu$，自己インダクタンス $L$，相互インダクタンス $M$，角周波数 $\omega$，リアクタンス $X_{\mathrm{L}}$，$X_{\mathrm{C}}$，インピーダンス $Z$ |
| 原子 | 電気素量 $e$，プランク定数 $h$，仕事関数 $W$，光子のエネルギー $h\nu$，質量数 $A$，原子番号 $Z$，半減期 $T$ |

- **問題文の記号との衝突を避ける**（問題文の点・物体・定数の名前，選択肢・図の番号を先に拾い，自分でおく文字・式番号と重ねない。立体と斜体だけ，プライムの有無だけの区別も衝突とみなす）。物体 $\mathrm{F}$ がある問題で力を $F$ とおかない（$f$ にする）。$V$ が別の量として出る問題で，無関係な量を $V'$ としない（$v'$，$U$ などにする）。
- 「気体がした仕事」「された仕事」の記号は，答案の最初に1通り決めて宣言し，小問ごとに変えない（問題文が指定した記号があれば，それを優先する）。
- 1題の中で，時間の $t$ と温度の $t$，周期の $T$ と温度・張力の $T$，起電力・電場・エネルギーの $E$，仕事・仕事関数の $W$ が同時に出るときは，添字を付けるか別の文字にして区別し，定義を書く。
- 熱力学第一法則は，$W$ の定義で形が変わる。「気体が吸収した熱量を $Q$，気体が外部から**された**仕事を $W$ とすると $\Delta U=Q+W$」「気体が外部に**した**仕事を $W'$ とすると $Q=\Delta U+W'$」。どちらの仕事かを必ず言葉で定義する。問題文に定義があればそれに従う。

- **問題文の用語・表記に合わせる。** 問題文が「電荷」「蓄えられる」「はねかえり係数」「電界」と書いていれば，解答もそれに合わせる。上の表は，問題文に手がかりが無いときの既定である。
- 力は「はたらく」，仕事は「する／される」，熱は「吸収する／放出する」，電流は「流れる」，電荷は「たくわえられる」。
- 「静かに置く・放す」は初速度 0，「なめらかな」は摩擦なし，「軽い」は質量を無視，「十分時間が経過した」は定常状態（コンデンサーの電流 0，コイルの起電力 0）。問題文のこれらの語をどう読んだかを，式を立てるときに一言書く。

## 10. 描画できなくなる書き方（物理で起きやすいもの）

物理で起きやすいものを挙げる。数式の中に丸数字を入れない，φ は `\varphi`，ベクトルの添字は矢印の外（`\vec{e}_1`），も守る。ほかの一般的な規則が必要なら high-school-math-answers の `references/notation.md` 13節（任意）。

| 書いてはいけない | 代わり |
|---|---|
| `\text{ア}=mg\sin\theta`，`v_{\text{ウ}}`（空欄記号を数式に入れる） | 文で「アは $mg\sin\theta$」。量には $v_{1}$ などの名前 |
| `\vec{v_A}` | `\vec{v}_{\mathrm{A}}` |
| `3.0 m/s`（単位が斜体になる），`3.0\mathrm{m/s}`（空きがない） | `3.0\ \mathrm{m/s}` |
| `\si{}`，`\SI{}{}`，`\unit{}`，`\degree`，`\celsius`，`\ohm` | `\mathrm{}`，`^{\circ}`，`{}^{\circ}\mathrm{C}`，`\Omega` |
| `\bm{F}`，`\boldsymbol{F}`，`\mathbf{F}` | `\vec{F}` |
| `\dot{x}`，`\ddot{x}` | $v$，$a$ と文字でおく |
| `\approx`，`\simeq`，`\sim` | `\fallingdotseq` |
