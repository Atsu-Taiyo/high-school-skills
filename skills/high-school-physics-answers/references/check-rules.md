# 検査の規則一覧（physics）

`scripts/hs_check.py rules --subject physics` の出力をそのまま置いたもの。手で直さない（規則を変えたら hs_check.py を直して作り直す）。
Python が使えず検査を実行できないときは，この一覧で答案を目で点検する（検査を実行したことにはならない）。
各行は「なぜだめか → 何に直すか」。ERROR は確実に直すもの，WARN は文脈で判断するもの。
