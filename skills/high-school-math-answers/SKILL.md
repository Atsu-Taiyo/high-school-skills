# 高校数学の解答・解説を書く

## 目的

読者は高校生と，その答案を採点する先生である。高校生が教科書の知識だけで読めて，そのまま自分の答案として書いても減点されない解答・解説を作る。

大学以降の記号や定理を使えば短く書けることは多い。しかし，習っていない記号が1つあるだけで生徒はそこで読むのをやめるし，教科書にない定理を使った答案は入試で減点されうる。だから，数学的に正しいだけでは足りず，**道具・記号・言葉のすべてが高校の教科書の中にあること**を求める。

## 範囲

平成30年告示の学習指導要領（2022年度入学生から）に従う。

| 科目 | 内容 |
|---|---|
| 数学Ⅰ | 数と式（集合と命題を含む），図形と計量，2次関数，データの分析（外れ値，仮説検定の考え方） |
| 数学A | 図形の性質，場合の数と確率（条件付き確率，期待値），数学と人間の活動（約数と倍数，ユークリッドの互除法，1次不定方程式，$n$ 進法） |
| 数学Ⅱ | いろいろな式（複素数と方程式，式と証明），図形と方程式，指数関数・対数関数，三角関数，微分・積分の考え（整式の範囲） |
| 数学B | 数列（漸化式，数学的帰納法），統計的な推測（確率分布，二項分布，正規分布，区間推定，仮説検定），数学と社会生活 |
| 数学Ⅲ | 極限，微分法，積分法 |
| 数学C | ベクトル（平面，空間），平面上の曲線と複素数平面（2次曲線，媒介変数，極座標，ド・モアブルの定理），数学的な表現の工夫 |

旧課程との違いに注意する。ベクトルは数学C，複素数平面と2次曲線も数学C，期待値は数学A，整数は数学Aの「数学と人間の活動」にある。行列は「表現の工夫」で表として触れる程度で，積・逆行列・固有値は範囲外。

**問題の科目より先の道具を使わない。** 数学Ⅰの2次関数の最大・最小を微分で解かない。数学Ⅱの微分・積分は整式だけなので，積の微分や合成関数の微分を使わない。数学Aの期待値は定義どおりに計算し，数学Bの $E(X+Y)=E(X)+E(Y)$ を持ち込まない。科目が示されていないときは，問題の内容から最も早く解ける科目を推定し，その科目までの道具で解く。

## 記号

使ってよいのは教科書に出てくる記号だけである。迷ったら言葉で書く。言葉で書いて減点されることはない。

### 使わない記号と書き換え

| 使わない | 書き換え |
|---|---|
| 総乗の大きな $\Pi$（`\prod`） | $1\cdot 2\cdot 3\cdots n$，$n!$，あるいは具体的な積を書き並べる |
| $\forall$，$\exists$ | 「すべての実数 $x$ について」「…を満たす実数 $x$ が存在する」 |
| `\binom{n}{r}` | ${}_{n}\mathrm{C}_{r}$ |
| $\mathbb{N},\mathbb{Z},\mathbb{Q},\mathbb{R},\mathbb{C}$ | 「自然数」「整数」「有理数」「実数」「複素数」と言葉で書く（「$x$ は実数」） |
| $\land$，$\lor$，$\lnot$ | 「かつ」「または」，否定は「$p$ でない」または $\overline{p}$ |
| 外積 $\vec{a}\times\vec{b}$ | 両方に垂直なベクトルを $(x,y,z)$ とおき，内積が $0$ の連立方程式を解く |
| $\langle\vec{a},\vec{b}\rangle$，$\Vert\vec{a}\Vert$，太字 $\mathbf{a}$ | $\vec{a}\cdot\vec{b}$，大きさは絶対値記号，ベクトルは $\vec{a}$ |
| $\arcsin$，$\arctan$，$\sinh$，$\cosh$ | 角を $\theta$ とおき「$\tan\theta=2$ を満たす角」と書く |
| $\cot$，$\sec$，$\csc$ | $\dfrac{1}{\tan\theta}$，$\dfrac{1}{\cos\theta}$，$\dfrac{1}{\sin\theta}$ |
| $\lfloor x\rfloor$，$\lceil x\rceil$ | $[x]$ と書き「$[x]$ は $x$ を超えない最大の整数」と定義を添える |
| $\ln x$，$\exp(x)$ | $\log x$（底 $e$ は省略），$e^{x}$ |
| $e^{i\theta}$ | $\cos\theta+i\sin\theta$ |
| $\partial$，$\nabla$，$o(x)$，$O(x)$ | 範囲外。使う解法ごと避ける |
| $a\mid b$，$\gcd(a,b)$，$a\bmod b$ | 「$b$ は $a$ の倍数」「$a$ と $b$ の最大公約数」「$a$ を $b$ で割った余り」 |
| $P(B\mid A)$ | $P_{A}(B)$ |
| $\therefore$，$\because$，s.t.，iff，Q.E.D. | 「よって」「…であるから」「…を満たす」「…と同値」「（証明終）」 |

### 注意して使う記号

- $\Rightarrow$，$\iff$ は使ってよい。ただし $\iff$ は本当に同値なときだけ使う。式変形のつなぎに並べない。
- 合同式 $a\equiv b\pmod{m}$ は教科書では発展扱い。原則として「$3$ で割った余りで分類する」と書く。使うなら最初に定義を書く。
- $\sum$ は数学Bで習う。数学Ⅰ・A・Ⅱの問題では $a_1+a_2+\cdots+a_n$ と書き下す。
- 区間 $[a,b]$，$(a,b)$ は数学Ⅲだけ。ほかでは $a\leqq x\leqq b$ と書く。
- 重複順列は $n^{r}$ と書く（${}_{n}\Pi_{r}$ は使わない）。

単元ごとの記号（確率の $P(A)$，統計の $E(X)$ と $V(X)$，データの $\overline{x}$ と $s_x$ など）は `references/notation.md` にある。

## 用語

### 大学の言葉を高校の言葉に直す

| 避ける | 使う |
|---|---|
| 多項式 | 整式 |
| 線形，線型 | 1次（1次式，1次結合は「$s\vec{a}+t\vec{b}$ の形」） |
| ノルム，長さ（ベクトル） | 大きさ |
| スカラー | 実数 |
| 直交 | 垂直 |
| 正規化する | 同じ向きの単位ベクトルを求める |
| 写像，単射，全射 | 関数，対応。「異なる $x$ に異なる値が対応する」のように内容を書く |
| 一意に定まる | ただ1つに定まる |
| 狭義単調増加 | 常に増加する（数学Ⅲでは「単調に増加する」） |
| 凸関数，凹関数 | 下に凸，上に凸 |
| 上界，上限，有界 | 使わない。「$a_n<2$ がすべての $n$ で成り立つ」のように内容を書く |
| 剰余，法 | 余り，「$m$ で割った余り」 |
| 特性方程式，不動点 | 「$\alpha=p\alpha+q$ を満たす $\alpha$」と式で書く |
| テレスコーピング | 「途中の項が打ち消し合う」 |
| 一般性を失わず | 「対称性から $a\leqq b$ としてよい」と理由を書く |
| 不偏分散，$p$ 値 | 高校の分散は $n$ で割る。検定は棄却域で述べる |

### 言葉づかい

- 「自明」「明らか」「容易にわかる」を理由の代わりに使わない。理由を1行で書けるなら書き，書けないならそこは説明が要る箇所である。
- 「同様に」は，本当に文字を入れ替えるだけのときに限る。計算の中身が変わるなら省略しない。
- 「〜であればよい」は十分条件の言い方である。条件を求める問題では「〜となるための条件は」「必要十分条件は」と書く。
- 使った定理は名前を書く（「余弦定理により」「相加平均と相乗平均の大小関係により」「平均値の定理により」）。
- 文体は「である」体（教材本文で「です・ます」が指定されていればそれに従う）。句読点は「，」と「。」。

## 答案の構成

### 基本の形

```markdown
**方針**　何に着目し，どの道具で解くかを1〜2文で書く。

**解答**

（本文。日本語の文で式をつなぐ）

**答**　$x=2$
```

- 方針は解説・教材のときに書く。模範答案だけを求められたら省いてよい。
- 答は最後に独立した行で示す。問いの形に合わせる（値，範囲，個数，「…であることが示された」）。単位があれば付ける。
- 証明問題は「（証明終）」で結ぶ。
- 文書に既存の見出しや書式があれば，そちらに合わせる。

### 式を文でつなぐ

式を並べただけの答案は，どれが仮定でどれが結論か読み手にわからない。次の語で関係を示す。

| 場面 | 語 |
|---|---|
| 自分で文字や式を置く | 「…とおく」「…とする」 |
| 根拠を示す | 「…より」「…から」「…であるから」 |
| 結論に進む | 「よって」「ゆえに」「したがって」 |
| 言い換える | 「すなわち」 |
| 十分性を確かめる | 「逆に，このとき…」 |
| 場合を分ける | 「[1] $a<0$ のとき」「[2] $0\leqq a\leqq 2$ のとき」 |

### 必ず書くこと

- **条件を先に書く。** 対数の真数は正，底は正で $1$ でない。分母は $0$ でない。根号の中は $0$ 以上。式を変形する前に書く。
- **置き換えたら範囲を書く。** $t=\sin\theta$ とおいたら $-1\leqq t\leqq 1$。$t=2^{x}$ とおいたら $t>0$。
- **文字で割る前に $0$ かどうかを分ける。** 不等式で文字を掛ける，割るときは符号も分ける。
- **2乗したら元の式に戻って確かめる。** 同値でない変形をしたら，得た解が条件を満たすか確認する。
- **場合分けは漏れも重なりもなく。** 境界の値がどちらに入るかを決め，最後にまとめる。
- **必要条件で絞ったら十分性を確かめる。** 軌跡，恒等式の係数決定（数値代入法），整数問題，存在条件。「逆に，このとき条件を満たす」を計算つきで書く。
- **等号成立条件を書く。** 相加平均と相乗平均の大小関係や不等式で最大・最小を求めたら，等号が成り立つ値が実際にあることを示す。
- **答が常識に合うか見る。** 確率は $0$ 以上 $1$ 以下，面積・長さは正，個数は $0$ 以上の整数。

### 証明の型

数学的帰納法と背理法は，型を外すと点にならない。

数学的帰納法：
1. 「(i) $n=1$ のとき」左辺と右辺を別々に計算して成り立つことを示す。
2. 「(ii) $n=k$ のとき成り立つと仮定すると」仮定の式を書き，$n=k+1$ の場合を導く。**仮定を使った箇所を「仮定より」と明示する。**
3. 「(i)，(ii) より，すべての自然数 $n$ について…が成り立つ。」

背理法：「…でないと仮定する」→ 推論 →「これは…に矛盾する」→「したがって，…である」。

軌跡，解の配置，最大・最小，絶対値などの型は `references/answer-style.md` にある。

### 解説と答案を分ける

直感的な説明や，答案には書けない近道（「定数項を無視すると漸近線が見える」など）は理解の助けになるので書いてよい。ただし「**参考**」と見出しを付け，「記述式の答案には使えない」と断る。答案として通る議論と混ぜない。範囲外の定理による検算も同じ扱いにする。

**範囲外の記号は「参考」の中でも書かない。** 「参考：総乗記号を使うと…」として `\prod` の式を載せる，といったことをしない。記号の名前だけを紹介することも，依頼されない限りしない。生徒にとっては，参考欄であっても読めない式が増えるだけである。

## 単元別の要点

詳しくは `references/units.md`。ここには落としやすいものだけを挙げる。

- **数学Ⅰ**：2次関数の最大・最小は平方完成と，軸と定義域の位置関係で分ける。2次方程式の解の配置は判別式・軸・端点の値の3つ。$\sqrt{a^{2}}$ は絶対値。分散は $n$ で割る。三角比の角は度数法。
- **数学A**：${}_{n}\mathrm{C}_{r}$，${}_{n}\mathrm{P}_{r}$。確率は「同様に確からしい」根元事象を決めてから数える。条件付き確率は $P_{A}(B)$。整数は余りによる分類と互除法で書き，合同式に頼らない。
- **数学Ⅱ**：真数条件と底の条件。指数・対数の不等式は底と $1$ の大小で向きが変わる。三角関数は弧度法で，置き換えたら範囲。微分・積分は整式のみ。不定積分には「$C$ は積分定数」。面積は上下関係を確かめてから積分する。
- **数学B**：$a_n=S_n-S_{n-1}$ は $n\geqq 2$ でしか使えないので $n=1$ を別に確かめる。階差数列も同じ。漸化式の変形は式で示す。統計は母集団・標本・有意水準を言葉で明示する。
- **数学Ⅲ**：極限はロピタルの定理を使わず，式変形，はさみうちの原理，微分係数の定義で求める。$\dfrac{\infty}{\infty}$ や $\infty-\infty$ を式として書かない。増減表を書く。置換積分は積分区間の対応を表で示す。
- **数学C**：ベクトルは $\vec{a}$，$\overrightarrow{\mathrm{AB}}$。$s\vec{a}+t\vec{b}=s'\vec{a}+t'\vec{b}$ から係数を比べるときは「$\vec{a}\neq\vec{0}$，$\vec{b}\neq\vec{0}$，$\vec{a}$ と $\vec{b}$ は平行でない」を書く。複素数平面の偏角には範囲を付ける。

## 出力形式

**呼び出し側（利用者・アプリ・システム）が出力形式を指定したら，そちらを優先する。** LaTeX 文書，プレーンテキスト，特定ツールのマクロなどを求められたら，それに従う。その場合も，範囲・記号・用語・答案構成の規約は変わらない。

指定がなければ Markdown＋LaTeX で書く。数式は文中を `$...$`，別行を `$$...$$` とし，KaTeX でも MathJax でも描画できる命令だけを使う。

| 内容 | 書き方 |
|---|---|
| 組合せ，順列 | `{}_{n}\mathrm{C}_{r}`，`{}_{n}\mathrm{P}_{r}` |
| ベクトル | `\vec{a}`，`\overrightarrow{\mathrm{AB}}` |
| 点・図形の名前 | `\mathrm{A}`，`\triangle\mathrm{ABC}`，`\angle\mathrm{A}` |
| 分数 | `\dfrac{a}{b}`（指数や添字の中だけ `\frac`） |
| 不等号 | `\leqq`，`\geqq`（教科書の ≦ ≧。既存文書が `\leq` ならそれに合わせる） |
| 文中の極限・総和・積分 | `\displaystyle\lim_{x\to 0}`，`\displaystyle\sum_{k=1}^{n}`，`\displaystyle\int_{0}^{1}` |
| 定積分の計算 | `\Bigl[\,x^{2}\,\Bigr]_{0}^{1}`，被積分関数と `dx` の間に `\,` |
| 複数行の式 | `$$\begin{aligned} ... \end{aligned}$$`（`&=` でそろえ `\\` で改行） |
| 場合分けの結果，連立方程式 | `\begin{cases} ... \end{cases}` |
| 角度 | `30^{\circ}` |
| 式番号，選択肢の番号 | `\quad\cdots\cdots\text{①}`，`\text{①}` |
| 通貨のドル記号 | `\$` |

守ること：

- **説明文を数式の中に入れない。** 「よって，両辺を2乗すると」のような文は，`\text{}` や `aligned` の1行にせず，地の文の段落に書く。`\text{}` に入れてよいのは式番号や単位などの短い語だけ。
- **`\newcommand`，`\def` を使わない。** `\nCr` のような独自マクロは，描画する側で定義されているとは限らない。毎回そのまま書く。
- **`align`，`equation`，`eqnarray`，`\label`，`\tag`，`\ref` を使わない。** そろえるのは `aligned`，番号は上の式番号の書き方。
- **Markdown の表の中では縦線 `|` を数式に書かない。** 表の区切りと衝突する。絶対値は `\lvert x\rvert`，条件付き確率は $P_{A}(B)$ の形にする。表の外では `|x|` でよい。
- 長い式は別行（`$$`）にする。文中の式は短く保つ。
- 立体にするもの：点の名前，$\mathrm{C}$ と $\mathrm{P}$，単位。$\sin$，$\log$，$\lim$ は `\sin`，`\log`，`\lim` と命令で書く。微分の $d$ はイタリックのまま（`dx`）。

**「そのまま貼れる教材」「プリント」などを求められたときは，本文だけを出す。** 全体をコードブロック（` ```markdown ` など）で囲まない。囲むと数式が描画されず，そのまま貼れない。前置き・後書き・作業メモ（「そのまま貼れるように…」「補足です」「〜にしています」など）を本文に混ぜない。表記の判断を利用者に伝えたいときは，本文の外に分けて短く書く。

## 出力前の点検

書き終えたら，次を1つずつ確かめる。

1. **検算した。** 答を元の式や条件に代入した。場合分けの境界で値がつながっている。別の方法や具体的な数値でも確かめた。
2. **範囲内である。** 使った定理・公式は問題の科目までの教科書にある。怪しければ `references/forbidden.md` で確かめた。
3. **記号が教科書のものである。** `\prod`，`\forall`，`\exists`，`\binom`，`\mathbb`，`\land`，`\lor`，`\times`（外積），`\ln`，`\arcsin` などが残っていない。
4. **用語が高校のものである。** 「自明」「明らか」で理由を省いていない。
5. **条件を書いた。** 真数・分母・根号の条件，置き換えた文字の範囲，$0$ で割る場合の扱い，等号成立条件，十分性の確認。
6. **場合分けに漏れも重なりもない。**
7. **$\iff$ は同値のところだけに使った。**
8. **答が問いに答えている。** 求めるものの形，単位，「すべて求めよ」への対応。答は独立した行にある。
9. **数式が描画できる。** 指定された出力形式に従っている。指定がなければ Markdown＋LaTeX で，`$` の開きと閉じが対応している。`\newcommand` と `align` がない。表の中に `|` がない。数式の中に説明文がない。
10. **参考と答案が分かれている。** 答案に使えない説明には「参考」と断ってある。参考の中にも範囲外の記号がない。
11. **貼り付け用の教材・プリントを求められたときは，本文だけを出している。** 全体をコードブロックで囲んでいない。前置き・後書き・作業メモが本文に混ざっていない。利用者への連絡は本文の外に分けてある。
