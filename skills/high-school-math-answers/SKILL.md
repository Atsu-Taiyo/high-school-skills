# 高校数学の解答・解説を書く

## 目的

読者は高校生と，その答案を採点する先生である。教科書の知識だけで読めて，そのまま答案として書いても減点されない解答・解説を作る。数学的に正しいだけでは足りず，**道具・記号・言葉のすべてが，問題の科目までの高校の教科書の中にあること**を求める。

この SKILL.md の「答案の構成」「出力形式」「図」は，high-school-physics-answers からも参照される共通の正本である。

## 範囲

平成30年告示の学習指導要領（2022年度入学生から）に従う。科目ごとの内容と単元別の注意は `references/units.md`。旧課程との違いに注意する（ベクトル・複素数平面・2次曲線は数学C，期待値は数学A，行列の積・逆行列は範囲外）。

**問題の科目より先の道具を使わない。** 数学Ⅰの2次関数の最大・最小を微分で解かない。数学Ⅱの微分・積分は整式だけ（積・合成関数の微分を使わない）。数学Aの期待値は定義どおりに計算し，数学Bの $E(X+Y)=E(X)+E(Y)$ を持ち込まない。科目が示されていなければ，内容から最も早く解ける科目を推定し，その科目までの道具で解く。

**範囲外の定理・解法は高校の方法に書き換える。** 代表例：ロピタルの定理 → 式変形・はさみうちの原理・微分係数の定義。外積 → 求めるベクトルを $(x,y,z)$ とおき，内積が $0$ の連立方程式を解く。逆三角関数 → $x=\tan\theta$ とおく置換積分。一覧と書き換えの例は `references/forbidden.md`（正本）。

## 記号と用語

使うのは教科書に出てくる記号と言葉だけ。**迷ったら言葉で書く**（言葉で書いて減点されることはない）。

- 代表的な書き換え：`\binom` → ${}_{n}\mathrm{C}_{r}$，$P(B\mid A)$ → $P_{A}(B)$，$\forall$・$\exists$ → 「すべての…について」「…が存在する」，`\prod` → 積を書き並べる，$\ln x$ → $\log x$，$\mathbb{R}$ → 「実数」，$\therefore$ → 「よって」。一覧は `references/forbidden.md` 5節，単元ごとの正しい記号は `references/notation.md`。
- 科目で使える記号が変わるもの：$\sum$ は数学Bから（それ以前は書き下す），区間 $[a,b]$ は数学Ⅲだけ（ほかは不等式），合同式は発展（原則は「$3$ で割った余りで分類する」）。
- $\iff$ は本当に同値なときだけ使う。
- 大学の用語は高校の用語にする（多項式 → 整式，直交 → 垂直，一意に → ただ1つに）。一覧は `references/forbidden.md` 6節。
- 「自明」「明らか」を理由の代わりにしない。「同様に」は文字を入れ替えるだけのときに限る。条件を求める問題で「〜であればよい」（十分条件）と書かず，「〜となるための条件は」と書く。使った定理は名前を書く。
- **範囲外の記号は「参考」の中でも書かない**（名前だけの紹介も，依頼されない限りしない）。

## 答案の構成

```markdown
**方針**　何に着目し，どの道具で解くかを1〜2文で。

**解答**

（本文。日本語の文で式をつなぐ）

**答**　$x=2$
```

- 方針は解説・教材のとき書く。模範答案だけを求められたら省く。既存の文書に見出しや書式があればそちらに合わせる。
- 文体は「である」体（指定があればそれに従う），句読点は「，」「。」。式は「…とおく」「…より」「よって」「逆に，このとき」などの語でつなぐ。
- **解答本体に Markdown の箇条書き（`-`，`1.`）を使わない。** 並べるときは文でつなぐか，(i)(ii)・[1][2] で区切った文章にする。
- **答** は独立した行で，問いの形（値・範囲・個数・「…であることが示された」）に合わせ，1題の中で書式をそろえる。証明は「（証明終）」で結ぶ。
- **答案（**解答** と **答**）は **答** で閉じる。** **答** の直後に「（確認：…）」や補足を続けない。検算は出力前に自分で行い，本文に載せない。
- 解説・別解・参考は，**答** の後に見出し（**解説**，**別解**，**参考**）を付けた別の欄として置く。解説は解答にない着眼点だけを短く書き，解答の言い直しをしない。答案に書けない近道や直感的な説明は「**参考**」とし，記述式の答案には使えないと断る。
- **書く前に記号の衝突を調べる。** 問題文の点・関数・定数の名前，選択肢・条件・小問・図の番号を拾い，自分でおく文字・式番号と重ねない。立体と斜体だけ（点 $\mathrm{F}$ と量 $F$），プライムの有無だけ（無関係な $V$ と $V'$）の区別は衝突とみなす。

### 必ず書くこと

- **条件を先に書く**：真数は正・底は正で $1$ でない，分母 $\neq 0$，根号の中 $\geqq 0$。置き換えたら新しい文字の範囲（$t=2^{x}$ なら $t>0$）。
- **同値でない変形に注意する**：文字で割る・不等式に文字を掛ける前に $0$ や符号で分ける。2乗・分母を払う・文字の消去で失う条件は，得た解を元の条件で確かめる。
- **必要条件で絞ったら十分性を確かめる**（軌跡，恒等式の数値代入法，整数問題，存在条件）。「逆に，このとき…」を計算つきで書く。
- **場合分けは漏れも重なりもなく**，境界の値の所属を決めて最後にまとめる。
- **等号成立条件**（相加平均と相乗平均の大小関係など）を書き，最大・最小では値をとる変数の値を添える。
- **符号つきの量から大きさを答える**ときは，符号を決めた式を示してから絶対値をとる。
- 証明の型（数学的帰納法・背理法）は `references/answer-style.md` 6・7節の型どおりに書く。帰納法は始点（多くは $n=1$。$n\geqq 2$ から始まる命題では $n=2$）で両辺を別々に計算し，(ii) で仮定を使った箇所を明示する。

## 出力形式

**呼び出し側が出力形式を指定したら，それを優先する**（LaTeX 文書，プレーンテキストなど）。その場合も範囲・記号・答案構成の規約は変わらない。

指定がなければ Markdown＋LaTeX。文中は `$...$`，別行は `$$...$$`。KaTeX と MathJax の両方で描画できる命令だけを使う。

- 分数は `\dfrac`（指数・添字の中だけ `\frac`），不等号は `\leqq`・`\geqq`，組合せは `{}_{n}\mathrm{C}_{r}`，点の名前・単位は `\mathrm{}`。文中の $\lim$・$\sum$・$\int$ には `\displaystyle`。
- ベクトルは `\vec{a}`・`\overrightarrow{\mathrm{AB}}`，添字は矢印の外（`\vec{e}_1`）。φ は `\varphi`（`\phi` にしない。図の中も同じ字形）。
- 複数行は `$$\begin{aligned}...\end{aligned}$$`，場合分け・連立は `cases`。`align`・`equation`・`\tag`・`\label`・`\newcommand`・`\def` は使わない。
- **説明文を数式の中に入れない。** `\text{}` に入れてよいのは「かつ」「または」程度の短い語だけ。
- Markdown の表の中では数式に縦線 `|` を書かない（`\lvert x\rvert`）。
- 長い式は別行（`$$`）にし，`aligned` の1行が長ければ2行に分ける。ただし下の式番号の規則が優先する。

**式番号**（後で参照する式だけに付ける）：

- 書式は1通り：`　$x>1$　……①`（行頭に全角空白，文中数式，全角空白，「……」，番号）。**丸数字は数式の外**に書く（数式の中では KaTeX が警告を出す）。参照は地の文で「① より」。
- **番号つきの式がある導出（小問・場合分けの1区分）では，1行の式はすべてこの字下げの形でそろえる**（番号の要らない式は `　$式$`）。この導出では `$$` を複数行の `aligned`・`cases` だけに使い，「長い式は別行」より優先する。番号つきの式が無い導出は `$$` でよい。
- 系列は既定 ①②…。問題文に丸数字の選択肢・空欄・条件があれば (a)(b)…，それもあれば (i)(ii)…。1題の中で変えない。小問番号と同じ形の (1)(2) は使わない。

詳細（描画できなくなる書き方の一覧と式番号の例）は `references/notation.md` 13節。

**「そのまま貼れる教材」「プリント」を求められたら本文だけを出す。** 全体をコードブロックで囲まない（数式が描画されなくなる）。前置き・後書き・作業メモを本文に混ぜず，利用者への連絡は本文の外に分けて短く書く。

### 図

図は svg-figures スキルで作る。本文の側では次を守る（物理の解答も同じ）。

- **図番号を問題の図と衝突させない。** 問題文に図があるときは解答・解説の図を「解図1，解図2 …」とし，問題の図は「問題の図1」と書く。問題に図がなければ「図1」でよい。問題が「図を描き写して記入せよ」と求めた答の図も解図とし，「（問題の図5に記入したもの）」と添える。
- 画像は `![解図1](fig1.svg)`。代替テキストは図の名前だけの平文（`<`・`$`・`|`・式を入れない）。
- 図題と説明（記号の意味，線種の区別，「境界線は含まない」，描くのに使った具体的な値）は画像の直下の本文に1〜2文で書く。図中の文字の決まりは svg-figures に従う。
- 本文で使う記号（点・直線・角・ベクトル）は同じ字形で図に入れ，主変数の角は弧で示す。図中の点は本文で定義してから使い，図はそれを参照する文の直後に置く。

## 出力前の点検

1. **検算した**：答を元の式・条件に代入した。場合分けの境界で値がつながる。答が常識に合う（確率は $0$ 以上 $1$ 以下，長さは正）。検算の過程は出力にない。
2. **範囲内である**：問題の科目までの道具と記号だけ。参考の中にも範囲外の記号がない。怪しければ `references/forbidden.md`。
3. **論理が閉じている**：条件・置き換えの範囲・十分性・等号成立・場合分けの漏れ。$\iff$ は同値のところだけ。
4. **答が問いに答えている**：求めるものの形，「すべて求めよ」への対応，独立した **答** の行で閉じている。
5. **描画できる**：`$` の対応，数式の中に丸数字・説明文・表の `|` がない，式番号の書式と系列が1通りで問題文の番号と衝突しない。
6. **図と貼り付け**：図番号が問題の図と衝突しない。貼り付け用の依頼で本文をコードブロックで囲んでいない。
