# 高校数学の解答・解説を書く

## 目的

読者は高校生と，その答案を採点する先生である。教科書の知識だけで読めて，そのまま答案として書いても減点されない解答・解説を作る。数学的に正しいだけでは足りず，**道具・記号・言葉のすべてが，問題の科目までの高校の教科書の中にあること**を求める。

この SKILL.md の「答案の構成」「出力形式」「図」は，high-school-physics-answers からも参照される共通の正本である。

## 原則

1. **範囲**：問題の科目までの教科書にある道具だけで解く。科目の順序も範囲のうちで，先の科目の道具を持ち込まない。科目が示されていなければ，内容から最も早く解ける科目を推定する。範囲外の道具を思いついたら，高校の道具で同じ結論を導き直す。
2. **記号と言葉**：教科書にある記号・用語だけを使う。迷ったら言葉で書く。範囲外の記号は「参考」の中でも書かない。
3. **同値性**：式変形が同値かどうかを常に意識する。同値でない変形（2乗，分母を払う，文字で割る，文字の消去）をしたら，失った条件と増えた解を確かめる。必要条件で絞ったら十分性を示す。$\iff$ は本当に同値なときだけ使う。
4. **条件と範囲**：変形の前に，その式が意味を持つ条件（定義域）と，置いた文字の動く範囲を書く。場合分けは漏れも重なりもなく，境界の所属を決める。
5. **根拠**：各段階の根拠（使った定理の名前，効いている条件）を書き，「自明」「明らか」で省かない。根拠には結論に効く条件だけを挙げる。
6. **符号と向き**：符号つきの量から大きさを答える，向きを持つ量を置き換えるときは，符号・向きを決めた式を先に示す。
7. **答の形**：問いが求める形（値・範囲・個数・存在・最大最小とそのときの値・等号成立）で答える。

各原則の判断の基準と論理の型は `references/answer-style.md`，範囲外の道具・記号・用語と書き換えは `references/forbidden.md`，科目ごとの道具の境界と固有の約束は `references/units.md`，記号の正しい書き方は `references/notation.md`，体裁の見本は `references/examples.md`。

## 答案の構成

- 順序は **方針**（解説・教材のとき。着目点と道具を1〜2文）→ **解答** → **答**。模範答案だけを求められたら方針を省く。既存の文書に書式があればそれに合わせる。
- 文体は「である」体（指定があればそれに従う），句読点は「，」「。」。式は接続の言葉（おく，より，よって，逆に）でつなぎ，仮定と結論の関係を示す。
- **解答本体に Markdown の箇条書きを使わない。** 並べるときは文でつなぐか，(i)(ii)・[1][2] で区切った文章にする。
- **答** は独立した行に書き，1題の中で書式をそろえる。証明は「（証明終）」で結ぶ。
- **答案（**解答** と **答**）は **答** で閉じる。** **答** の直後に確認や補足を続けない。検算は出力前に自分で行い，本文に載せない。
- 解説・別解・参考は，**答** の後に見出しを付けた別の欄として置く。解説は解答にない着眼点だけを書き，解答を言い直さない。答案に書けない近道や直感的な説明は「**参考**」とし，記述式の答案には使えないと断る。
- **書く前に記号の衝突を調べる。** 問題文の名前と番号（点・関数・定数，選択肢・条件・小問・図）を拾い，自分でおく文字・式番号と重ねない。立体と斜体だけ，プライムの有無だけの区別は衝突とみなす。

## 出力形式

**呼び出し側が出力形式を指定したら，それを優先する。** その場合も範囲・記号・答案構成の規約は変わらない。

指定がなければ Markdown＋LaTeX。文中は `$...$`，別行は `$$...$$`。KaTeX と MathJax の両方で描画できる命令だけを使う（使えない命令の一覧は `references/notation.md` 13節）。

- 分数は `\dfrac`（指数・添字の中だけ `\frac`），不等号は `\leqq`・`\geqq`，点の名前・単位は `\mathrm{}`。文中の $\lim$・$\sum$・$\int$ には `\displaystyle`。
- ベクトルの添字は矢印の外（`\vec{e}_1`）。φ は `\varphi`（図の中も同じ字形）。
- 複数行は `aligned`，場合分け・連立は `cases`。`align`・`equation`・`\tag`・`\label`・`\newcommand`・`\def` は使わない。
- **説明文を数式の中に入れない**（`\text{}` は「かつ」「または」程度の語だけ）。Markdown の表の中では数式に縦線 `|` を書かない。
- 長い式は別行にする。ただし下の式番号の規則が優先する。

**式番号**（後で参照する式だけに付ける）：

- 書式は1通り：行頭に全角空白，文中数式，全角空白，「……」，番号（`　$式$　……①`）。**丸数字は数式の外**に書く。参照は地の文で「① より」。
- **番号つきの式がある導出（小問・場合分けの1区分）では，1行の式はすべてこの字下げの形でそろえる**。その導出の `$$` は複数行の `aligned`・`cases` だけに使う。番号つきの式が無い導出は `$$` でよい。
- 系列は既定が丸数字。問題文の番号と衝突するなら，問題文に現れない系列に切り替え（`notation.md` 13節），1題の中で変えない。小問番号と同じ形は使わない。

**そのまま貼れる教材・プリントを求められたら本文だけを出す。** 全体をコードブロックで囲まず，前置き・後書き・作業メモを本文に混ぜない。利用者への連絡は本文の外に分ける。

### 図

図は svg-figures スキルで作る。本文の側では次を守る（物理の解答も同じ）。

- **図番号を問題の図と衝突させない。** 問題文に図があるときは解答・解説の図を「解図1，解図2 …」とし，問題の図は「問題の図1」と書く。問題に図がなければ「図1」でよい。問題の図に記入して答える図も解図とし，どの図に記入したかを添える。
- 画像の代替テキストは図の名前だけの平文（`<`・`$`・`|`・式を入れない）。
- 図題と説明（記号の意味，線種の区別，境界を含むか，描くのに使った具体的な値）は画像の直下の本文に書く。
- 本文で使う記号は同じ字形で図に入れ，主変数の角は弧で示す。図中の点は本文で定義してから使い，図はそれを参照する文の直後に置く。

## 出力前の点検

1. **検算した**：答を元の式・条件に代入した。場合分けの境界で値がつながる。答が常識に合う。検算の過程は出力にない。
2. **原則を満たす**：範囲（参考の中の記号も），同値性と十分性，条件と範囲，根拠，符号と向き，答の形。
3. **描画できる**：`$` の対応，数式の中に丸数字・説明文・表の `|` がない，式番号の書式と系列が1通りで問題文の番号と衝突しない。
4. **体裁**：答案が **答** で閉じ，図番号が問題の図と衝突せず，貼り付け用の依頼で本文をコードブロックで囲んでいない。
