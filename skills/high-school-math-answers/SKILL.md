# 高校数学の答案を書く

## 目的

高校数学の答案らしい文章を書く。採点する先生が読んで，論理に切れ目がなく，そのまま答案として減点されないものにする。数学的に正しいだけでは足りず，**道具・記号・言葉のすべてが，問題の科目までの高校の教科書の中にあること**を求める。

**求められない限り，方針・解説・別解・参考は書かず，解答と答だけを書く。**

**記号と書式の細かい規則は検査が教える。書いたら必ず run する**（「検査を回す」）。この本文には，検査では判定できないことだけを書く。

## 範囲

平成30年告示の学習指導要領（2022年度入学生から）に従う。科目ごとの内容と単元別の注意は `references/units.md`。旧課程との違いに注意する（ベクトル・複素数平面・2次曲線は数学C，期待値は数学A，行列の積・逆行列は範囲外）。

**問題の科目より先の道具を使わない。** 数学Ⅰの2次関数の最大・最小を微分で解かない。数学Ⅱの微分・積分は整式だけ（積・合成関数の微分を使わない）。数学Aの期待値は定義どおりに計算し，数学Bの $E(X+Y)=E(X)+E(Y)$ を持ち込まない。科目が示されていなければ，内容から最も早く解ける科目を推定し，その科目までの道具で解く。

**範囲外の定理・解法は，思いついても高校の方法に書き換える。** 判断の基準と，使ってよいもの・条件つきで使えるもの・書き換えの例は `references/forbidden.md`。範囲外の方法は検算に使ってよいが，答案には書かない（名前だけの紹介もしない）。

## 参照ファイル

| ファイル | 読むとき |

## 記号と用語

使うのは教科書に出てくる記号と言葉だけ。**迷ったら言葉で書く**（言葉で書いて減点されることはない）。

- 科目で使える記号が変わるもの：$\sum$ は数学Bから（それ以前は書き下す），区間 $[a,b]$ は数学Ⅲだけ（ほかは不等式），合同式は発展（原則は「$3$ で割った余りで分類する」）。
- 同値記号は本当に同値なときだけ使う。
- 「同様に」は文字を入れ替えるだけのときに限る。条件を求める問題では「〜となるための条件は」と書く。使った定理は名前を書く。

## 答案の構成

- 既存の文書に見出しや書式があればそちらに合わせる。文体は「である」体（指定があればそれに従う）。
- 式は「…とおく」「…より」「よって」「逆に，このとき」などの語でつなぐ。1つの段落には1つの推論を入れる。並べるときは文でつなぐか，(i)(ii)・[1][2] で区切った文章にする。
- 答は問いの形（値・範囲・個数・「…であることが示された」）に合わせ，1題の中で書式をそろえる。証明は「（証明終）」で結ぶ。検算は出力前に自分で行い，本文に載せない。
- **書く前に記号の衝突を調べる。** 問題文の点・関数・定数の名前，選択肢・条件・小問・図の番号を拾い，自分でおく文字・式番号と重ねない。立体と斜体だけ（点 $\mathrm{F}$ と量 $F$），プライムの有無だけ（無関係な $V$ と $V'$）の区別は衝突とみなす。

### 必ず書くこと

- **条件を先に書く**：真数は正・底は正で $1$ でない，分母 $\neq 0$，根号の中が $0$ 以上。置き換えたら新しい文字の範囲（$t=2^{x}$ なら $t>0$）。
- **同値でない変形に注意する**：文字で割る・不等式に文字を掛ける前に $0$ や符号で分ける。2乗・分母を払う・文字の消去をしたら，得た値を元の式に代入して確かめる行を答案に書く（省かない）。これは検算ではなく答案の論理の一部である。
- **必要条件で絞ったら十分性を確かめる**（軌跡，恒等式の数値代入法，整数問題，存在条件）。「逆に，このとき…」を計算つきで書く。
- **場合分けは漏れも重なりもなく**，境界の値の所属を決めて最後にまとめる。
- **等号成立条件**（相加平均と相乗平均の大小関係など）を書き，最大・最小では値をとる変数の値を添える。
- **符号つきの量から大きさを答える**ときは，符号を決めた式を示してから絶対値をとる。
- 証明の型（数学的帰納法・背理法）は `references/answer-style.md` 6・7節の型どおりに書く。帰納法は始点（多くは $n=1$。$n\geqq 2$ から始まる命題では $n=2$）で両辺を別々に計算し，(ii) で仮定を使った箇所を明示する。

## 出力形式

**呼び出し側が出力形式を指定したら，それを優先する**（LaTeX 文書，プレーンテキストなど。検査は `--format other`）。その場合も範囲・答案構成の規約は変わらない。指定がなければ Markdown＋LaTeX で，KaTeX と MathJax の両方で描画できる命令だけを使う。

- 長い式は別行にし，複数行の式の1行が長ければ2行に分ける。
- 式番号は後で参照する式だけに付け，参照は地の文で「① より」。系列は問題文の番号（選択肢・空欄・条件・小問）と衝突しないものを選び，1題の中で変えない。
- 「そのまま貼れる形で」と求められたら本文だけを出す。前置き・後書き・作業メモを本文に混ぜず，利用者への連絡は本文の外に分けて短く書く。

### 図

図は svg-figures スキルで作る。本文の側では次を守る。

- 問題文に図があるときは解答の図を「解図1，解図2 …」とし，問題の図は「問題の図1」と書く。問題が「図を描き写して記入せよ」と求めた答の図も解図とし，「（問題の図5に記入したもの）」と添える。
- 図題と説明（記号の意味，線種の区別，「境界線は含まない」，描くのに使った具体的な値）は画像の直下の本文に1〜2文で書く。図中の文字の決まりは svg-figures に従う。
- 本文で使う記号（点・直線・角・ベクトル）は同じ字形で図に入れ，主変数の角は弧で示す。図中の点は本文で定義してから使い，図はそれを参照する文の直後に置く。

## 検査を回す

**書いたら必ず検査を run する。** 記号・命令・書式（数式の区切り，式番号，答の行など）・範囲外の語の規則はこの検査が正本で，出力の各行が「なぜだめか → 何に直すか」を示す。`S` はこの SKILL.md のフォルダ（Claude Code では `${CLAUDE_SKILL_DIR}`，Codex の `.agents/skills/…` などでは読み込んだ SKILL.md の場所）。

```sh
python3 "$S/scripts/hs_check.py" run --subject math --final answer.md --problem problem.md
python3 "$S/scripts/hs_check.py" verify --final answer.md
```

ファイルを作らないときは `--final -`（標準入力）。

1. `run` の出力の1行目に従う。候補を1つずつ答案と照らし，当たっているものだけを1回でまとめて直す。WARN は文脈で決める。検査を消すためだけの言い換えはしない。範囲外の語が出たら，語を変えるのでなく解き方を高校の方法に書き換える。
2. 直したら `run` をもう一度実行し，その後は本文を変えない。
3. 提出の直前に，本文を変えずに `verify` を1回実行する。合わなければ `run` と `verify` をやり直す。

検査が見るのは機械的に判定できることだけで，正しさの合格ではない（下の点検は省かない）。答案と同じフォルダの図には svg-figures の lint もかかる。シェルで Python が使えない環境（アプリ内の AI など）では，`references/check-rules.md`（同じ規則の一覧）で目視し，検査は実行していないと報告する。

検査の結果は答案に書かない。返答では本文の後に `---` で区切って「検査：ERROR 0 件・WARN 1 件（残した理由）」の1行だけを添える（本文だけを求められたら聞かれたときに伝える）。`verify` に渡すのは区切りより前の本文。

## 出力前の点検

1. **検算した**：答を元の式・条件に代入した。場合分けの境界で値がつながる。答が常識に合う（確率は $0$ 以上 $1$ 以下，長さは正）。検算の過程は出力にない（同値でない変形の後の確かめは答案に書いた）。
2. **範囲内である**：問題の科目までの道具と記号だけ。怪しければ `references/forbidden.md`。
3. **論理が閉じている**：条件・置き換えの範囲・十分性・等号成立・場合分けの漏れ。同値記号は同値のところだけ。
4. **答が問いに答えている**：求めるものの形，「すべて求めよ」への対応。頼まれていない方針・解説・別解・参考がない。
5. **検査を run し，最後に verify した**（できない環境では check-rules.md で目視した）。
