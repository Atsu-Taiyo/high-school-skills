# 科目の範囲と固有の約束

科目ごとの「使える道具の境界」と，原則からは導けない教科書の約束をまとめる。条件・同値性・十分性・場合分けなど，SKILL.md の原則から導ける注意はここに書かない。

## 科目と内容

平成30年告示の学習指導要領（2022年度入学生から）。

| 科目 | 内容 |
|---|---|
| 数学Ⅰ | 数と式（集合と命題を含む），図形と計量，2次関数，データの分析（外れ値，仮説検定の考え方） |
| 数学A | 図形の性質，場合の数と確率（条件付き確率，期待値），数学と人間の活動（約数と倍数，ユークリッドの互除法，1次不定方程式，$n$ 進法） |
| 数学Ⅱ | いろいろな式（複素数と方程式，式と証明），図形と方程式，指数関数・対数関数，三角関数，微分・積分の考え（整式の範囲） |
| 数学B | 数列（漸化式，数学的帰納法），統計的な推測（確率分布，二項分布，正規分布，区間推定，仮説検定），数学と社会生活 |
| 数学Ⅲ | 極限，微分法，積分法 |
| 数学C | ベクトル（平面，空間），平面上の曲線と複素数平面（2次曲線，媒介変数，極座標，ド・モアブルの定理），数学的な表現の工夫 |

旧課程との違い：ベクトル，複素数平面，2次曲線は数学C。期待値は数学A。整数は数学Aの「数学と人間の活動」。行列は「表現の工夫」で表として触れる程度で，積・逆行列・固有値は範囲外。

## 道具の境界

原則：**問題の科目より後で習う道具は使わない。** 判断に迷いやすい境界を挙げる。

| 科目 | まだ使えないもの |
|---|---|
| 数学Ⅰ | 微分，加法定理・2倍角（$15^{\circ}$ などの三角比は図形から），弧度法，$\sum$，正規分布・棄却域（仮説検定は考え方を言葉で） |
| 数学A | $\sum$（書き下す），点と直線の距離の公式（数学Ⅱ），$E(X+Y)=E(X)+E(Y)$（期待値は定義どおり），座標・ベクトルによる図形の解法（その単元を学んだ後の問題に限る） |
| 数学Ⅱ | 整式以外の関数の微分・積分，積・商・合成関数の微分（展開してから微分する）。3次方程式の解と係数の関係は発展なので導いてから使う |
| 数学B | 極限 |
| 数学Ⅲ | 広義積分（定積分の極限として書く），微分方程式（誘導がなければ使わない） |
| 数学C | 外積，平面の方程式，点と平面の距離の公式，$e^{i\theta}$ |

範囲外の定理・記号・用語の一覧と書き換えは `forbidden.md`。

## 固有の約束

教科書の定義・書き方として決まっていて，原則からは導けないもの。

| 単元 | 約束 |
|---|---|
| データの分析 | 分散は $n$ で割る（不偏分散，$t$ 分布，$p$ 値は使わない）。四分位数は中央値で上下に分け，個数が奇数なら中央値はどちらにも入れない。外れ値は $Q_{1}-1.5(Q_{3}-Q_{1})$ 以下または $Q_{3}+1.5(Q_{3}-Q_{1})$ 以上 |
| 統計的な推測 | 正規分布表を使ったことを書く。母平均の信頼度 $95\%$ の信頼区間は $\overline{X}\pm1.96\cdot\dfrac{\sigma}{\sqrt{n}}$。検定は帰無仮説・対立仮説・有意水準・棄却域・判定・結論の順に書き，両側（$\lvert Z\rvert\geqq1.96$）か片側（$Z\geqq1.64$）かを対立仮説から選ぶ。「棄却されない」を「帰無仮説が正しい」と書かない |
| 三角関数 | 一般角には「$n$ は整数」を添える。合成の角 $\alpha$ は $\cos\alpha$，$\sin\alpha$ の値で定める。3倍角・和と積の公式は加法定理から導いて使う |
| 整数 | 1次不定方程式の一般解は「$a$ と $b$ は互いに素であるから」と述べて書き，「$k$ は整数」を添える。文字が整数であることを置くたびに書く |
| 微分・積分 | 不定積分には「$C$ は積分定数」。$\displaystyle\int\dfrac{1}{x}\,dx=\log\lvert x\rvert+C$。置換積分は積分区間の対応を表で示す。回転体の体積は $\pi\displaystyle\int y^{2}\,dx$（パップス・ギュルダンの定理は使わない） |
| 数列 | 漸化式 $a_{n+1}=pa_{n}+q$ は「$\alpha=p\alpha+q$ を満たす $\alpha$」を用いて変形する（特性方程式の語は使わない） |
| ベクトル | 係数比較の前に「$\vec{a}\neq\vec{0}$，$\vec{b}\neq\vec{0}$，$\vec{a}$ と $\vec{b}$ は平行でない」（空間では「4点は同じ平面上にない」）と書く |
| 複素数平面 | 極形式は $r>0$ で，偏角の範囲を書く |
