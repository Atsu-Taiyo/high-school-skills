# 答案作法

SKILL.md の「原則」を，判断の基準と答案の型で補う。答案の形・式番号・図は SKILL.md が正本。

## 1. 論理の原則と判断の基準

### 同値性

- **基準**：変形のたびに「逆にたどれるか」を問う。たどれない変形（2乗する，分母を払う，文字で割る，文字や媒介変数を消去する，対数をとる）は，失った条件を先に書くか，得た解を元の条件で確かめる。自信がなければ「よって」でつなぎ，最後に確かめる。
- 必要条件で候補を絞る解き方（軌跡，恒等式の数値代入法，整数問題，存在条件）では，候補が条件を満たすこと（十分性）を「逆に，このとき…」と計算つきで示す。
- 言い分け：「〜となるための条件は」「必要十分条件は」は同値，「〜であればよい」は十分条件，「〜が必要である」は必要条件。条件を求める問題で十分条件の言い方をしない。「すべての」と「ある」，「かつ」と「または」も，どちらを示しているかを文で書く。

### 条件と範囲

- **基準**：式に現れる各部分が意味を持つ条件（定義域）と，自分で置いた文字の動く範囲を，変形の前に書く。あとから書くと，解を捨てる根拠が弱くなる。
- 置き換えたら，新しい文字の範囲を元の範囲から求める（範囲は答に直結する）。
- 不等式に文字を掛ける・割るときは，その符号で場合を分けるか，符号が決まる理由を書く。
- 例：$t=2^{x}$ とおいたら，$t$ の範囲 $t>0$ を書いてから $t$ の式を解く。

### 場合分け

- 何で分けるかを最初に述べ，[1][2]… の番号を付ける（(i)(ii) は帰納法の段に使う）。境界の値はどれか1つに入れ，等号の付け方をそろえ，最後にまとめる。
- 連続する量なら，境界で隣の場合の値と一致するか検算する。

### 根拠

- 使った定理・公式は名前を挙げ，その定理が使える条件（正の数，連続，微分可能，独立）を確かめて書く。
- 「同様に」は文字を入れ替えるだけのときに限る。図から読み取ったことは計算で裏付ける。
- 同じ根拠を繰り返さない。何度も使う事実は初出で番号を付け，以後は番号で引く。

### 評価と実現（最大・最小，不等式）

- **基準**：「この値以上（以下）」（評価）と「この値をとる場合がある」（実現）の両方を示して初めて最大・最小と言える。等号成立条件はこの実現である。端点を含まない区間では最大・最小が無いことがある。
- 狭義の不等号を極限値との比較で言うときは，極限から直接言えるのは等号つきまでなので，途中の点を1つはさんで狭義を示す。
- 増減表・グラフで言えることを文章で言い直さない。補助の関数で調べたなら，元の関数の行も表に入れる。

### 符号と向き

- 符号つきの量（座標，成分）から長さ・大きさを答えるときは，符号を決めた式を示してから絶対値をとる。
- 向きを持つ量を「大きさ × 単位ベクトル」などに置き換えるときは，向きが一致する理由を述べる。

## 2. 答案の型

型を外すと点にならない形式。

**数学的帰納法**（示す命題を (A) とする）

> (i) 始点（多くは $n=1$）のとき，左辺と右辺を別々に計算して (A) が成り立つことを示す。
> (ii) $n=k$ のとき (A) が成り立つと仮定すると（仮定の式に番号）…，$n=k+1$ のときも成り立つ。仮定を使った箇所に「① より」と書く。
> (i)，(ii) より，すべての（始点以上の）自然数 $n$ について (A) は成り立つ。（証明終）

始点が $n=2$ なら (i) は $n=2$。「$n=k$，$k+1$ で成り立つと仮定して $n=k+2$」の型なら (i) で2つの値を示す。どの型かを最初に述べる。(ii) は示したい式の一方の辺から出発する。

**背理法**：「…でないと仮定する」→ 推論 →「これは…に矛盾する」（何と矛盾するかを名指す）→「したがって，…である」。結論の否定を正しく作る。**対偶**：「対偶『…』を証明する」→ 証明 →「対偶が真であるから，もとの命題も真である」。

**軌跡**：条件を満たす点を $\mathrm{P}(x,y)$ とおき，条件を式にして図形を得る →「逆に，この図形上の任意の点は条件を満たす」→ 除外点を調べる → 図形の名前で答える。

## 3. 答の書き方

| 問いの形 | 答の形 |
|---|---|
| 値・すべて求めよ | 全部を並べる |
| 範囲 | 不等式 |
| 個数・場合の数 | 単位（個，通り）を付ける |
| 最大値・最小値 | そのときの変数の値とともに |
| 方程式・軌跡・領域 | 式の形，図形の名前，除外点・境界の扱い |
| 証明 | 結論の文と「（証明終）」 |
| 場合分けのある答 | すべての場合をまとめて |
| 選択肢 | 番号と内容の両方 |

- 求める量に名前（記号）があれば「記号 $=$ 式」，なければ値だけ，のどちらかに1題の中でそろえる。
- 分母は有理化し，分数は約分し，根号の中は簡単にする。近似値を求められていなければ $\pi$，$\sqrt{2}$ などは残す。

## 4. 解説を書くとき

- 解答にない着眼点（最初の一手の理由，誤りやすい所，問題の誘導の意図）だけを書く。解答で述べたことを言い直さない。
- 途中式は1段階ずつ示す。本解はその単元の標準的な方法にし，別解は見出しで分ける。
- 誤答に触れるなら「よくある誤り」と見出しを付け，どこが誤りかを述べる。
- 厳密さは教科書に合わせる（教科書が直観で扱う所はその程度で，答案の論理はごまかさない）。
- 検算・確認を本文に載せない。理解の助けになる数値の確かめだけは「参考」に短く置いてよい。

## 5. 減点されやすい書き方

| 書き方 | 原則 |
|---|---|
| 式だけが並び，仮定と結論の関係が分からない | 根拠：接続の言葉でつなぐ |
| 等しくないものを $=$ でつなぐ，1本の等式の途中に別の式が混ざる | 同値性：1本の等式の連鎖は同じものの変形だけ |
| $\dfrac{\infty}{\infty}$，$\infty-\infty$ を式として書く | 記号：状況を言葉で書く |
| 条件を満たさない解を理由なく捨てる | 条件と範囲：どの条件に反するかを書く |
| 「明らか」「同様に」で根拠を省く | 根拠 |
| 答が本文に埋もれている | 答の形：独立した **答** の行 |
