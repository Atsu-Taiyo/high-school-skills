# 答案作法

採点者は，答が合っているかだけでなく，そこに至る論理が切れ目なく書かれているかを見る。解説も同じで，生徒は書かれていない行間を自分では埋められない。ここでは，つなぎの言葉，論理の表現，問題の型ごとの書き方をまとめる。

## 1. 全体の形

1. **方針**（解説のとき）。着目点と道具を1〜2文。
2. **解答**。設定（文字をおく，条件を書く）→ 計算と推論 → 結論。
3. **答**。独立した行に書く。

長い解答は，(1)(2) の小問や [1][2] の場合分けで区切る。1つの段落には1つの推論を入れる。自分でおいた文字は，おいた場所で定義する。

箇条書きを使わないこと，記号の衝突の調べ方，答で閉じることは SKILL.md「答案の構成」が正本である。

## 2. つなぎの言葉

| 働き | 語 | 例 |
|---|---|---|
| 文字・式を導入する | とおく，とする，と表す | 「$t=2^{x}$ とおくと，$t>0$ である。」 |
| 根拠を示す | より，から，であるから，ので | 「① より」「$a>0$ であるから」 |
| 定理を使う | により，を用いると | 「余弦定理により」 |
| 結論に進む | よって，ゆえに，したがって | 「よって，$x=2$」 |
| 言い換える | すなわち，つまり | 「$x-1>0$，すなわち $x>1$」 |
| 条件を加える | このとき，ここで，ただし | 「ここで，$t>0$ であるから」 |
| 逆を確かめる | 逆に | 「逆に，$a=1$ のとき」 |
| 並べる | また，さらに，一方 | |
| 場合を分ける | のとき，の場合 | 「[1] $a<0$ のとき」 |
| まとめる | 以上から，[1]〜[3] より | 「以上から，求める最小値は」 |
| 代入・計算する | に代入すると，を整理すると，両辺を…すると | 「② を ① に代入すると」 |

「よって」「ゆえに」「したがって」は同じ意味である。同じ語が3回続いたら入れ替えるとよいが，意味を変えてはいけない。「より」は根拠の後ろに付き（「① より」），「よって」は文の頭に付く。

後で使う式には番号を付け，「上の式より」ではなく「① より」と引く（書式と系列は SKILL.md「出力形式」と `notation.md` 13節）。

**同じ根拠を繰り返さない。** 何度も使う事実（「$g(x)>0$」など）は，初出で示して式番号を付け，以後は「① より」と番号で引く。方針・解答・解説で同じ文を繰り返さない。

## 3. 論理の表現

**必要条件と十分条件を言い分ける。**

- 「〜となるための条件は」「〜であるための必要十分条件は」：同値な条件を求めるとき。
- 「〜であればよい」「〜とすれば成り立つ」：十分条件を1つ示すとき。条件を求める問題でこう書くと，必要性を示していないことになる。
- 「〜であることが必要である」：必要条件で絞るとき。あとで十分性を確かめる。

**$\iff$ は同値のときだけ。** 式変形を $\iff$ でつなぐのは，すべての段階が逆にもたどれるときだけにする。2乗する，分母を払う，対数をとる，文字を消去する，といった変形は条件を付けないと同値にならない。自信がなければ「よって」でつなぎ，最後に解を確かめる。

**「すべての」と「ある」。** 「すべての実数 $x$ について $f(x)>0$」と「$f(x)>0$ を満たす実数 $x$ が存在する」は別の主張である。どちらを示しているのかを文で書く。「任意の」は「すべての」と同じ意味で使ってよい。

**「かつ」と「または」。** 連立不等式の解は「かつ」，場合分けの結果を合わせるときは「または」。$x<1,\ 3<x$ のようにコンマで並べたものは「または」の意味になる。紛らわしいときは言葉で書く。

**主語を明示する。** 「これは」「それは」が何を指すのか迷う文は，式番号や名前で言い直す。

## 4. 条件と範囲

式を変形する前に書く。あとから書くと，条件を満たさない解を捨てる根拠が弱くなる。

| 場面 | 書くこと |
|---|---|
| 対数 $\log_{a}M$ | 真数 $M>0$。底に文字があれば $a>0$，$a\neq 1$ |
| 分数式 | 分母 $\neq 0$ |
| 無理式 $\sqrt{A}$ | $A\geqq 0$。$\sqrt{A}=B$ なら $B\geqq 0$ も |
| 置き換え | 新しい文字の範囲。$t=\sin\theta+\cos\theta$ なら $-\sqrt{2}\leqq t\leqq\sqrt{2}$ |
| 文字で割る | $0$ でないことを示すか，$0$ の場合を分ける |
| 不等式に文字を掛ける | 符号で場合を分ける |
| 両辺を2乗する | 両辺が $0$ 以上であることを確かめる。そうでなければ得た解を元の式で確かめる |
| 三角形の辺・角 | 辺は正，角は $0^{\circ}$ より大きく $180^{\circ}$ より小さい。三角形の成立条件 |
| 2次方程式・2次関数 | $x^{2}$ の係数が文字なら $0$ の場合を分ける |
| 数列 | $n$ の範囲（$n\geqq 2$ でしか成り立たない式に注意） |
| 確率・個数 | 文字が表す個数は $0$ 以上の整数 |

## 5. 型：場合分け

- 何で分けるかを最初に言う。「軸 $x=a$ と定義域 $0\leqq x\leqq 2$ の位置関係で場合を分ける。」
- [1]，[2]，[3] と番号を付ける。(i)(ii) は数学的帰納法で使うので，場合分けには [1][2] を使うと混ざらない。
- 境界の値は必ずどれか1つに入れる。$a<0$，$0\leqq a\leqq 2$，$2<a$ のように，等号の付け方をそろえる。
- 最後にまとめる。答を `cases` で書くときは，条件を式だけで書き，日本語を入れない。最小値を $m$ とすると

$$m=\begin{cases}3 & (a<0)\\-a^{2}+3 & (0\leqq a\leqq 2)\\-4a+7 & (2<a)\end{cases}$$

「$a<0$ のとき…」と1行ずつ地の文で並べてもよい。

- 境界の値で2つの式が同じ値になるかを検算する（連続な量の場合）。

## 6. 型：数学的帰納法

等式 (A) を示すとする。

> すべての自然数 $n$ について (A) が成り立つことを，数学的帰納法で証明する。
>
> (i) $n=1$ のとき
> 　（左辺）$=\cdots$，（右辺）$=\cdots$
> 　よって，$n=1$ のとき (A) は成り立つ。
>
> (ii) $n=k$ のとき (A) が成り立つと仮定すると
> 　（仮定の式）　……①
> 　$n=k+1$ のときを考えると，① より
> 　（計算）
> 　よって，$n=k+1$ のときも (A) は成り立つ。
>
> (i)，(ii) より，すべての自然数 $n$ について (A) は成り立つ。（証明終）

注意：

- (i) では左辺と右辺を別々に計算する。「$1=1$ より成り立つ」とだけ書かない。
- (ii) で仮定を使った箇所に「① より」「仮定より」と書く。仮定を使っていない証明は帰納法になっていない。
- (ii) の結論で示したい式（$n=k+1$ の式）を先に書いて変形していくのは避ける。示したい式の一方の辺から出発して他方に達する。不等式なら差をとる。
- 変形した形：$n\geqq 2$ から始まるなら (i) は $n=2$。「$n=k$，$k+1$ で成り立つと仮定して $n=k+2$」の型なら (i) で $n=1$，$2$ の両方を示す。「$n\leqq k$ のすべてで成り立つと仮定」の型もある。どの型かを最初に述べる。
- 結びの文を省かない。

## 7. 型：背理法・対偶

背理法：

> $\sqrt{2}$ が無理数でないと仮定する。
> このとき，$\sqrt{2}$ は有理数であるから，…（推論）…
> これは，$m$ と $n$ が互いに素であることに矛盾する。
> したがって，$\sqrt{2}$ は無理数である。（証明終）

- 何を仮定したかを最初に書く。結論の否定を正しく作る（「すべて」の否定は「ある」，「かつ」の否定は「または」）。
- 何と矛盾するのかを名指しする。「矛盾」とだけ書かない。

対偶：

> 対偶「$n$ が奇数ならば $n^{2}$ は奇数である」を証明する。
> …
> 対偶が真であるから，もとの命題も真である。（証明終）

## 8. 型：必要条件から十分性の確認へ

必要条件で候補を絞る解き方では，候補が本当に条件を満たすかを確かめる。確かめずに終えると，答が合っていても論証が半分である。

**軌跡**

> 条件を満たす点を $\mathrm{P}(x,y)$ とする。
> （条件を $x$，$y$ の式で表し，整理する）
> よって，点 $\mathrm{P}$ は円 $x^{2}+y^{2}=4$ 上にある。
> 逆に，この円上の任意の点 $\mathrm{P}(x,y)$ は条件を満たす。
> したがって，求める軌跡は，中心が原点，半径が $2$ の円である。

- 式変形が同値なら「逆に」は1文でよい。同値でない変形（2乗，文字の消去）をしたときは，逆を実際に確かめる。
- 除外点を調べる。媒介変数を消去したとき，とれない値がないか。分母が $0$ になる点，三角形ができない点。
- 答は図形の名前で述べる（「直線 $y=2x+1$」「中心 $(1,0)$，半径 $2$ の円。ただし，点 $(3,0)$ を除く」）。

**恒等式（数値代入法）**

> $x=0$，$1$，$2$ を代入すると…，これを解いて $a=1$，$b=2$，$c=3$。
> 逆に，このとき（左辺）$=\cdots=$（右辺）となり，与式は恒等式である。

係数比較法なら逆の確認はいらない。

**整数問題・存在条件**

「$n$ は $6$ の約数であることが必要である」と絞ったら，候補を1つずつ元の条件に代入して確かめ，満たすものだけを答える。

## 9. 型：最大・最小

- 最大値・最小値を答えるときは，**そのときの変数の値**も書く。「$x=1$ で最大値 $5$」。
- 定義域を確認し，端点を含むかどうかを見る。端点を含まない区間では最大値・最小値が「ない」ことがある。その場合は「最大値はない」と書く。
- 2次関数：平方完成して頂点と軸を示し，定義域との位置関係を述べる。
- 置き換えを使ったら，新しい文字の範囲で考える。
- 数学Ⅱ・Ⅲ：導関数を求め，増減表を書き，表から読み取る。極値と端点の値を比べる。
- 相加平均と相乗平均の大小関係：使う2数が正であることを述べ，等号成立条件を確かめる（次節）。
- 図形量の最大・最小では，変数のとりうる範囲を図形の条件から出す。
- 図形の配置で最小値を示すときは，「どの配置でもこの値以上」（評価）と「この値をとる配置がある」（実現）の両方を書く。作図で「辺との交点」と書いたら，交点が線分の上にあることを1行で示す。
- **極限値との大小に狭義の不等号を使うときは，途中の点を1つはさむ。** $f(x)$ が $a\leqq x<b$ で単調に増加し，$\displaystyle\lim_{x\to b-0}f(x)=M$ のとき，いきなり「$f(a)<M$」と書かない。極限からすぐに言えるのは $f(x)\leqq M$ までである。$a<x_{0}<b$ を満たす $x_{0}$ をとり，「$f(a)<f(x_{0})\leqq M$ であるから $f(a)<M$」と書く。値域を「$f(a)\leqq f(x)<M$」と述べるときも同じで，$f(x)<M$ は「$x<x_{1}<b$ を満たす $x_{1}$ に対して $f(x)<f(x_{1})\leqq M$」から出る。
- 増減表に書く極値は，表の前で計算しておく。
- 補助の関数（$g(x)$）の増減から元の関数（$f(x)$）の増減を導いたときは，増減表に $f(x)$ の行も入れる。表で言えることを文章で言い直さない。
- 計算の途中に出る有名角でない角（三角関数の合成の角など）は，$\alpha$ とおいて $\sin\alpha$，$\cos\alpha$ の値だけで進めるなど，最短の形を選ぶ。

## 10. 型：不等式の証明と等号成立

- 基本は（左辺）$-$（右辺）を計算して，平方の和や正の数の積に変形する。
- 両辺が $0$ 以上のときは，2乗の差を調べてもよい。その前提を書く。
- 相加平均と相乗平均の大小関係を使うとき：

> $x>0$ より $x>0$，$\dfrac{4}{x}>0$ であるから，相加平均と相乗平均の大小関係により
> $$x+\dfrac{4}{x}\geqq 2\sqrt{x\cdot\dfrac{4}{x}}=4$$
> 等号が成り立つのは $x=\dfrac{4}{x}$，すなわち $x=2$ のときである。
> よって，$x=2$ で最小値 $4$ をとる。

- 等号成立を確かめないと，「$4$ 以上」は言えても「最小値が $4$」とは言えない。
- 相加平均と相乗平均の大小関係を2回使うときは，2つの等号が同時に成り立つかを確かめる。成り立たなければその方法は使えない。
- 右辺が定数にならない形で使っても最小値は求まらない。

## 11. 型：2次方程式の解の配置

$f(x)=ax^{2}+bx+c$（$a>0$）のグラフで考える。条件は次の3つの組合せで書く。

1. 判別式 $D$ の符号（実数解をもつ，異なる2つの実数解をもつ）
2. 軸の位置
3. 端点での $f(x)$ の符号

例：異なる2つの解がともに $1$ より大きい条件は「$D>0$，軸 $>1$，$f(1)>0$」。3つを連立して共通範囲を求める。

- 「$1$ より大きい解と小さい解を1つずつもつ」は $f(1)<0$ だけでよい（$a>0$ のとき）。理由を「グラフが下に凸であるから」と添える。
- 解と係数の関係で書いてもよいが，「$\alpha+\beta>2$ かつ $\alpha\beta>1$」は「ともに $1$ より大きい」と同値ではない。$(\alpha-1)+(\beta-1)>0$ かつ $(\alpha-1)(\beta-1)>0$ とする。
- 「実数解」と「異なる2つの実数解」を読み分ける。重解を含むかどうかで $D\geqq 0$ と $D>0$ が変わる。

## 12. 型：絶対値・無理式・分数式

**絶対値**

- 中身の符号で場合を分け，各場合で得た解がその場合の条件を満たすかを確かめる。
- $|A|=B$ は「$B\geqq 0$ かつ $A=\pm B$」。$|A|<B$ は $-B<A<B$。$|A|>B$ は「$A<-B$ または $B<A$」。右辺に文字があるときは符号に注意する。

**無理方程式・無理不等式（数学Ⅲ）**

- 根号の中が $0$ 以上という条件を書く。
- 両辺を2乗して解いたら，元の式に代入して確かめる。または，グラフの上下関係で解く。

**分数方程式・分数不等式（数学Ⅲ）**

- 分母が $0$ でない条件を書く。
- 不等式で分母を払うときは，分母の符号で場合を分けるか，分母の2乗を掛ける。

## 13. 型：確率・場合の数

- **何を同様に確からしいとみるか**を最初に決める。同じ色の玉も区別して数える。
- 全事象の数と，条件を満たす場合の数を分けて書く。
- 「少なくとも1つ」は余事象。「余事象は『すべて…でない』であるから」と書く。
- 排反であることを確かめてから確率を足す。独立であることを確かめてから掛ける。
- 反復試行：${}_{n}\mathrm{C}_{r}p^{r}(1-p)^{n-r}$。何が $n$，$r$，$p$ かを述べる。
- 条件付き確率：事象に $A$，$B$ と名前を付け，$P_{A}(B)=\dfrac{P(A\cap B)}{P(A)}$ で計算する。
- 式だけを書かない。${}_{5}\mathrm{C}_{2}\times{}_{3}\mathrm{C}_{1}$ の各因数が何を数えたものかを言葉で添える。
- 答は既約分数で書く。$0$ 以上 $1$ 以下であることを見る。

## 14. 答の書き方

| 問いの形 | 答の形 |
|---|---|
| 値を求めよ | 「**答**　$x=2$」 |
| すべて求めよ | 全部を並べる。「$x=2,\ -3$」 |
| 範囲を求めよ | 不等式で書く。「$-1<a\leqq 2$」 |
| 個数を求めよ | 「$3$ 個」と単位を付ける |
| 最大値・最小値 | 「$x=1$ で最大値 $5$，$x=-1$ で最小値 $-3$」 |
| 方程式を求めよ | 「$y=2x+1$」と式の形で |
| 軌跡・領域 | 図形の名前と，除外点・境界の扱い |
| 証明せよ | 結論の文と「（証明終）」 |
| 場合分けのある答 | すべての場合をまとめて書く |

- 分母は有理化する。分数は約分する。根号の中は最も簡単な形にする。
- 近似値を求められていなければ，$\pi$，$\sqrt{2}$，$\log 2$ はそのまま残す。
- 文章題は単位を付ける（cm，個，通り，円）。
- 「通り」は場合の数に付ける。

**答の書式を1題の中でそろえる。** 求める量に名前（記号）があれば「記号 $=$ 式」，なければ式・値だけ，のどちらかにする。選択肢で答える小問は，番号だけでなく内容も添える（「②（左向き）」）。

## 15. 解説を書くときの追加事項

- **最初の一手の理由を書く。** 「なぜ $t=2^{x}$ とおくのか」は，生徒が一番知りたいことである。方針で「$4^{x}=(2^{x})^{2}$ であるから，$2^{x}$ についての2次方程式とみる」と述べる。
- **途中式を飛ばさない。** 展開，因数分解，通分は1段階ずつ書く。2段階以上を1行にまとめない。
- **別解は「別解」と見出しを付けて分ける。** 本解は，その単元で習う標準的な方法にする。
- **答案に書けない説明は「参考」に入れる。** 直感的な説明，図形的な意味，範囲外の背景知識。「記述式の答案には使えない」と断る。
- **解答にない着眼点だけを書く。** 解答本文で述べたこと（端点の扱い，境界を含むかどうか，場合分けの結果）を言い直さない。方針と解説で同じことを二度書かない。
- **検算・確認を載せない。** 「（確認：…一致する）」「検算：$a=1.5$ を代入すると…」は出力前の点検であり，括弧書きでも欄でも書かない。数値を代入した確かめが理解の助けになる場合に限り，「参考」に1行で書く。
- 地の文の「近づく」は `\to` で書く（$x\to 0$ のとき）。`\longrightarrow` と混ぜない。
- **誤答に触れるなら，誤りであることがはっきりわかるように書く。** 「よくある誤り」と見出しを付け，どこが誤りかを述べる。
- **厳密さの程度を使い分ける。** 教科書が直観で扱うところ（極限，連続性，面積の定義）は教科書と同じ程度で書く。答案の論理（同値性，場合分け，条件）はごまかさない。

## 16. 減点されやすい書き方

体裁（箇条書き，式番号，**答** の後の確認，図番号）の誤りは SKILL.md の点検で扱う。ここには論理と記述の誤りを挙げる。

| 書き方 | 直し方 |
|---|---|
| 式だけが縦に並んでいる | つなぎの言葉を入れる |
| 文字を説明なしに使う | 「…を $t$ とおく」と書く |
| $=$ でつないだ式の途中に不等式や別の式が混ざる | 1本の等式の連鎖は同じものの変形だけにする |
| 等しくないものを $=$ でつなぐ（「$x^{2}-4=0=(x-2)(x+2)$」，微分して「$x^{3}=3x^{2}$」） | 「$(x^{3})'=3x^{2}$」のように正しく書く |
| $\displaystyle\lim$ を途中で書き忘れる | 極限をとる直前まで $\displaystyle\lim$ を付け続ける |
| $\dfrac{\infty}{\infty}$，$\dfrac{1}{0}$，$\infty-\infty$ を式に書く | 「分母・分子がともに発散するので，分母の最高次の項で割る」と言葉で書く |
| 「$n=1$ のとき成り立つ」だけで計算がない | 両辺を計算する |
| 「同様に」で別の計算を省く | 計算を書く |
| 「明らかに」で根拠を省く | 根拠を書く |
| 図から読み取っただけで式の裏付けがない | 「図より」と書いたうえで，交点の座標などは計算で示す |
| 積分定数 $C$ の説明がない | 「$C$ は積分定数」 |
| 一般角で「$n$ は整数」がない | 添える |
| 答が本文に埋もれている | 独立した行に書く |
| $\overrightarrow{\mathrm{OH}}=d\,\vec{n}$ と書いて向きの根拠がない | 同じ向きである理由を1文書く |
| 無関係な条件を理由に並べる | 結論に効く条件だけを書く |
| 条件を満たさない解を理由なく捨てる | 「$x>1$ を満たさないから不適」と書く |
| 定理を使う条件を確かめていない | 「$x>0$，$y>0$ であるから」「$f(x)$ は連続であるから」 |
