# 範囲外の定理・解法と，高校範囲での書き換え

範囲外の道具を思いついたら，まずここで扱いを確かめ，高校範囲の方法で書き直す。範囲外の方法は検算に使ってよいが，答案には書かない。範囲外の定理・記号は，名前だけの紹介もしない。

範囲外の定理・記号・用語の一覧と，1つずつの書き換え先は `scripts/hs_check.py` が持つ（検査の出力に「なぜだめか → 何に直すか」が出る。一覧は `check-rules.md`）。ここには検査では判定できない判断の基準と，書き換えの手順の例を置く。

## 目次

1. 判断の基準
2. 扱いに注意がいるもの（教科書にあるが使い方に条件がある）
3. 範囲内なので使ってよいもの（範囲外と誤解しやすい）
4. 書き換えの例

## 1. 判断の基準

次の順に考える。

1. その定理・公式は，問題の科目までの教科書の本文に載っているか。載っていれば名前を挙げて使う。
2. 「発展」「研究」として載っているか。そうなら，定義や導出を1〜2行書いてから使う。
3. 載っていないなら使わない。教科書の道具で同じ結論を導く。

科目の順序も範囲のうちである。数学Ⅲの道具で数学Ⅱの問題を解くと，その単元を学んでいる生徒には読めない。

## 2. 扱いに注意がいるもの

教科書に載っているか，広く使われているが，使うときに条件があるもの。

| 項目 | 扱い |
|---|---|
| 合同式 | 発展。「整数 $a$，$b$ を正の整数 $m$ で割った余りが等しいとき，$a\equiv b\pmod{m}$ と書く」と定義してから使う。合同式での割り算はしない |
| $\displaystyle\int_{\alpha}^{\beta}(x-\alpha)(x-\beta)\,dx=-\dfrac{1}{6}(\beta-\alpha)^{3}$ | 教科書に載る。式を書いて使ってよい。$\dfrac{1}{12}$，$\dfrac{1}{3}$ の公式は載らないので計算を示す |
| ヘロンの公式 | 数学Ⅰに載る。名前を挙げて使ってよい |
| 3次方程式の解と係数の関係 | 数学Ⅱの発展。式を書いてから使う |
| $(ax+b)^{n}$ の微分・積分 | 数学Ⅱでは発展。数学Ⅱの問題では展開して計算する。数学Ⅲでは自由に使える |
| 点と直線の距離の公式 | 数学Ⅱの本文にある。数学Ⅰ・Aの問題では使わない |
| 1次独立 | 用語は発展。「$\vec{a}\neq\vec{0}$，$\vec{b}\neq\vec{0}$ で，$\vec{a}$ と $\vec{b}$ は平行でないから」と書く |
| 正射影ベクトル | 用語は本文にない。「$\mathrm{H}$ は直線 $\mathrm{OA}$ 上にあるから $\overrightarrow{\mathrm{OH}}=k\vec{a}$ とおけて，$\overrightarrow{\mathrm{PH}}\perp\vec{a}$ より…」と導く |
| 三角形の面積 $\dfrac{1}{2}\lvert x_{1}y_{2}-x_{2}y_{1}\rvert$ | 使ってよいが，「$\overrightarrow{\mathrm{OA}}=(x_{1},y_{1})$，$\overrightarrow{\mathrm{OB}}=(x_{2},y_{2})$ のとき」と前提を書く |
| 和と積の公式 | 加法定理から導ける。暗記を前提にせず，導出を1行添える |
| 特性方程式 | 用語は教科書にない。「$\alpha=2\alpha+1$ を満たす $\alpha=-1$ を用いて，$a_{n+1}+1=2(a_{n}+1)$ と変形できる」と書く。隣接3項間は誘導に従う |
| 重複組合せ ${}_{n}\mathrm{H}_{r}$ | 「〇と仕切りの並べ方」として ${}_{n+r-1}\mathrm{C}_{r}$ を導く |
| 期待値の和 $E(X+Y)=E(X)+E(Y)$ | 数学B。数学Aの問題では定義どおりに計算する |
| 中間値の定理，平均値の定理 | 数学Ⅲの本文にある。条件（連続，微分可能）を述べて使う |
| ロルの定理 | 教科書により扱いが違う。平均値の定理で書く |

## 3. 範囲内なので使ってよいもの

範囲外と誤解されやすいが，教科書の本文にある。名前を挙げて使う。

- 数学Ⅰ：正弦定理，余弦定理，三角形の面積 $\dfrac{1}{2}bc\sin A$，背理法，対偶による証明，ド・モルガンの法則
- 数学A：チェバの定理，メネラウスの定理，方べきの定理，接線と弦のつくる角の定理（接弦定理），角の二等分線と比，3つの集合の要素の個数，ユークリッドの互除法，1次不定方程式，反復試行の確率
- 数学Ⅱ：剰余の定理，因数定理，解と係数の関係（2次），二項定理，相加平均と相乗平均の大小関係（2数），点と直線の距離，加法定理，2倍角・半角の公式，三角関数の合成
- 数学B：数学的帰納法，$\sum k$，$\sum k^{2}$，$\sum k^{3}$ の公式，部分分数に分けて和を求める方法，中心極限定理に基づく正規分布による近似（結果を使う）
- 数学Ⅲ：はさみうちの原理，$\displaystyle\lim_{x\to 0}\dfrac{\sin x}{x}=1$，$\displaystyle\lim_{h\to 0}(1+h)^{\frac{1}{h}}=e$，中間値の定理，平均値の定理，区分求積法，曲線の長さ，速度と道のり，置換積分法，部分積分法
- 数学C：ド・モアブルの定理，極形式，2次曲線の焦点・準線・離心率，極方程式，直線・円のベクトル方程式

## 4. 書き換えの例

### ロピタルの定理を使わない

$\displaystyle\lim_{x\to 0}\dfrac{e^{x}-1}{x}$ を求める。

$f(x)=e^{x}$ とおくと，$f'(x)=e^{x}$ である。微分係数の定義により

$$\lim_{x\to 0}\dfrac{e^{x}-1}{x}=\lim_{x\to 0}\dfrac{f(x)-f(0)}{x-0}=f'(0)=1$$

### 外積を使わない

$\vec{a}=(1,2,1)$，$\vec{b}=(2,1,-1)$ の両方に垂直なベクトルを求める。

求めるベクトルを $\vec{n}=(x,y,z)$ とおく。$\vec{n}\perp\vec{a}$，$\vec{n}\perp\vec{b}$ より $\vec{n}\cdot\vec{a}=0$，$\vec{n}\cdot\vec{b}=0$ であるから

$$\begin{cases}x+2y+z=0\\2x+y-z=0\end{cases}$$

辺々を加えると $3x+3y=0$ より $y=-x$。これを第1式に代入して $z=x$。

よって，$\vec{n}=(x,-x,x)=x(1,-1,1)$ である。たとえば $\vec{n}=(1,-1,1)$。

### 総乗の記号を使わない

$\dfrac{k+1}{k}$ を $k=1$ から $k=n$ まで掛け合わせた積を求める。

$$\dfrac{2}{1}\cdot\dfrac{3}{2}\cdot\dfrac{4}{3}\cdots\dfrac{n+1}{n}=n+1$$

隣り合う分数の分子と分母が約分されて，最初の分母 $1$ と最後の分子 $n+1$ だけが残る。

### フェルマーの小定理を使わない

$2^{100}$ を $7$ で割った余りを求める。

$2^{3}=8=7+1$ であるから，$2^{100}=2\cdot(2^{3})^{33}=2(7+1)^{33}$ である。二項定理により

$$(7+1)^{33}={}_{33}\mathrm{C}_{0}\cdot 7^{33}+{}_{33}\mathrm{C}_{1}\cdot 7^{32}+\cdots+{}_{33}\mathrm{C}_{32}\cdot 7+1$$

最後の項以外はすべて $7$ の倍数であるから，$(7+1)^{33}=7N+1$（$N$ は整数）と表せる。

よって，$2^{100}=2(7N+1)=7\cdot 2N+2$ となり，求める余りは $2$ である。

### コーシー・シュワルツの不等式を名前で使わない

$a$，$b$，$x$，$y$ が実数のとき，$(a^{2}+b^{2})(x^{2}+y^{2})\geqq(ax+by)^{2}$ を示す。

$$\begin{aligned}
(a^{2}+b^{2})(x^{2}+y^{2})-(ax+by)^{2}&=a^{2}y^{2}-2abxy+b^{2}x^{2}\\
&=(ay-bx)^{2}\geqq 0
\end{aligned}$$

よって，$(a^{2}+b^{2})(x^{2}+y^{2})\geqq(ax+by)^{2}$ が成り立つ。等号が成り立つのは $ay=bx$ のときである。（証明終）

### 逆三角関数を使わない

$\displaystyle\int_{0}^{1}\dfrac{1}{1+x^{2}}\,dx$ を求める。

$x=\tan\theta$ とおくと，$dx=\dfrac{1}{\cos^{2}\theta}\,d\theta$ であり，$x$ と $\theta$ の対応は次のようになる。

| $x$ | $0$ | $\longrightarrow$ | $1$ |
|---|---|---|---|
| $\theta$ | $0$ | $\longrightarrow$ | $\dfrac{\pi}{4}$ |

$1+\tan^{2}\theta=\dfrac{1}{\cos^{2}\theta}$ であるから

$$\int_{0}^{1}\dfrac{1}{1+x^{2}}\,dx=\int_{0}^{\frac{\pi}{4}}\cos^{2}\theta\cdot\dfrac{1}{\cos^{2}\theta}\,d\theta=\int_{0}^{\frac{\pi}{4}}d\theta=\dfrac{\pi}{4}$$

### テイラー展開を使わない

$x>0$ のとき $e^{x}>1+x$ を示す。

$f(x)=e^{x}-(1+x)$ とおくと，$f'(x)=e^{x}-1$ である。$x>0$ のとき $e^{x}>1$ であるから $f'(x)>0$ となり，$f(x)$ は $x\geqq 0$ で単調に増加する。

$f(0)=0$ であるから，$x>0$ のとき $f(x)>0$，すなわち $e^{x}>1+x$ である。（証明終）

### 合同式を使わない

整数 $n$ について，$n^{2}$ を $3$ で割った余りは $0$ か $1$ であることを示す。

$n$ を $3$ で割った余りで分類する。$k$ を整数とする。

[1] $n=3k$ のとき，$n^{2}=9k^{2}=3\cdot 3k^{2}$ より余りは $0$。

[2] $n=3k+1$ のとき，$n^{2}=9k^{2}+6k+1=3(3k^{2}+2k)+1$ より余りは $1$。

[3] $n=3k+2$ のとき，$n^{2}=9k^{2}+12k+4=3(3k^{2}+4k+1)+1$ より余りは $1$。

[1]〜[3] より，$n^{2}$ を $3$ で割った余りは $0$ か $1$ である。（証明終）
