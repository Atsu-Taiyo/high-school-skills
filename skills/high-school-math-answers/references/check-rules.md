# 検査の規則一覧（math）

`scripts/hs_check.py rules --subject math` の出力をそのまま置いたもの。手で直さない（規則を変えたら hs_check.py を直して作り直す）。
Python が使えず検査を実行できないときは，この一覧で答案を目で点検する（検査を実行したことにはならない）。
各行は「なぜだめか → 何に直すか」。ERROR は確実に直すもの，WARN は文脈で判断するもの。

## 数式の中・形式・構成

| 水準 | 検査 | なぜだめか → 何に直すか |
|---|---|---|
| ERROR | frac | \frac は文中で小さく組まれ，教科書の分数の大きさと違う → 分数は \dfrac（\frac は指数・添字の中だけ） |
| ERROR | circled-in-math | 丸数字は KaTeX のフォントに無く，数式の中では警告が出て位置がずれる → 丸数字・丸囲み文字は数式の外に書く（KaTeX が警告を出す） |
| ERROR | table-pipe | 表の中の \| は列の区切りと衝突して表が崩れる → 表の中の数式に縦線 \| を書かない（\lvert x\rvert） |
| WARN | text-long | 数式の中の文は字体と改行が本文とずれる → \text{} に入れてよいのは「かつ」「または」程度の短い語だけ |
| WARN | text-unit | \text{} の単位は字体が本文と違う → 点の名前・単位は \mathrm{}（\text{} にしない） |
| WARN | displaystyle | 文中の lim・Σ・∫ は小さく組まれて読みにくい → 文中の \lim・\sum・\int には \displaystyle |
| ERROR | dollar-unclosed | $ が閉じていないと以降の本文が数式として崩れる → $ の対応がとれていない（閉じ忘れ，または段落をまたいでいる） |
| ERROR | display-blank | $$ の中の空行で数式が切れて描画されない → $$ の中に空行を入れない |
| ERROR | paren-delim | この答案の数式の区切りは $ に決めている（\( \) は環境によって描画されない） → 数式の区切りは $…$・$$…$$（\( \) と \[ \] は使わない） |
| ERROR | code-wrap | コードブロックの中では数式が描画されない → 全体をコードブロックで囲まない（数式が描画されなくなる） |
| ERROR | bullet | 箇条書きは答案の文章でなく，推論のつながりが切れる → 解答本体に Markdown の箇条書きを使わない（文でつなぐか (i)(ii)・[1][2] で区切る） |

| WARN | sections | 求められない限り解答と答だけを書く決まり → 頼まれていない方針・解説・別解・参考は書かない（頼まれたなら問題ない） |
| ERROR | eqno-format | 式番号の書式は1通りに決めている（丸数字を数式の外に置くため） → 式番号の書式は「　$式$　……①」（行頭に全角空白，文中数式，全角空白，「……」，番号） |
| ERROR | eqno-paren-digit | (1)(2) は小問の番号と紛れる → 式番号に (1)(2) を使わない（小問番号と紛れる） |

| WARN | congruence | 合同式は発展事項で，断りなく使うと範囲外 → 合同式は発展。使うなら定義を書いてから（割った余りで分類する書き方が原則） |

| WARN | svg-missing | 参照した図が無い → 答案が参照する SVG 図が見つからない |
