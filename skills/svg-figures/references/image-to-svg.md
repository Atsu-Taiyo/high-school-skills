# 画像から教材図を作る

Mode A・B の手順の正本。種類の決め方は SKILL.md，描き方の原則は [principles.md](principles.md)，数値の既定値は [conventions.md](conventions.md)。

元画像を保存し，図の周囲の式・説明も読む。切り出した範囲，向き，読める文字，印や矢印の数と位置を控える。描き方の痕跡（筆圧の変化，かすれ，罫線との関係）から手描きと分かれば Mode A，活字・規則的な線・既存の清書図なら Mode B。汚れや撮影の傾きだけで手描き扱いしない。判断がつかなければ該当箇所を示して確認する。

## Mode A　意図を読み取り，構造から描き直す

**守るもの**：筆者が伝えたかったこと。線の揺れ・傾き・比率の崩れ・重ね書きは意図ではないので，筆跡をなぞらない。

1. **描く前に意図仕様を書く**（`<図>.intent.md`，書式は [intent-template.md](intent-template.md)）。伝えたいこと，対象とその関係（交点・頂点・接点などは式や幾何から計算した値），本質の印とその意味，図に書く文字（薄く小さくても意味のあるものを含む），判読できない文字（`[?]`），立体なら投影。
2. **仕様から正確に描く**。直線・円・式の曲線で構成し，崩れた対称・比率・寸法は仕様の関係に合わせて直す。立体は1つの投影で一貫させる。色は原図から測って平塗りにする。
3. **筆者が書いたものだけを描く**。原図に無い要素（筆者が描いていない線・力・数値，解答文だけにある値）を足さない。読めない文字は推測で描かない。重ね書きで判断しにくい所は，拡大や筆跡の抽出（`trace_strokes.py`）を測定の下図に使ってよい。
4. **確かめる**。仕様の関係（半径・交点・角・等長）が図で成り立つか確かめ，掲載幅で描画して原図と並べ，意図が伝わるかを見る。Python が使えるなら，ルートに `data-mode="A"` を付けて `python3 "$S/lint_svg.py" --strict figure.svg`（付けない場合は `--intent=figure.intent.md`。どちらも無いと仕様との照合は行われない）。使えなければ，仕様の「文字」「本質の印」を1件ずつ図と突き合わせる。

Mode A に数値の忠実度採点は使わない。

## Mode B　原図の配置を再現する

**守るもの**：原図そのもの。体裁をそろえるために詰めたり，作図標準へ寄せたりしない。標準と違う表現に気づいたら，原図の状態を記録してそのまま再現する。

1. 元の作図データがあればそれを使う。画像しかなければ，左上を基準に要素の座標・線幅・破線の間隔・字面と基線・色を測り，直線・円・滑らかな曲線と活字で組み直す。余白と縦横比を含めて範囲を保つ。
2. 図題・番号（空白やダッシュの種類を含む）・凡例・字間・ラベルの表記・色は原図のとおりに写す。色は平塗りにして `data-source-colors` に書く。
3. 部品の**状態と接続**（開閉，接点，極性，向き，どちら側に付くか，どこで途切れてどこで再開するか）は意味を決めるので，個別に測って写す。密集した文字は親文字と添字を別々に測る。
4. SVG に `title`・`desc`・`role="img"`・`data-mode="B"` を付ける。

### 原寸での確認（普段はこれで足りる）

SVG を原図と同じ寸法で描画し，原図と並べて（または重ねて）比べる。端点・接点・交点・記号・部品の状態・文字の位置と表記を局所的に拡大して確かめ，ずれた所だけを直す。色のある領域は色見本でも比べる。

### 数値による採点（必要な案件だけ）

原図への忠実さを数値で示す必要があるとき（依頼で求められたとき，多段回路などで目視では判断しきれないとき）だけ使う。Chrome または Chromium，Pillow，NumPy，OpenCV が要る。使えない環境では原寸での確認で納品し，採点していないことを伝える。

```sh
# S はスキルの scripts ディレクトリ。回ごとに新しい出力先を使う。
python3 "$S/fidelity_loop.py" --source source.png --svg figure.svg --out-dir iter-0
```

- **採点値の考え方**：原図と描画を同じしきい値で二値化し，両方を細線化してから同じ幅に太らせて重なりを測る（`iou_norm`）。にじみ・線幅・書体の違いを抑え，線の位置を評価するため。素の画素の重なり `iou_raw` と1画素の許容で測る `f1_1px` も記録する。しきい値・膨張半径・切り出しは全試行で固定する（既定値は conventions.md）。
- **直し方**：`feedback.md`・`overlay.png`・上位の `regions/` を開き，残差の大きい領域から1〜2件だけ直す（橙は不足，赤紫は余分，青緑は一致）。編集位置は `bbox_svg`（SVG 座標）を使う。全体を動かす・全体の線を引き直すことはしない。文字の候補には元の文字列と推奨入力が出るので，原図を拡大して確かめる。
- **終了**：目標に届いたら終える。各版を保存し，後退したら最良版に戻して別の直し方を試す（後退も回数に数える）。最高値を更新できない採点が続いたとき，または修正回数の上限で終える。未達なら「目標未達」と明記し，最良版の3指標，終了理由，残差の位置と内容を報告する。
