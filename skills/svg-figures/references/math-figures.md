## 1. 関数のグラフ

- 窓は，見せたい特徴（頂点，極値，交点，漸近線）がすべて入り，周りに 0.5〜1 目盛りの余裕がある範囲にする。x と y は同じ縮尺（`unit` だけ指定）。
- 曲線は `plot(f, a, b)`（400 分割）。窓の上下からはみ出す部分は自動で切られる。$y=\tan x$ や $y=1/x$ のように途切れる関数も，そのまま渡してよい（漸近線をまたぐ縦線は出ない）。分割が粗くて鋭い山が欠けるときは `n` を増やすか区間を分ける。
- 定義域に端があるとき（$\sqrt{x}$，$\log x$）は，定義される範囲だけを渡す。
- 漸近線は `line_through(..., style="dash")`。
- 目盛りは必要な値だけ：`axes(xticks=[1, (2, "$a$"), (math.pi, "$\\pi$")], yticks=[...])`。目盛りの文字が曲線や破線と重なるときは `(値, ラベル, 向き)` で向きを変える（例 `(2, "$2$", "SE")`）。原点を曲線が通って「O」と重なるときは，`axes(origin=None)` にして `label("O", (0,0), dir="SE")` などで置き直す。
- 極値・交点・切片には黒丸。座標を読ませたい点からは，軸へ破線を下ろす。
- グラフの名前（$y=f(x)$）は，曲線の端の近くに `label` で置く。

```python
f = lambda x: x**3 - 3*x
fig = Figure(-2.6, 2.6, -3, 3, unit=44, title="y=x^3-3x のグラフ", desc="極大 (-1,2)，極小 (1,-2)")
fig.axes(xticks=[(-1, "$-1$"), (1, "$1$", "N")], yticks=[(2, "$2$", "E"), (-2, "$-2$")])
fig.plot(f, -2.6, 2.6)
for x in (-1, 1):                       # 極値の x は f'(x)=0 を解いた値
    fig.segment((x, 0), (x, f(x)), style="dash")
    fig.segment((0, f(x)), (x, f(x)), style="dash")
    fig.dot((x, f(x)))
fig.label("$y=x^3-3x$", (2.1, f(2.1)), dir="W", dist=8)
```

縦横の縮尺を変えるのは，同じ縮尺では図が読めないときだけ（極端に細長い，値が小さすぎて x 軸に貼り付く，など）。変えたら，**図の下に注記を入れるか，y 軸に数値の目盛りを入れる**。最大値を $M$ のような記号や式で示すだけの図では縮尺が読めないので，注記が要る。

```python
f = lambda t: math.sin(t) - t + t**3 / 6            # 区間 [-1, 1] で |f| < 0.01
M = f(1)
fig = Figure(-1.45, 1.5, -0.0112, 0.0124, unit=130, yunit=13000, title="…", desc="…縦軸方向は100倍に拡大…")
fig.xaxis("$\\theta$", ticks=[(-1, "$-1$", "N"), (1, "$1$")])
fig.yaxis("$y$", ticks=[(M, "$M=\\sin 1-\\frac{5}{6}$"), (-M, "$m=\\frac{5}{6}-\\sin 1$", "E")])
fig.plot(f, -1, 1)
fig.note("※ 縦軸方向は拡大して描いてある")
```

目盛りや点の値が分数のときは `\\frac` で縦組みにする（`"$\\frac{1}{2}$"`，`"$-\\frac{3}{4}$"`）。点の座標を書くときは `"A$(\\frac{3}{2}, 1)$"`，`"P$(a, b)$"`（カンマの後に空白）。

- **近接する2曲線の名前。** 2本の曲線がほぼ重なる・接する場所に曲線名を置かない。十分離れた場所に置くか，`fig.leader("$y=f(x)$", 曲線上の点, 文字を置く点)` で引き出し線を付ける。引き出し線は斜線の領域・補助線・他の曲線を横切らせない（領域をはさむ2曲線の名前は，それぞれ領域の外側へ引き出す）。
- **領域の図の線種。** 含まない境界は `style="bound"`（太い破線），含む境界は実線，座標を読む補助線は `style="guide"`（細い点線）。境界の破線を，境界でない区間（軸までの延長）に同じ線種で続けない。含まない端の点は白丸。
- **細くつぶれる領域。** 2曲線が接する点の近くでは斜線が消えて，領域がどこまで続くか読めない。接点に短い語（「接する」）を添えるか，その部分の拡大図を別の図として付ける。
- **具体的な値で描いた概形**（$a=1.5$ の場合のグラフなど）は，その値をキャプションに書く。
- **主変数の角は弧で示す。** 本文で $\theta$ を「$x$ 軸の正の向きから…までの角」と定義したら，図にその弧と名前を入れる。本文で名前を付けた図形（三角形 $T$，直線 $\ell_1$）も図に書く。
- 縮尺の注記は文言をそろえる（「※ 縦軸方向と横軸方向の縮尺は異なる」など。`conventions.md`）。境界を含むかどうかなどの説明は図に書かず，本文に書く。

## 2. 接線・面積

- 接点は式から求める。`P, m = hs.tangent_at(f, a)` で接点と傾き。接線は `line_through(P, (P[0]+1, P[1]+m))`。
- 2曲線の交点は `hs.solve(lambda x: f(x)-g(x), 左, 右)`。区間は，解を1つだけ含むように取る。厳密な値が分かっているならその値を直接使う。
- 面積は `hatch(hs.region_between(上の関数, 下の関数, a, b))`。境界の曲線はその後で描く（ハッチは最背面に入る）。
- x 軸との間の面積は `region_between(f, lambda x: 0, a, b)`。
- 2つの領域を区別するなら `angle=135` や `spacing=8` で斜線を変える。
- 面積の記号 $S$ を領域の中に置くときは `label("$S$", 点, dir="C", bg=True)`。

## 3. 三角形・円

- 頂点を変数にし，他の点はすべてそこから計算する。

| 求めるもの | 関数 |
|---|---|
| 中点，内分点，外分点 | `midpoint(A,B)`，`lerp(A,B,t)`（$m:n$ の内分は $t=m/(m+n)$，外分は $t=m/(m-n)$） |
| 垂線の足 | `foot(P, A, B)` |
| 2直線の交点 | `intersect_lines(A,B,C,D)` |
| 外心・内心・重心・垂心 | `circumcenter` `incenter` `centroid` `orthocenter` |
| 内接円の半径，接点 | `inradius(A,B,C)`，`foot(I, A, B)` |
| 円と直線，2円の交点 | `intersect_line_circle(A,B,O,r)` `intersect_circles(O1,r1,O2,r2)` |
| 円外の点からの接線の接点 | `tangent_points(P, O, r)` |
| 角の二等分線と対辺の交点 | `lerp(B, C, AB/(AB+AC))`（$BD:DC=AB:AC$） |
| 回転，対称 | `rotate(P, 度, 中心)` `reflect(P, A, B)` |

- 辺の長さや角が与えられた三角形は，余弦定理などで頂点の座標を出してから描く。例：$AB=5$，$AC=4$，$\angle A=60°$ なら `A=(0,0); B=(5,0); C=hs.polar(4, 60)`。
- 一般の三角形として描くときは，二等辺・直角・正三角形に見えない形にする（例 `A=(1.8,3.6), B=(0,0), C=(5,0)`）。逆に，条件に直角や等辺があるなら必ず印を付ける。
- 印：`angle_mark(P, 頂点, Q, label="$\\theta$")`（等しい角は `n=2` などで本数を揃える），`right_angle(P, 頂点, Q)`，`tick_marks(A, B, n)`，`parallel_marks(A, B, n)`。
- 頂点の名前は `point(P, "A", away=重心)`。垂線の足や辺上の点は `dir="S"` などで辺の外側を指定する。
- 円は `circle(O, r)`。中心には黒丸と名前。半径を示す線分は破線にせず細い実線（`style="aux"`）。
- 円周角・接弦定理の図は，弧に対する角の位置関係が崩れないよう，点を偏角で置く（`hs.polar(r, 度, O)`）。

## 4. ベクトル

- ベクトルは `arrow(始点, 終点)`（本体の太さ，先に矢じり）。名前は矢印の中点付近の外側：`label("$\\vec{a}$", hs.midpoint(O, A), dir=...)`。
- 和 $\vec{a}+\vec{b}$ は平行四辺形を作り，残りの2辺を破線にする。差・実数倍も，成分を計算して終点を決める。
- 位置ベクトルの図では，点に黒丸と名前（立体），矢印に $\vec{a}$（イタリック＋矢印）。
- 成分表示を見せる図は座標軸を付け，成分を読む破線を軸へ下ろす。

```python
O, A, B = (0, 0), (3, 0.5), (1, 2)
C = hs.add(A, B)
fig = Figure(-0.5, 4.6, -0.5, 3, unit=50, title="ベクトルの和", desc="a と b の和を平行四辺形で示す")
fig.segment(A, C, style="dash"); fig.segment(B, C, style="dash")
for P in (A, B, C):
    fig.arrow(O, P)
fig.label("$\\vec{a}$", hs.midpoint(O, A), dir="S")
fig.label("$\\vec{b}$", hs.midpoint(O, B), dir="NW")
fig.label("$\\vec{a}+\\vec{b}$", hs.lerp(O, C, 0.62), dir="SE", dist=4)
fig.label("O", O, dir="SW")
```

## 5. 空間図形（斜投影）

- `hs.oblique((x, y, z))` で平面の点にする。y 軸が右，z 軸が上，x 軸が手前（左下 45° の向き，長さ 1/2）。教科書の座標空間の図と同じ向き。奥行きを 30° にするなら `angle=30`。
- 正面（yz 平面に平行な面）は実形で，奥行き方向だけ半分に縮む。奥行き方向の長さや角は図から読めないので，必要な長さは文字で示す。
- 見える辺は `main`，隠れる辺は `style="hidden"`。どの辺が隠れるかは視点（右上・手前から見る）で決まる：この投影では，x が小さい（奥）・y が小さい（左）・z が小さい（下）頂点に集まる3辺が隠れる。
- 頂点の名前は `dir` を指定する方が確実（上面は上，底面は下，隠れた頂点は内側の空いた向き）。
- 頂点に座標を添えるときは `"C$(0, 0, 2)$"` のようにカンマの後を空ける。
- 断面は切り口の多角形を `polygon`，面を示すなら `hatch`。切り口の頂点は辺上の内分点として計算する。
- 球は円（輪郭）と，赤道を表す楕円（手前を実線，奥を破線）。円柱・円錐の底面は楕円（横半径 $r$，縦半径 $r/2 \times \sin 45°$ 程度）で，奥の半分を破線にする。
- 座標空間の軸は，原点から3本の矢印（$x$ は左下，$y$ は右，$z$ は上）。

```python
P = lambda x, y, z: hs.oblique((x, y, z))
a, b, c = 2.4, 3.6, 2.4                       # 奥行き，横，高さ
V = dict(A=P(a,0,c), B=P(a,b,c), C=P(0,b,c), D=P(0,0,c),
         E=P(a,0,0), F=P(a,b,0), G=P(0,b,0), H=P(0,0,0))
fig = Figure(-1.6, 4.6, -1.4, 3.4, unit=44, title="直方体 ABCD-EFGH", desc="…")
for s in ("AB", "BC", "CD", "DA", "AE", "BF", "CG", "EF", "FG"):
    fig.segment(V[s[0]], V[s[1]])
for s in ("DH", "HE", "HG"):                  # 隠れる3辺
    fig.segment(V[s[0]], V[s[1]], style="hidden")
dirs = dict(A="W", B="E", C="NE", D="NW", E="SW", F="SE", G="E", H="NE")
for k, p in V.items():
    fig.label(k, p, dir=dirs[k])
```

## 6. 数直線

- `xaxis(label=None, ticks=[...])` だけを描く。窓の y 範囲は −1〜1.2 程度に狭く取る。
- 区間は `interval(a, b, closed_a=True, closed_b=False)`。端点を含むなら黒丸，含まないなら白丸。片側が無限なら `None`。
- 連立不等式のように複数の区間を重ねるときは，`h`（高さ px）を変えて段を分け，共通部分を `hatch` で示す。
- 点の名前や値は数直線の下。

```python
fig = Figure(-4, 5, -1, 1.2, unit=36, title="-2≦x<3 の図示", desc="…")
fig.xaxis(ticks=[-2, 3])
fig.interval(-2, 3, closed_a=True, closed_b=False)
```

## 7. ベン図

- 全体集合 $U$ は長方形（`style="aux"`），集合は円。名前はイタリックで，円の外側の上（$U$ は長方形の内側の隅）。
- 塗る部分は `hatch` の `intersect` と `exclude` で指定する。

| 部分 | 書き方（`A`, `B` は `circle_region`，`U` は長方形の4点） |
|---|---|
| $A \cap B$ | `hatch(A, intersect=[B])` |
| $A \cup B$ | `hatch(A)`; `hatch(B, exclude=[A])` |
| $A \cap \overline{B}$ | `hatch(A, exclude=[B])` |
| $\overline{A \cup B}$ | `hatch(U, exclude=[A, B])` |
| $\overline{A}$ | `hatch(U, exclude=[A])` |

- 斜線の位相は図全体で共通なので，`hatch` を分けて呼んでも線がつながる。
- 要素の個数を書き込む図は，各部分の中央に数字（立体）を `dir="C"` で置き，斜線は使わない。

## 8. 三角関数・単位円

- 単位円は `circle((0,0), 1)` と座標軸。動径は原点から `hs.polar(1, 度)` へ。角は `angle_mark((1,0), (0,0), P, label="$\\theta$")`。
- $\sin\theta$，$\cos\theta$ を表す線分は，点から軸への垂線（破線）と軸上の点で示す。
- $y=\sin x$ などのグラフは横に長いので，x 軸の目盛りを $\pi/2$ ごとに取り，ラベルは `"$\\pi$"`，`"$2\\pi$"`，`"$\\frac{\\pi}{2}$"`（斜線の `π/2` にしない）。分数の目盛りは高さがあるので，x 軸との間隔を PNG で確かめる。x と y は同じ縮尺が原則（x 軸の 3.14… の位置に $\pi$ の目盛りが来る）。
- 周期・振幅を示すときは `dimension` で寸法線を入れる。
