## 1. 力の図

描く前に，力の大きさをすべて同じ単位で計算する。手順は次のとおり。

1. **尺度を決める。** `fig.set_force_scale(2.3)` は「大きさ 1 の力を長さ 2.3 で描く」。基準は図の中で最も大きい力（多くは $mg$）を 1 とし，その矢印が図に収まる長さにする。
2. **全部の力の大きさを同じ単位で計算する。** 斜面上の静止なら $mg=1$，$N=\cos\theta$，$F=\sin\theta$。大きさが未知の力も，つり合いや運動方程式と矛盾しない値を置く。
3. **`force_polar(作用点, 大きさ, 向き)` で描く。** 長さを個別に手で決めない。ベクトルで渡す `force(作用点, v)` を使うときも，`fig.force_len(大きさ)` で長さを出す。
4. **つり合いの図は `fig.force_balance()` を呼ぶ。** 矢印のベクトル和が 0 でないと警告が出る。
5. **PNG でつり合う力どうしの長さを比べる。** 垂直抗力と $mg\cos\theta$ の破線，摩擦力と $mg\sin\theta$ の破線が同じ長さに見えるか。数値が合っていても，矢印の根元が物体や他の矢印に隠れると短く見える。

その他の規約。

- 力は太い矢印（太さ 2.2）。物体の輪郭（1.5）や補助線（1.0）と区別が付く。
- **作用点から引く。** 重力は重心から鉛直下向き。垂直抗力・摩擦力は接触面上の点から。張力は糸の付け根から糸に沿って。弾性力はばねの付け根から。
- **静止している物体の垂直抗力・摩擦力の作用点**は，重力の作用線が接触面と交わる点に取る（3力がつり合うとき，作用線は1点で交わる）。`hs.intersect_lines(G, hs.add(G, (0, -1)), 面の点1, 面の点2)`。こうすると垂直抗力の矢印が重心を通らず，根元が見えるので長さを比べやすい。作用点には黒丸を打つ（`dot=True`）。
- **接触面に沿う力（摩擦力など）は面の線に重ねない。** 物体側へ線幅の3〜4倍ずらす（`shift=5`。`shift` は矢印の向きに対して左が正）。
- 同一直線上に重なる2つの力（水平面上の重力と垂直抗力など）は，作用点が違う（重心と接触面）ことを黒丸で示し，矢印が重なって長さが読めないときは一方を横に 5px 前後ずらす（`shift`）。
- 名前はイタリック（$mg$，$N$，$T$，$F$，$f$，$kx$）で矢印の先の近く。矢印の線に重ねない（`dir=` で向きを指定）。
- 物体は長方形（`block`）か円。物体は白か薄い灰色で塗り，下の線を隠す。**質量 $m$ は物体の内側**に置く：`block(..., label="$m$")`。力の矢印が中央を通るときは `label_at=(0.62, 0.42)` のように物体の中の空いた所へずらす。物体の外の角には置かない。
- 床・壁・天井は `ground(A, B, side)`（線と片側の斜線）。`side=-1` は A→B の右側（左から右へ引けば下側）に斜線。
- 力の分解は `components(作用点, 力のベクトル, 向き, labels=(…, …))`。2つの分力の破線の矢印と，長方形を閉じる破線を描く。
- 加速度・速度の向きを添えるときは，力と区別するために物体の外に細い矢印で描き，$a$，$v$ と名前を付ける。

## 2. 斜面

- 斜面は直角三角形（`polygon`）。傾きの角は実際の角度で描く（$\theta=30°$ なら 30°）。角度が一般の $\theta$ のときは 25〜35° 程度にし，30° や 45° と決めつけた計算をしない。
- 角の印は底辺の頂点に `angle_mark(..., r=34, label="$\\theta$")`。斜面が長いと角が小さく見えるので半径を大きめにする。
- 物体は `block(底辺の中点, 幅, 高さ, angle=θ)`。底辺の中点は斜面上の点 `hs.mul(hs.polar(1, θ), s)`。戻り値の `"center"` が重心。
- 斜面に沿う向きは `θ`，垂直な向きは `θ+90`（度）。
- 重力の分解は `components(G, 重力のベクトル, θ, ...)`。重力と $mg\cos\theta$ の成分の間の角に $\theta$ を入れる。
- 力と分力の長さは同じ尺度なので，$N$ と $mg\cos\theta$，$F$ と $mg\sin\theta$ は同じ長さ・逆向きになる。

```python
th = 30
c, s = math.cos(math.radians(th)), math.sin(math.radians(th))
e, Q = hs.polar(1, th), (7, 7 * s / c)
fig = Figure(-0.6, 8.0, -0.5, 5.3, unit=50, title="…", desc="…")
fig.set_force_scale(2.3)                                  # mg = 1 を長さ 2.3 で
fig.ground((-0.4, 0), (7.8, 0))
fig.polygon([(0, 0), (7, 0), Q])
fig.angle_mark((7, 0), (0, 0), Q, r=34, label="$\\theta$")
blk = fig.block(hs.mul(e, 5.2), 1.5, 0.9, angle=th, fill="#e6e6e6", label="$m$", label_at=(0.62, 0.42))
G = blk["center"]
P = hs.intersect_lines(G, hs.add(G, (0, -1)), (0, 0), Q)  # 重力の作用線と斜面の交点
v1, v2 = fig.components(G, (0, -fig.force_len(1)), th,
                        labels=("$mg\\sin\\theta$", "$mg\\cos\\theta$"), dirs=("W", "E"))
fig.angle_mark(hs.add(G, (0, -1)), G, hs.add(G, v2), r=44, label="$\\theta$")
fig.force_polar(G, 1, -90, "$mg$", dir="SW", dot=True)
fig.force_polar(P, c, th + 90, "$N$", dot=True)           # N = mg cosθ
fig.force_polar(P, s, th, "$F$", dir=th - 90, dist=7, shift=5)   # F = mg sinθ，物体側へずらす
fig.force_balance()
```

## 3. ばね・滑車・糸

- ばねは `spring(A, B, n=6)`（ジグザグ。両端に短い直線部）。自然長と伸びた状態を並べる図では，山の数を同じにして長さだけ変える。伸び $x$ は `dimension` で示す。
- 糸は細い実線（`segment(..., style="aux")`）。滑車に掛かる糸は，滑車の円に接する位置から出す（鉛直に垂らすなら，中心から左右に半径だけ離れた点）。斜めに出る糸の接点は `hs.tangent_points(糸の先の点, 中心, 半径)` で求める。
- 滑車は `pulley(中心, 半径)`（円と軸の黒丸）。天井から吊るす線と `ground(..., side=1)` の天井を添える。動滑車は軸からおもりを吊る。
- おもりは `block`。質量 $m$，$M$ は物体の内側に置く（`label="$m$"`）。

## 4. 回路図（JIS C 0617）

2004 年度以降の教科書は新 JIS の記号を使う。旧記号（ギザギザの抵抗，ループのコイル）は使わない。

| 素子 | 記号 | 関数 |
|---|---|---|
| 抵抗 | 長方形（縦横 1:3） | `resistor(A, B, "$R$")` |
| 可変抵抗 | 長方形に斜めの矢印 | `resistor(..., variable=True)` |
| コンデンサ | 同じ長さの平行な2線 | `capacitor(A, B, "$C$")` |
| 電池・直流電源 | 長く細い線（正極）と短く太い線（負極） | `battery(A, B, "$E$", plus_at_a=True)` |
| コイル | 半円を4つ並べる | `inductor(A, B, "$L$")` |
| スイッチ | 片側から斜めに上がる線 | `switch(A, B, "S", closed=False)` |
| 電球 | 円に× | `lamp(A, B)` |
| 電流計・電圧計・検流計 | 円に立体の A・V・G | `ammeter` `voltmeter` `meter(A, B, "G")` |
| 交流電源 | 円に正弦波 | `ac_source(A, B)` |
| 導線，分岐点 | 線，黒丸 | `wire(P, Q, ...)` `junction(P)` |

- 素子は2点 A, B の中点に置かれ，両側の導線も一緒に引かれる。回路は格子状の座標（角の点）を決めて，辺ごとに素子か `wire` を置く。
- 配線は水平・垂直だけ。交差させない配置を先に考える。つながっている分岐点には黒丸（`junction`），角（曲がるだけの点）には付けない。
- 名前の位置は `side` で選ぶ。`side=1` は A→B の進行方向の左側（左から右へ引けば上），`side=-1` は右側。コイルの半円の膨らむ側，スイッチの開く側も `side` に従う。
- 電池の向きは回路の意味を決めるので，`plus_at_a` を必ず意識して指定し，PNG で長い線がどちら側かを確かめる。
- 電流の向きを示すときは，導線に沿って外側に細い矢印（`arrow(..., style="aux")`）と $I$。導線の上に矢じりを直接載せるなら `segment(..., style="circuit", arrow="mid")`。
- 名前は量の記号ならイタリック（$R_1$，$C$，$E$，$L$），スイッチの S や計器の文字は立体。値を書くなら `"$R$"` の代わりに `"10 Ω"`（数字と単位は立体，間に空白）。
- 電圧計は測る素子と並列，電流計は直列。図の位置関係がそうなっているか確かめる。

```python
fig.battery((0, 3), (0, 0), "$E$", side=-1)      # 上が正極
fig.switch((0, 3), (2.6, 3), "S")
fig.resistor((2.6, 3), (6, 3), "$R$")
fig.lamp((6, 3), (6, 0))
fig.ammeter((6, 0), (0, 0))
fig.wire((6, 3), (7.6, 3)); fig.voltmeter((7.6, 3), (7.6, 0)); fig.wire((7.6, 0), (6, 0))
fig.junction((6, 3)); fig.junction((6, 0))
```

## 5. 波形

- $y$-$x$ グラフ（ある時刻の波形）と $y$-$t$ グラフ（ある点の振動）を取り違えない。横軸のラベル（$x$ か $t$）と単位を必ず入れる。
- 正弦波は `plot(lambda x: A*math.sin(2*math.pi*x/lam), 0, 端)`。振幅 $A$，波長 $\lambda$（または周期 $T$）の位置に目盛りを入れる。
- 縦横の縮尺は違ってよい（`unit` と `yunit`）。その代わり，振幅と波長を目盛りか `dimension` で読めるようにする。$y$-$x$ グラフで縦を拡大したら（変位も長さなので）「※ 縦軸方向は拡大して描いてある」と注記する（`fig.note`）。
- 進む向きは波形の上か横に矢印と $v$。少し後の波形を重ねるなら破線にする。
- 媒質の速度の向き（各点の上下の矢印）は，進行方向へ少しずらした波形との差から決める。
- 定常波は，両端の振動状態を実線と破線の2本で描き，節と腹の位置を計算した値（$\lambda/2$ ごと）に置く。
- 縦波の疎密を横波表示にする図は，変位の向きの約束（x 軸正の向きの変位を y 軸正に）を `<desc>` に書く。

## 6. レンズの光線図

- 像の位置と大きさは `b, m = hs.lens_image(a, f)` で計算する（$1/a + 1/b = 1/f$，$m = -b/a$）。$b>0$ は後方の実像（倒立），$b<0$ は前方の虚像（正立）。凹レンズは $f<0$ を渡す。
- 光軸は一点鎖線（`optical_axis()`）。レンズは `lens(0, 半分の高さ)`（凸）か `kind="concave"`。光線はレンズの中心面（x=0）で1回だけ折る（薄いレンズの近似）。
- 物体と像は光軸から立つ矢印（`arrow`）。焦点は黒丸と F，F′（立体）。レンズの中心は O。
- 代表的な3本の光線（凸レンズ・実像の場合。物体の先端 `tip=(-a, h)`，像の先端 `img=(b, m*h)`）：

| 光線 | 経路 |
|---|---|
| 光軸に平行 → 後方の焦点を通る | `ray(tip, (0, h), img)` |
| レンズの中心を直進 | `ray(tip, img)` |
| 前方の焦点を通る → 光軸に平行 | `ray(tip, (0, m*h), img)` |

  3本が像の先端で1点に交わることが，計算と作図が合っている確認になる。
- 虚像（$a<f$ の凸レンズ，凹レンズ）は，屈折後の光線を後方へ実線で伸ばし，前方への延長を破線（`ray(..., dash=True)`）で描いて，延長が虚像の先端で交わるようにする。虚像の矢印も破線。
- 光線の矢じりが焦点の黒丸や他の線と重なるときは，`ray(..., at=0.3)` で位置をずらす。
- 図は横に長くなる。光軸方向と高さ方向は同じ縮尺にする（違えると屈折の角度が変わって見える）。
- $a$，$b$，$f$ の長さを示すなら，光軸の下に `dimension` を段を分けて入れる。

鏡（平面鏡・凹面鏡）も同じ考え方で，反射の法則や写像公式で点を計算してから線を引く。

## 7. v-t グラフなどの運動のグラフ

- 軸は `xaxis("$t$")`，`yaxis("$v$")`。単位を付けるなら `xaxis("$t$ [s]", label_dir="N")`，`yaxis("$v$ [m/s]", label_dir="E")` のように，長い名前がはみ出さない向きに置く（単位は立体，角括弧は教科書の表記に合わせる）。窓の右端・上端には目盛りを置かない（軸の名前と重なる）。
- 縦横の縮尺は違ってよい（`Figure(0, 10, 0, 6, unit=30, yunit=40)`）。読み取る値（折れ目の時刻，速度）には必ず数値の目盛りと破線を入れる。目盛りが $v_0$，$t_1$ のような記号だけの概形グラフは `Figure(..., aspect_ok=True)` とする（縦横が別の量なので拡大の注記は要らない）。
- 折れ線は `polyline([(0,0), (4,8), (10,8)])`。折れ目の座標は等加速度の式で計算する。
- 面積（移動距離）は `hatch(多角形)`。傾き（加速度）を示すなら，三角形の補助線と $\Delta t$，$\Delta v$。
- x-t グラフの放物線は `plot`。接線の傾きが速度であることを見せるなら，`tangent_at` で接線を引く。
- 第1象限だけを使うなら，窓を 0 から始め，左と下の余白を広めに取る（`margin=(40, 28, 28, 36)`）。負の速度があるなら x 軸の下も含める。

## 8. 磁場・電流

- 紙面に垂直な向き：`field_mark(P, into=True)` が ⊗（表→裏），`into=False` が ⊙（裏→表）。一様な磁場は格子状に並べる。
- 直線電流のまわりの磁場は同心円（`circle` または `arc`）に向きの矢じり（`arc(O, r, 20, 340, arrow="mid")`）。右ねじの法則と向きが合っているか確かめる：電流が ⊙（手前向き）なら磁場は反時計回り。
- 磁力線は N 極から出て S 極に入る。線の途中に矢じり（`segment(..., arrow="mid")`）。磁石は長方形に N，S（立体）。
- 電流 $I$，磁束密度 $B$，力 $F$，速度 $v$ を1枚に描くときは，3つの向きの関係（フレミングの左手の法則，ローレンツ力）を計算で確かめてから矢印を引く。電流は導線に沿う矢印，力は太い矢印。
- 電場の電気力線は正電荷から出て負電荷に入る。本数は電気量に比例させ，交差させない。等電位線は破線。
- ソレノイドは，長方形の芯に巻き線を等間隔の斜線で描く簡略図にとどめ，電流の向きを矢印で示す。
