# 作図の原則

新規作図と Mode A（手描きの清書）に使う。Mode B（原図の再現）では原図が決めていることを優先し，ここは原図が決めていない事項にだけ使う。数値の既定値は [conventions.md](conventions.md) の「既定値」にまとめてある。

各原則は「何を守るか」と「判断の基準」で書く。例は理解に要るものだけを1つ添える。

## 1. 位置は計算で決める

**守るもの**：図が問題の条件と矛盾しないこと。
**基準**：交点・接点・垂線の足・中点・像・極値など，条件から決まる位置は式や幾何から求め，目分量で置かない。条件から決まらない形（一般の三角形，未知の大きさの力）は，特別な場合（二等辺・直角・特定の角）に見えない値を選ぶ。描いたあと，決まった関係（接する，通る，交わる）が画面上で成り立っているかを拡大して確かめる。

## 2. 縮尺は意味を保つ

**守るもの**：図から読み取れる比や形が，実際と食い違わないこと。
**基準**：形や角に意味がある図は縦横同じ縮尺にする。比べる量（つり合う力，長さ）は共通の尺度で描く。縮尺を変える・誇張するのは，同じ縮尺では読めないときだけにし，そのときは読者に分かるようにする（数値の目盛りか，縮尺が違う・模式図である旨の注記）。
例：大きさが分かっている力は共通の尺度で描くので，つり合う2力は同じ長さ，直角に分けた分力は元の力より短くなる。

## 3. 条件にある関係だけを印で示す

**守るもの**：図が条件以上のことを主張しないこと。
**基準**：直角・等長・等角・平行・含む／含まない，など条件にある関係は印で示す。条件から導けない関係の印を足さない。Mode A では筆者が書いていない要素（数値，補助線，分解した力）を足さない。

## 4. 1つの意味に1つの線種

**守るもの**：線を見ただけで，その線が何か（本体・補助・境界・隠れ線・軸）が分かること。
**基準**：意味の違う線に同じ線種を使わない。同じ意味の線は同じ線種・同じ太さにそろえる（一部だけ太くすると別の意味に読まれる）。線が軸や他の線と重なるときは，太さか位置で見分けが付くようにする。線種の区別の説明はキャプションに書く。
例：含まない境界線と，座標を読むための補助線は，どちらも破線にすると見分けが付かないので別の線種にする。

## 5. 文字・印は意味のある線や形を隠さず，接しない

**守るもの**：すべての文字が読め，すべての線・形が欠けずに見えること。
**基準**：文字（白い下地を含む），矢じり，矢印，点の印は，意味を持つ線・図形・他の文字を隠したり接したりしない。どの文字がどの対象を指すか迷わない位置（対象の近く，他の対象から離れた側）に置く。置き場が無ければ，向きを変える → 余白を広げる → 図の縮尺を上げる → 引き出し線で外へ出す，の順に対処し，文字を小さくして押し込まない。引き出し線も他の線や領域を横切らせない。
例：分力と合力の名前を矢印の同じ側に置くと接して紛れるので，互いに反対側へ置く。

## 6. 掲載したときの大きさで読めること

**守るもの**：教材に置いた最終の表示で，文字・矢じり・寸法・短い区間が読めること。
**基準**：大きさは表示幅で測る（図が表示幅より広ければ縮んだ後で測る）。文字・矢印・寸法の区間が既定の下限を割るなら，図を大きくするか要素を減らす・分ける。短すぎて寸法が付けられない区間は，誇張して模式図と断るか拡大図にする。

## 7. 図中には記号と短いラベル，説明は本文

**守るもの**：図が本文と二重にならず，図の中が説明文で埋まらないこと。
**基準**：図に置くのは記号・短い名称・短い式や量のラベル。説明文・凡例・記号の意味・線種の区別・関係を述べる式や長い式・状況の説明は，図の直下の本文（キャプション）に書く。図の下の注記は縮尺や模式図の断り1文だけ。Mode B で原図にあるものは写す。

## 8. 本文と図で記号をそろえる

**守るもの**：読者が本文と図を同じものとして対応づけられること。
**基準**：本文で使う点・線・角・量・軸・素子の名前は，同じ文字・同じ字形・同じ書体で図に入れ，図にだけある記号を作らない。主変数の角は弧で示す。本文の式に現れる量（力・圧力・場・電荷）や，向きの根拠に使った前提は図にもある。問題の図から省いたものはキャプションで挙げ，本文で参照する名前は図に残す。

## 9. 状況と視点を1つに決める

**守るもの**：1枚の図が1つの状況・1つの視点を表すこと。
**基準**：対象物・時刻・観測者・視点を決めてから描く。2つの状況（前後，置き換え）を比べるなら，同じ縮尺で並べた別の図にする。重ねるのは動いた量を示すときだけで，線種で区別しキャプションで説明する。選択肢の向きを問う問題では問題の図と同じ視点で描き，選択肢の矢印と求めた向きを並べる。

## 10. 白黒で区別できること

**守るもの**：白黒で印刷しても，区別すべきものが区別できること。
**基準**：区別は線種・塗り・名前で付け，色や灰色の濃淡だけに頼らない。性質の違う領域（気体・液体・固体，2つの領域）は塗りや斜線の向きで分ける。背景は白で塗る。原図に色があるときだけ，その色を写す（`data-source-colors`）。

## 11. 書体は本文の数式と同じ規則

**守るもの**：図の文字が本文の数式と同じものに見えること。
**基準**：変数・量・定数は斜体，点・物体・素子の名前，数字，関数名，単位，元素記号，和文は立体。分数は縦組み，添字・指数は正しい高さで，後ろの文字は基線に戻す。記号は正しい文字（負号 −，プライム ′，度 °）を使い，形の似た別の文字で代用しない。

## 一般化できない固有の約束

教科書・規格で決まっている描き方。理由から導けないので覚えておく。

| 分野 | 約束 |
|---|---|
| 共通 | 直角の印は小さな正方形。等しい角は弧の本数，等しい辺は辺を横切る短線の本数で組を示す。含む境界は実線，含まない境界は破線。端点は含むなら黒丸，含まないなら白丸。立体の隠れる辺は破線 |
| 座標 | 軸の正の向きに矢じり1つ，軸名は正の端，原点 O は空いた象限 |
| 空間図形 | 斜投影は x 軸を手前（左下），y 軸を右，z 軸を上に取り，奥行きを縮める（教科書の座標空間の向き） |
| 回路 | JIS の記号（抵抗は長方形，コイルは半円の列）。電池は長い線が正極。分岐点に黒丸，交差するだけの所には付けない。電圧計は並列，電流計は直列 |
| 場 | 紙面の表から裏は ⊗，裏から表は ⊙。磁力線は N から S，電気力線は正電荷から負電荷へ，交差させない。強弱は印・線の密度で示す |
| 光 | 光軸は一点鎖線。実際の光線は実線，虚像を作る延長は破線。薄いレンズの光線はレンズの中心面で1回折る |
| 波 | 波形（$y$-$x$）と振動（$y$-$t$）は横軸で区別する。波長は同時刻の同位相点間，周期は同じ場所の同位相時刻間 |
| 運動・状態のグラフ | 軸に量と単位。各過程の向きは線の途中の矢じり。状態量の値は軸の目盛りに置く |
| 化学 | 元素記号・状態記号は立体，原子数は右下，電荷は右上（大きさ，符号の順）。骨格式の無表示の頂点は炭素。くさびの黒は手前，破線は奥。平衡は ⇌。電気分解の陽極は電源の正極側 |
