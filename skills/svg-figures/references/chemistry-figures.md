# 高校化学の作図

## 化学式を組む

元素記号は立体。Cl の小文字 l と大文字 I を区別する。係数は基線上に置き、原子数は下付き、電荷は大きさ・符号の順で上付きにする（2 H₂O、Na⁺、SO₄²⁻、Fe³⁺）。単位電荷の 1 は省く。状態記号 (s)、(l)、(g)、(aq) は立体のまま式に続ける。Mode A では H₂O (l) のように間隔をそろえ、B では原図の空白・改行を写す。「触媒」「加熱」「陽極」「陰極」も編集できる文字で組む。

[scripts/chemistry_symbols.py](../scripts/chemistry_symbols.py) の関数は SVG 断片を返す。座標は左上原点の px、y は下向き。線は親の `<g fill="none" stroke="black" stroke-width="1.5">` に入れる。色が役割を表すときは採色し、平塗りにしてルートに `data-source-colors` を宣言する。暗い黒板の明るい字は白地に暗く描く。

```python
from hsfig import Figure
from chemistry_symbols import formula, reaction_arrow, atom_label, bond_to_atom
fig = Figure(0, 440, 0, 108, unit=1, margin=0, title="アンモニアの合成",
             desc="触媒と加熱条件を平衡の矢印に添える。")
left = formula(16, 64, "N₂ (g) + 3 H₂ (g)")
arrow = reaction_arrow(184, 278, 58, kind="⇌", above="触媒", below="加熱")
right = formula(300, 64, "2 NH₃ (g)")
fig.add_svg(left, arrow, right)
fig.save("equilibrium.svg")
```

`formula` と `atom_label` には Unicode の下付き・上付き文字を渡す。通常の数字は係数などの基線上の数字として残る。SVG には立体のセリフ（`CHEM_FONT`）の text と、本文の 75% のサイズで基線をずらした tspan が出る。掲載幅で本文 16 px、添字 12 px を確保する。構造式の原子名には `atom_label` を使う。

## 構造式と反応経路

- 骨格式では無表示の頂点と線端が炭素を表す。ヘテロ原子とその水素、電荷、原図にある孤立電子対（`lone_pair`）を残す。構造式に明示された C、H、O、N、Cl と CH₃、OH、H₂ などの基は、数式の斜体変数ではなく化学式の元素記号として組む。`atom_label(x,y,value,size)` は大文字の視覚的な中心に立体のセリフ（`CHEM_FONT`）を置き、下付き・電荷も `formula` と同じ規則で付ける。構造のグループには `data-role="chem-structure"` を付ける。斜体や数式用書体の原子名は lint が警告する。
- 結合は字形の手前で止める。`bond_to_atom(outer,centre,value,size)` は中心へ向かう線を原子のクリアランスで短くし、`bond(a,b,order=2)` は平行な二重線を描く。
- Mode A の六員環は正六角形を基準に結合長と角度をそろえる。ケクレ式では交互の二重結合を内側に置く。`benzene(centre,radius,style="circle")` は内接する円を描く。B では環の向き、頂点、二重線が付く辺や円の有無を写す。頂点列は二重線が付く辺から始められる。
- `wedge(tip,end)` の細い端は立体中心側。黒いくさびは手前、`hashes=6` のくさびは奥。二重結合の左右の置換基、環の表裏、cis・trans を確認する。見栄えのために片側だけを反転しない。
- 進行方向は →、平衡は ⇌（U+21CC）、原図が両矢印なら ↔。共鳴式を化学平衡に読み替えない。条件は対応する矢印の上下に置く。多段階では中間生成物を隣の段階と共有し、後処理や収率が図中にある場合は原図の段に付ける。

## 器具と電極

- `vessel(x,y,w,h,kind)` の基準点は口の中央。丸底（round）は球状の胴、三角（erlenmeyer）は平底と斜めの肩、ビーカー（beaker）は広口。水面は水平にする。`burette` は目盛・コック・細い先端をもつ。滴下する先端、受器、液面の上下関係を保つ。
- `condenser(a,b)` はリービッヒ冷却器の内管と外筒を同じ軸に沿わせ、冷却水の側口を外筒につなぐ。水は低い側から入り高い側から出る。蒸気や留出液と冷却水の経路を区別する。
- `gas_collection` は水槽の中に集気びんを倒立させる。びんの口は水没し、導管は口の下を回ってびんの内側に開く。原図にある水位・気泡・液面を読んで追加する。
- 電解槽は `vessel` と `electrode` を組み合わせる。浸した極板の上端を外部回路に接続する。電気分解の陽極は正極側、陰極は負極側。原図で極性が設問なら答えを追記せず、電極名と電源・端子の対応を写す。気泡は示された側だけに置く。

## エネルギー・結晶・曲線・周期表

- `graph_axes` の横軸を反応座標、縦軸をエネルギーとする。`energy_profile` に反応物、遷移状態の山、必要なら中間体の谷と次の山、生成物を順に渡す。活性化エネルギーの矢印はその段階の谷から山まで。ΔH または ΔU は始状態と終状態の差で、終状態が低い発熱図と高い吸熱図を区別する。触媒あり・なしで始点と終点の高さをそろえる。
- `unit_cell(origin,side,depth,kind)` は手前の左下を原点とし、奥行きを右上への共通ベクトルで与える。単純立方（simple）は頂点8個、体心（bcc）は体心1個を加え、面心（fcc）は6面の中心を加える。中心を投影して円で示す。隠れる3辺は破線。B では原図の省略や線の断ち方も確認し、奥の辺が実線の透視図に破線を足さない。
- `graph_axes` と `measured_curve` を併用し、目盛値から点を画面座標へ写す。滴定は滴下量と単位、縦軸の pH、急変部や緩衝域を読み取る。当量点・指示薬の変色域・実測の終点は別々に扱う。溶解度曲線は横軸に温度、縦軸に溶解度と基準量（例 g / 水 100 g）。濃度・溶解度積を扱う図は原図の量と単位、対数目盛を保つ。
- `element_tile` は原子番号と元素記号をもつ一枠。族は列、周期は行に置き、空所も保持する。Mode A は問題に要る範囲だけを読みやすく組む。B は見出し、枠の太さ、原子量、欄外の注記など原図にある項目と順を写す。複数曲線の凡例、化合物名や図番号も図の一部として切り出して重ねる。
