# 仕上げの点検

最終の掲載幅で描画した図を目で見て確かめる。番号は [principles.md](principles.md) の原則に対応する。1つでも当てはまれば直して描画し直す。Mode B は [image-to-svg.md](image-to-svg.md) の照合を先に行い，原図と違う所を原図に合わせる（ここの項目で原図を書き換えない）。

## 点検項目

1. **位置**：条件で決まる点・接点・交点・像が，線の上に正確にある。接線が曲線を横切らない。条件に無い特別な形（二等辺，直角）に見えない。
2. **縮尺**：形に意味のある図は縦横同じ縮尺。比べる量（つり合う力など）が描いた長さでも比べられる（根元や先が他の要素に隠れていない）。縮尺を変えた・誇張した図には目盛りか注記がある。
3. **印**：条件にある関係（直角・等長・含む／含まない）に印があり，条件に無い印が無い。Mode A で原図に無い要素を足していない。
4. **線種**：意味の違う線が見分けられ，同じ意味の線はそろっている。軸や他の線に重なる線も見分けられる。
5. **干渉**：文字・下地・矢じり・矢印・点の印が，意味のある線・図形・他の文字を隠したり接したりしていない。どの文字がどの対象のものか迷わない。引き出し線が他の線・領域を横切らない。
6. **大きさ**：表示幅で文字・矢じり・寸法の区間が既定の下限以上（[conventions.md](conventions.md)「既定値」）。
7. **図中の文字**：説明文・凡例・関係式・長い式が図に無い（Mode B で原図にあるものは除く）。注記は1文。
8. **本文との一致**：本文の記号・字形・名前が図と同じ。本文の式に現れる量と向きの根拠が図にある。省いたものはキャプションにある。
9. **状況と視点**：1枚に1つの状況・視点。比べる図は同じ縮尺で並び，重ねたなら区別がキャプションにある。
10. **白黒**：白黒で区別できる。背景が白。色は原図にある色だけ（`data-source-colors`）。
11. **書体と字形**：斜体・立体の区別，縦組みの分数，添字の高さと基線の戻り，−・′・° が正しい文字で表示され，和文が化けていない。

固有の約束（[principles.md](principles.md) の表）に合っているかも見る。回路では電池の向き・計器のつなぎ方・分岐点，光線図では像の先端で光線が1点に交わるか，向きの図では法則どおりの向きかを，計算と照らす。

## レンダラー

- 確認は Chrome／Chromium のヘッドレス（`render_png.py` の既定）か `rsvg-convert` で行う。
- cairosvg は tspan を含む文字（斜体と立体の混在，添字）の位置を崩すことがある。cairosvg でしか確認できなかった図は，文字の位置を未確認として伝える。
- 細部が見えないときは拡大して描画する（`render_png.py --scale 3`）。

## lint の指摘の読み方

`lint_svg.py` の文字の箱は字数と font-size からの概算なので，WARN は「見に行く場所」の案内と考え，描画した図で判断する。lint で分からない正しさ（1〜3）は必ず目で見る。

| 指摘 | 対処 |
|---|---|
| ERROR（整形式でない，viewBox・title が無い，外部参照，文字が viewBox の外） | 必ず直す |
| 文字どうしが重なる | ほぼ確実に重なっているので直す |
| 文字に線が重なる／太い矢印が文字に接する／引き出し線が横切る | 描画で確かめて配置を変える（原則5）。白い下地つきで意図して重ねた文字は `data-lint="skip"` |
| 本文字・最小の文字が小さい／寸法の区間が短い | 図を表示幅以下にして作り直す，縮尺を上げる，誇張・拡大図にする（原則6） |
| 説明文になっている／注記が2文以上 | キャプションへ移す（原則7） |
| 斜線の分数／座標のカンマ／度の記号 | 直す（原則11）。単位の `m/s` が候補に出たときは，単位か分数かを照合して判断する |
| 色・構造式の原子名の書体 | 原則10・11 と固有の約束に合わせる |
| 線が viewBox の外に出る | 窓の端で切れてよい線でなければ窓を広げる |
| 意図仕様との照合（Mode A） | 仕様の文字・印を図に入れる，仕様に無い文字を外す，`[?]` を描かない |

`hsfig` の `save()` が出す警告も同じ扱いで，1つずつ描画で確かめて直す。
