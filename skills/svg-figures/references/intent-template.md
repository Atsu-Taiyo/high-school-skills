# 手書き図の意図仕様（`<図>.intent.md`）

手書きはデフォルメされている。線の揺れ、傾き、比率の崩れは「意図」ではない。描く前に、**この図は結局何を伝えたいのか**を読み取り、この仕様を書く。図と同じ場所に、`figure.svg` なら `figure.intent.md` として保存する。`lint_svg.py --strict` が、仕様に書いた文字・印が図にあるか、仕様にない文字を足していないかを照合する。

## 書式（見出しごとに箇条書き）

```md
## 伝えたいこと
一文で。何を示す図か（示したい領域・量・関係・状況）。

## 対象と関係
- 対象: 曲線・直線・領域・立体・ベクトル・装置など。式や名前で確定して書く
- 関係: 対称、平行・垂直、等長、角、接点、交点、比。交点・頂点・切り口は式や幾何から計算した値で書く

## 本質の印
- 斜線: どの領域を表すか [hatch]
- 破線: 補助線か、含まない境界か [dashed]
- 白丸 / 黒丸: 含まない点 / 含む点・頂点 [open-point] / [dot]
- 角の印・等長印 [angle]
- 矢印: 向きの意味 [arrow]
- 図題・注記 [caption]

## 文字
- `図に書く文字`（1行1件。数式は TeX 可。薄い・小さい文字も、原図にあれば書く）

## 読めない
- [?] 判読できない文字の位置。候補は 「…」 で書けるが、図には描かない

## 歪みの補正
- 直すもの（揺れた線、崩れた対称・比率、不揃いの寸法）と、その基準

## 投影（立体のとき）
- 選んだ投影（斜投影・等角など）、軸の向きと比、隠れ線の扱い
```

## 手順の考え方

1. **意図を先に**。図の周囲の式・説明も読み、示したい領域や量を決める。線をなぞらない。
2. **対象と関係を確定**する。式・対称・平行・等長・角・接点・交点を式や幾何から求め、仕様に書く。描く座標はこの値から決める。
3. **印の意味**を決める。斜線は何の領域か、白丸と黒丸はどちらの境界か、破線は補助か除外か。
4. **正確に描く**。手書きの歪みは直し、立体は一つの投影で一貫させる。
5. **筆者が書いたものだけ**。ラベル・数値・図形を足さない。読めない文字は `[?]` として図から外す。
6. **薄くても意味のある印**（小さな数字、目盛り、短い斜線、白丸）は、必ず「文字」「本質の印」に書き、必ず描く。
7. 図の外の本文（解答文の結果など）は図に入れない。筆者が図に書いていない値を足さない。
8. 印には種類タグ（`[hatch]` `[dashed]` `[open-point]` `[dot]` `[angle]` `[arrow]` `[caption]`）を付ける。lint が図に対応するものがあるか確かめる。
