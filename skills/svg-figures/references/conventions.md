# 体裁の規約と SVG 断片

`hsfig.py` はここに書いた規約どおりに出力する。手で SVG を書く・既存の SVG を直すときは，この骨組みと断片を使う。

## 骨組み

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="296" height="352" viewBox="0 0 296 352"
     role="img" aria-labelledby="fig1-t fig1-d">
  <title id="fig1-t">放物線と直線で囲まれた部分</title>
  <desc id="fig1-d">放物線 y=x^2 と直線 y=x+2 が x=-1, 2 で交わり，囲まれた部分に斜線を引いた図</desc>
  <defs><!-- 矢じりの marker --></defs>
  <rect x="0" y="0" width="296" height="352" fill="#fff"/>
  <g fill="none" stroke="#000" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">
    <!-- 線・図形 -->
  </g>
  <g font-family="'Times New Roman', Times, 'Nimbus Roman', 'Liberation Serif', 'Hiragino Mincho ProN', 'Yu Mincho', 'Noto Serif CJK JP', serif"
     font-size="16" fill="#000" stroke="none" text-anchor="middle">
    <!-- 文字（最後に置き，線の上に来るようにする） -->
  </g>
</svg>
```

- `viewBox` は `0 0 幅 高さ`。`width`/`height` は表示サイズで，既定は viewBox と同じ px。印刷物の寸法に合わせるなら `width="60mm"` のように変え，viewBox はそのままにする（線幅と文字が一緒に縮むので，縮めた後の文字が「文字の大きさと表示幅」の基準を下回らないか確かめる）。
- 画面で読む教材の本文は 16px 前後なので，図中の本文字も 16px にする（印刷では 1px を 0.75pt と考え，16px が 12pt）。図の幅は 300〜600px が扱いやすい。表示幅（既定 650px）を超えない。
- `id` は図ごとに違う接頭辞を付ける（HTML に複数の SVG を埋め込むと，同じ `id` の marker や title が衝突する）。
- 外部リソース（`<image>`，外部フォント，`@import`，`<script>`，外部への `href`）は使わない。`<style>` と class による装飾も使わず，表示属性（`stroke-width="1"` など）を要素に直接書く。`<style>` を落とす環境でも崩れない。
- `transform` は原則使わない。数学座標から px への変換（y の反転）は生成時に計算で済ませ，SVG には px の座標だけを書く。文字が裏返る事故が起きず，lint も座標をそのまま読める。
- 座標は小数第2位まで。

## 座標の変換

数学座標 $(x, y)$ を px の $(X, Y)$ にする式は1か所に置く。

```
X = 左余白 + (x − xmin) × unit
Y = 上余白 + (ymax − y) × unit      ← y の反転はここだけ
```

余白は 28px 前後（軸のラベルや頂点の名前が入る幅）。ラベルがはみ出すなら，窓か余白を広げる。図を縮めて押し込まない。

## 線

| 用途 | 太さ | 破線 | `hsfig` の style |
|---|---|---|---|
| 図形の本体，関数のグラフ | 1.5 | — | `main` |
| 補助線，角の弧，直角記号，等長の印，光線 | 1.0 | — | `aux` |
| 座標軸 | 1.0 | — | `axis` |
| 補助の破線，見えない辺，漸近線 | 1.0 | `5 3` | `dash` / `hidden` |
| 領域の境界線（含まない） | 1.5 | `7 3.5` | `bound` |
| 座標を読む補助線（点から軸へ下ろす線） | 0.7 | `2 2.5`（細い点線） | `guide` |
| 軸・補助線と重なるグラフの線（サイクルの過程など） | 2.2 | — | `heavy` |
| 光軸，対称軸 | 1.0 | `9 3 1.5 3`（一点鎖線） | `chain` |
| 点線（2本目のグラフの区別など） | 1.0 | `1.5 3.5` | `dot` |
| 力の矢印 | 2.2 | — | `force` |
| 回路の配線と素子 | 1.2 | — | `circuit` |
| ハッチ，寸法の引き出し線 | 0.6 | — | `thin` |

- 端は丸（`stroke-linecap="round"`），角も丸（`stroke-linejoin="round"`）。破線だけは `stroke-linecap="butt"` にする（丸だと破線の切れ目が詰まる）。
- 2本のグラフを区別するときは，実線と破線（または点線）で分ける。色や太さの微妙な差で区別しない。
- **同じ図の中で，意味の違う線に同じ線種を使わない。** 特に領域の図では，含まない境界線（`bound`）と，目盛りを読むための補助線（`guide`）を描き分ける。境界線は境界になっている区間だけに引き，その先を軸まで延ばすなら `guide` に切り替える。含む境界線は実線。
- **軸の上に乗る線**（縦軸に重なる定積変化など）は，軸より明らかに太くする（`heavy`）。1本だけ太くすると別の意味に読まれるので，同じ種類の線（サイクルの全過程）をまとめて太くする。矢印が軸と重なるときは，数 px 平行にずらすか，太く大きくする。
- **自由な形**（たるんだ導線，ひも，液面のゆらぎ）は，通過点を3〜6個決めて `fig.smooth([...])` でなめらかに結ぶ。折れ線で描くと角が立ち，意味のない形に見える。図の主役でなければ直線に単純化する。式で決まる曲線は `plot`・`arc` で正確に描く。

## 矢じり

```svg
<marker id="fig1-arr-e" markerUnits="userSpaceOnUse" markerWidth="9" markerHeight="6.4"
        refX="4" refY="3.2" orient="auto" overflow="visible">
  <path d="M0,0 L9,3.2 L0,6.4 L2.2,3.2 Z" fill="#000" stroke="none"/>
</marker>
...
<path d="M28,268 L263,268" stroke-width="1" marker-end="url(#fig1-arr-e)"/>
```

- 形は後ろがくびれた三角。大きさは線幅で決める：線幅 1.6 以下は長さ 9・幅 6.4，力の矢印（2.2）は長さ 12・幅 8.8，それより太い線は線幅に比例して大きくする。**矢じりの幅は線幅の4倍以上**（太線の上に小さい矢じりを載せると埋もれて向きが読めない）。寸法線・引き出し線（0.8）は小さい矢じり（長さ 7・幅 4.6）。
- `markerUnits="userSpaceOnUse"` にして，大きさを px で直接決める（`hsfig` は線幅に合う marker を選ぶ）。
- 線は終点の 5px 手前で止め，`refX` をその分ずらして矢じりの先が本来の終点に来るようにする（上の例は本来の終点が X=268。線が矢じりの先まで届いていると，先が四角く潰れる）。
- 始点側の矢じりは，向きを逆に描いた別の marker（`…-s`）を `marker-start` に使う。`orient="auto-start-reverse"` は SVG 2 の機能で，古いレンダラーが対応していないため使わない。
- 線の途中に向きを示す矢じり（光線，磁力線，電流，サイクルの過程の向き）は，その位置で終わる短い線を重ねて `marker-end` を付ける。`hsfig` では `segment(..., arrow="mid")`，折れ線の各辺は `polyline(..., arrow="mid")`，曲線は `mid_arrow(曲線上の点, その少し先の点)`。
- 向きを示したい線は太くしない。サイクル図は全過程を同じ太さ（1.5）で描き，矢じりは各過程の中央に置く。線種・太さを変えるなら，その意味を本文のキャプションで説明する。

## 点

```svg
<circle cx="188" cy="108" r="2.6" fill="#000" stroke="none"/>             <!-- 点 -->
<circle cx="188" cy="108" r="3" fill="#fff" stroke="#000" stroke-width="1.2"/>  <!-- 含まない点 -->
```

点は線より後に描く。白丸は下の線を隠すために白で塗る。

## 文字

```svg
<text x="62.4" y="92.6"><tspan font-style="italic">y</tspan> = <tspan font-style="italic">x</tspan><tspan font-size="12" dy="-6.4">2</tspan></text>
<text x="246" y="290">A</text>
<text x="80" y="60"><tspan font-style="italic">a</tspan><tspan font-size="12" dy="3.84"><tspan font-style="italic">n</tspan>+1</tspan></text>
```

| 立体（upright） | イタリック |
|---|---|
| 点の名前 A, B, C, P, Q，原点 O，焦点 F | 変数・定数 $x$, $y$, $a$, $b$, $k$, $t$ |
| 数字，演算記号，括弧 | 角 $\theta$, $\alpha$, $\beta$ |
| 関数名 sin, cos, tan, log | 物理量 $m$, $g$, $v$, $F$, $N$, $T$, $R$, $C$, $L$, $E$, $I$ |
| 単位 m, s, N, V, Ω | 関数 $f(x)$ の $f$ |
| 和文，計器の A・V，スイッチの S | 集合 $A$, $B$, $U$，面積 $S$ |

- 同じ「A」でも，点 A は立体，集合 $A$ はイタリック。本文での書体に合わせる。
- 負の符号は「−」（U+2212），プライムは「′」（U+2032）。ハイフンやアポストロフィで代用しない。
- 角度の ° は「°」（U+00B0）を数字と同じ大きさ・同じ基線で書く：`"$60^\\circ$"` または `"60°"`。「˚」（U+02DA）や上付きの小さな丸にしない（数字から離れて浮いて見える）。
- φ は本文と同じ字形にする。教科書の φ は LaTeX の `\varphi` の形なので，本文は `\varphi`，図は `"$\\varphi$"`（`hsfig` は `\\phi` も同じ φ にする）。
- 等号・不等号の両側には細い空き（U+2009）を入れる。`hsfig` の `$...$` 記法は自動で入れる。
- 添字・指数は `<tspan dy="…" font-size="12">`（本文字の 0.75 倍。12px を下回らない）。`baseline-shift` はレンダラーによって効かないので使わない。添字の後に通常の文字が続くときは，`dy` を逆向きに入れて基線を戻す。
- `text-anchor="middle"` で中心を決めて置く。文字幅はフォントで変わるので，左端揃えで細かく詰める組み方はしない。
- ベクトルの矢印は，文字の上に細い線（0.7）と小さな矢じりを別の `<path>` で描く。結合文字（U+20D7）はフォントによって位置がずれる。
- **分数は縦組み**にする（分子・括線・分母）。`5/6`，`π/2` のような斜線の分数は使わない。`hsfig` では `"$\\frac{5}{6}$"`。手で書くときは，分子と分母を別の `<text>`（どちらも括線の中央に `text-anchor="middle"`）にし，括線を細い線（0.8）で引く。括線は式の中心の高さ（基線の 0.3em 上）。分数の前後の文字は，分数の側に寄せて固定する（前は `text-anchor="end"`，後ろは `"start"`）。

  ```svg
  <text x="150" y="100" text-anchor="end"><tspan font-style="italic">M</tspan> = sin 1 − </text>
  <text x="158" y="92.2">5</text>
  <text x="158" y="108.7">6</text>
  <path d="M151.5,95.8 L164.5,95.8" stroke="#000" stroke-width="0.8"/>
  ```
- **座標はカンマの後に空白**を入れる：C(0, 0, 2)，P$(a, b)$。`C(0,0,2)` と詰めない。点の名前は立体，中の文字式はイタリック。
- 根号の中の長い式・積分記号・Σ など，上の記法で書けない式は図に入れない。記号（$S$，$l$ など）を図に置き，式は本文に書く。

## ラベルの置き方

- 点の名前は，点から 6px 離して，図形の外側へ。三角形なら重心と反対の向き，座標軸上の点なら軸の下（x 軸）か左（y 軸）。
- 線・曲線の名前（$y=x^2$，$l$）は，線の端の近くで，線から 4〜8px 離す。他の線が通らない側を選ぶ。
- 角の文字は，弧の外側，角の二等分線上。角が狭いときは弧の半径を大きくするか，文字を外に出す。
- 辺の長さは，辺の中点の外側。
- 物体の質量（$m$，$M$）は物体の内側に置く。力の矢印が中央を通るときは，物体の中の空いた所へずらす。物体の外の角には置かない。
- ラベルどうしは 2px 以上離す。力の分解の図では，分力の名前と合力の名前が上下に接しやすいので，一方を矢印の反対側へ回す（`save()` が「接している」と警告する）。
- **引き出し線**：2本の曲線がほぼ重なる場所の曲線名，混み合う場所の点・部品の名前は，対象から細い線（0.7）を引き出して，その先に文字を置く。`fig.leader("$y=f(x)$", 曲線上の点, 文字を置く点)`。
  - **引き出し線は，他の線・補助線・斜線の領域を横切らせない。** 曲線の名前は，領域と反対の側（曲線の外側）へ引き出す。2曲線にはさまれた領域の境界なら，それぞれ領域の外へ。横切るしかないなら，ラベルの置き場所を変える（2曲線が十分離れた所に直接置く）。`save()` と lint が交差を警告する。
  - 対象のすぐそば（文字1つ分以内）に置けるなら，引き出し線は使わない。
  - 長さ・高さ・間隔は寸法線で示し，引き出し線で「高さ…」と書かない。角の名前は角の弧に付ける（引き出し線だけで角を指さない）。
- **力の矢印とラベル**：矢印が物体の名前（A）や他のラベルを横切らない・接しないようにする。物体の名前は矢印の通らない隅へ（`block(..., label_at=…)`），力の名前は矢印の先の外側へ。接していると警告が出る。
- 置き場が無いときは，この順に対処する：別の向きにする → 窓・余白を広げる → 図の縮尺を上げる → 引き出し線で外へ出す → 白い下地を敷いて線の上に置く。文字を小さくして押し込まない。

## 図中に書かないもの

図中の文字は，記号（$F$，$\theta$，P）と短い名称（「可動壁」「液面」「物体」）だけにする。次のものは図に入れず，図の直下の本文（キャプション）に書く。

| 書かないもの | 例 | 置き場所 |
|---|---|---|
| 記号・印の説明，凡例 | 「⊙ は紙面の裏から表の向きの電流」 | キャプション |
| 式 | 「$F=IBl$」（図中は $F$ だけ） | 本文 |
| 状況の説明 | 「電流は 0」「スイッチを閉じて十分時間が経過した後」 | 図題・キャプション |
| 線種の意味 | 「実線：置き換え前，破線：置き換え後」 | キャプション |

図の下の注記（`note`）に書いてよいのは，縮尺・模式図の断りを1文だけ。文言はそろえる：「※ 縦軸方向は拡大して描いてある」「※ 縦軸方向と横軸方向の縮尺は異なる」「※ 角は誇張して描いてある」「※ 模式図（実際の長さの比とは異なる）」。`hsfig` と lint は，長い和文・句読点のある文・2文以上の注記を警告する。

## 文字の大きさと表示幅

大きさは**教材に置いたときの表示**で測る。数値基準は次のとおり（`hsfig` の `save()` と `lint_svg.py` が同じ基準で警告する）。

| 文字 | 表示での大きさ | viewBox の幅 $W$ が表示幅 $D$ より広いときの font-size |
|---|---|---|
| 本文字（点・量・線の名前，目盛り） | 16px 以上 | $16\times W\div D$ 以上 |
| 最小の文字（添字，指数，注記，計器の文字） | 12px 以上 | $12\times W\div D$ 以上 |

- 表示幅 $D$ は置き場所で決まる。分からなければ 650px（本文の幅 600〜700px）とする。`Figure(..., display_width=D)`，lint は `--display-width=D`。
- `hsfig` の既定は本文字 16px，添字・指数はその 0.75 倍（12px），注記 12px。$W\leqq D$ ならこのままで基準を満たす。**`size=` で一部のラベルだけ小さくしない**（添字が 12px を割る）。置き場が無いなら図を大きくする。
- $W>D$ の図は全体が $D\div W$ 倍に縮む。対処の順：`unit` を下げて $W\leqq D$ にする → 要素を減らす・2枚に分ける → `font_size` を $16\times W\div D$ に上げる。
- 逆に，小さな図（$W$ が 300px 未満）に多くのラベルを入れると，文字は基準どおりでも密集する。ラベルどうし・ラベルと線の間が取れる縮尺まで図を大きくする。

### 詰め込みの下限

| もの | 下限（px） | 足りないとき |
|---|---|---|
| 力の矢印の長さ | 36 | `set_force_scale` の尺度か `unit` を上げる |
| 寸法を付ける区間 | 28 | 縮尺を上げる／誇張して「※ 模式図」／拡大図 |
| 矢印が3本以上出る物体の一辺 | 60 | `unit` を上げる |
| ラベルと線・他のラベルの間 | 2 | 向きを変える・図を広げる |

## 縮尺を変えたときの注記

縦横の縮尺を変えた図（値が小さすぎる・大きすぎる関数のグラフなど）は，図の下に注記（12px）を入れる。

```svg
<text x="212" y="375" font-size="12">※ 縦軸方向は拡大して描いてある</text>
```

`hsfig` では `fig.note("※ 縦軸方向は拡大して描いてある")`（その分だけ図の高さが増える）。y 軸に数値の目盛り（0.005 など）を入れて縮尺が読めるなら，注記は無くてよい。`<title>`・`<desc>` に書くだけでは読者に伝わらない。

## 力の矢印

- 1枚の図の力は同じ尺度で描く（力の大きさ × 一定の長さ）。つり合う2力，力とその分力は同じ長さになる。
- 作用点が分かりにくいとき（矢印が物体や他の矢印を通るとき）は，作用点に小さな黒丸（半径 2.4）を打つ。
- **接触面に沿う力**（摩擦力，面に沿う張力）は，面の線の真上に描かない。物体側へ線幅の3〜4倍（5px 前後）平行にずらす。ずらせないときは，接触面の中点を作用点にして物体の内側寄りに描く。
- 分力は破線の矢印（太さ 1.0）で，元の力と長方形（平行四辺形）を作る破線を添える。

## ハッチング

面積や領域は 45° の斜線（間隔 5px，太さ 0.6）で示す。2種類を区別するときは，向き（45° と 135°）と間隔を変える。

`hsfig.hatch()` は，領域の多角形と各斜線の交点を計算して，切り取った線分だけを1つの `<path class="hatch">` に書く。`clipPath` を使わないので，`id` の衝突やレンダラーの差が出ない。

手で書くときは `clipPath` を使ってよい。

```svg
<defs>
  <clipPath id="fig1-clip"><path d="M148,228 L…（領域の境界）… Z"/></clipPath>
</defs>
<g class="hatch" clip-path="url(#fig1-clip)" stroke="#000" stroke-width="0.6">
  <path d="M100,300 L300,100 M107,300 L307,100 …"/>
</g>
```

- `<pattern>` による塗りは，レンダラーによって継ぎ目が出るので使わない。
- ハッチは最初に描き，境界線・軸をその上に描く。
- ハッチの上にラベルを置くときは白い下地を敷き，`<text data-lint="skip">` とする（lint の線との重なり検査から外れる）。
- 床・壁・天井は，線（1.5）と，その片側に短い斜線（長さ 8px 程度，間隔 6px，太さ 0.7）。

## 印

- **角**：半径 16px 前後の円弧（太さ 1.0）。等しい角は同じ本数（2本目は半径 +3px）。
- **直角**：一辺 8px の小さな正方形。円弧で描かない。
- **等しい長さ**：辺の中点に，辺と垂直な短い線（長さ 10px）。組ごとに1本，2本，3本。
- **平行**：辺の中点に「>」。組ごとに1個，2個。
- **寸法**：下の「寸法線」。

## 寸法線

長さを示す細い両矢印（0.8）と，測る2点から下ろす補助線（0.6），長さの文字。

- **図形から離した段に置く。** 1段目は図形の最も外の線から 16px，以後 20px ごと（`row=0, 1, 2`）。同じ辺に沿う寸法は同じ段にそろえ，区間ごとの寸法を内側，全体の長さを外側の段に置く。分数のラベルがある段は間隔を広げる（`fig.dim_step = 34`）。
- **図形を横切らない。** 光軸上の距離を測るときも，補助線はレンズ・スクリーンの下端から下ろし，寸法線は最も下に出た部分のさらに外に置く（`axis="x"` で水平距離を測る）。
- **区間の長さで扱いを決める**（長さは表示での px）。

  | 区間の長さ | 扱い |
  |---|---|
  | 文字＋矢じり2個＋余白が入る（文字幅＋22px 以上） | 内向きの両矢印，文字は中央（白い下地） |
  | 28px 以上で，上に満たない | 矢じりを外側に置いて内向きにし，文字は入れば間に，入らなければ寸法線の外へ |
  | 28px 未満 | **寸法を付けない。** 縮尺を上げる／その長さを誇張して描き「※ 模式図（実際の長さの比とは異なる）」と注記する／その部分の拡大図を別に描く |

  `dimension` は上の2段を自動で選び，28px 未満には警告を出す。連続する寸法（`dimension_chain`）では，短い区間は隣の区間の矢じりが境界を示すので，矢じりを重ねて描かない。像の高さのように，縮尺どおりだと極端に小さくなる量は，最初から模式図として誇張する。
- 文字は寸法線の中央に白い下地つきで置く。寸法線から離れた所に「高さ $h$」のように書かない。**長さ・高さは引き出し線でなく寸法線で示す。**
- 2本の線（光線と光軸など）がすでに両端を示しているときは補助線を省く（`ext=False`）。

```python
feet = [(xS, -2.0), (xP1, 0), (x2, -1.1), (x1, -2.2)]          # スクリーン・レンズの下端と軸上の点
fig.dimension_chain(feet, ["$d$", "$3d$", "$5d$"], side=-1, axis="x")   # 1段目：区間ごと
fig.dimension(feet[0], feet[-1], "$9d$", side=-1, axis="x", row=1)     # 2段目：全体
fig.leader("P$_1$", (xP1, 0), (xP1 + 0.9, -0.95), dot=True)              # 混み合う所の名前は引き出し線
```

`examples/lens-dimensions.svg` が完成例。

## 白黒で読めること

- 使う色は黒 `#000` と白 `#fff`。物体の塗りに薄い灰色（`#e6e6e6` 前後）を使ってよいが，灰色の濃淡だけで2種類を区別しない。
- **固体・液体・気体を見分けられるようにする。** 気体は白，液体は薄い灰色，固体（可動壁，ピストン，おもり，板）は斜線（`hatch(多角形, spacing=4)`）か輪郭の太い灰色にし，それぞれに短い名前を付ける。可動壁を気体と同じ白で描かない。
- 強調のために1色だけ使う依頼があっても，白黒で印刷して区別できるか（線種やラベルでも区別されているか）を確かめる。
- 背景は白い矩形を最初に置く（透明のままだと，暗い背景の画面で線が見えなくなる）。
