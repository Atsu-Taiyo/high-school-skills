# 高校数学・物理・化学の図を描く

## 作図の種類を決める

| 種類 | 入力 | 何に従うか |
|---|---|---|
| 新規作図 | 条件・式・問題文 | 作図の原則 |
| Mode A（手描きの清書） | 板書・ノート・スケッチ | 筆者の意図を読み取り，作図の原則で描き直す |
| Mode B（清書済みの図の再現） | 印刷図・製図された図・既存の SVG／PNG | 原図。原則は原図が決めていない事項にだけ使う |

画像は写っている図の描き方で判定する（撮影の傾きや汚れでは決めない）。判別できなければ，迷う箇所を示して確認する。Mode A・B の手順の正本は [画像から教材図を作る](references/image-to-svg.md)。

## 作図の原則（新規作図と Mode A）

[作図の原則](references/principles.md) が正本。要点は次のとおり。

- 条件で決まる位置は計算で決め，条件に無い関係を図に持ち込まない。
- 縮尺は意味を保ち，変えたり誇張したりしたら読者に分かるようにする。
- 1つの意味に1つの線種。文字・印は意味のある線や形を隠さず，接しない。
- 掲載したときの大きさで読めるようにする（下限は既定値）。
- 図中には記号と短いラベルだけを置き，説明・凡例・関係式はキャプションに書く。
- 本文と記号・字形・書体をそろえ，1枚に1つの状況・視点を描く。白黒で区別できるようにする。
- 教科書・規格で決まっている描き方（回路記号，場の向きの印，光線の線種など）は「固有の約束」の表に従う。

Mode A では描く前に意図仕様 `<図>.intent.md`（[書式](references/intent-template.md)）を書き，筆者が書いていないものを足さない。

## Mode B の規約

原図の配置・範囲・線種・文字位置と，図題・番号・凡例・ラベルの表記・色を保つ。部品の状態と接続は個別に測って写す。色は平塗りで写して `data-source-colors` に書き，ルートに `data-mode="B"` を付ける。

## 図の番号とキャプション

番号の付け方とキャプションの置き方は high-school-math-answers の SKILL.md「図」が正本。

## 確認

- **普段の図**：最終の掲載幅で描画して見る。決まった関係（接する，通る）や文字の干渉は拡大して局所的に確かめる。Mode B は原図と同じ寸法で並べて比べる。点検項目は [仕上げの点検](references/qa-checklist.md)。
- **数値による忠実度の採点**は，原図への忠実さを数値で示す必要がある Mode B の案件だけに使う。必要な環境と手順は [image-to-svg.md](references/image-to-svg.md)。

## 補助スクリプト（使える環境で）

Python 3 があれば，`scripts/` で作図と検査を速くできる。`S` はこのスキルの scripts ディレクトリ。

```sh
python3 "$S/math_label.py" '<TeX のラベル>' --x <X> --y <Y>      # 数式ラベルの SVG 断片
python3 "$S/lint_svg.py" --strict --display-width=<表示幅> fig.svg  # 体裁の検査
python3 "$S/render_png.py" --renderer chrome fig.svg              # PNG にして目視
```

- 新規作図は `hsfig.py` の `Figure`（標準ライブラリだけで動く）で生成できる。関数の索引と既定値は [SVG の書き方と既定値](references/conventions.md)。
- lint が意図仕様と照合するのは，ルートに `data-mode="A"` があるか `--intent=PATH` を渡したときだけ。ERROR は直し，WARN は描画で確かめて判断する。
- Python が使えない環境では，conventions.md の骨組みで SVG を直接書き，ブラウザで掲載幅に表示して点検項目を目で確かめる。
