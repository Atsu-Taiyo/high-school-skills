# 高校数学・物理・化学の図を描く

## 画像を清書する場合

最初に画像を見て、次のどちらの作図を行うか決める。写真やスキャンでも、判定するのは写っている図の描き方である。

- **Mode A — 手描きの清書**　板書、ノート、スケッチと判断できる場合。線幅の揺れ、重ね書き、罫線などを手掛かりにする。手書きはデフォルメされているので、筆跡をなぞらず、**この図は結局何を伝えたいのか**を先に読み取る。描く前に意図仕様 `<図>.intent.md`（[書式](references/intent-template.md)）を書く。伝えたいこと、対象と関係（式・対称・平行・等長・角・接点・交点を式から確定）、本質の印（斜線・破線・白丸・黒丸・角の印）、図に書く文字、判読できない文字（`[?]`）、立体なら投影。この仕様から、正確な幾何で描く。歪みは直す（揺れた線は直線や式の曲線に、崩れた対称・比率・寸法は復元、立体は一貫した投影）。薄くても意味のある印は仕様に書いて描く。筆者が書いていないラベル・数値・図形は足さず、読めない文字は当て推量で描かない。文字はまず `math_label.py` で組む。納品前に `lint_svg.py --strict` で体裁と、仕様と図の照合（仕様の文字・印が図にあるか、仕様にない文字がないか）を確かめる。
- **Mode B — 清書済みの図の再現**　印刷図、製図された図、すでに整った SVG・PNG の場合。原図の配置、線種、文字位置、開閉・接続を保ち、同じ範囲で重ねて確認する。図題・キャプション・番号・字間・ラベルは原図の表記をそのまま写し、作図標準で置き換えない。標準は、原図が決めていない事項にだけ用いる。

印刷図らしいものは Mode B とする。なお判別できない場合は、判断が分かれる箇所を示して確認する。判定後の作図・照合手順は [画像から教材図を作る](references/image-to-svg.md) を参照する。

色は白黒を基本とする。原図に色があるときは、その色を測って平塗りの色に写し、Mode A・B ともに再現する。暗い地のチョークやインクは白地に暗い線とし、意味のある色の線だけ色を残す。使った原図の色はルートの `data-source-colors` に書く。

### Mode B の修正と再採点

原図の切り出しを固定し、Chrome の原寸・倍率 1 で左上から重ねる。白地合成後に同じ輝度しきい値（通常 200、淡い面で既定値があれば 236 など）で二値化する。両方を細線化して同じ半径（既定 2 px）の円盤で太らせ、積集合の画素数を和集合の画素数で割った `iou_norm` を採点値とする。これで印刷のにじみや線幅の違いを抑えて位置を評価できる。文字を含む素の画素 IoU `iou_raw` と 1 px 許容の `f1_1px` も記録する。

1. `python3 "$S/fidelity_loop.py" --source source.png --svg figure.svg --out-dir iter-0` で初回を採点する。`S` はスキルの scripts ディレクトリ。目標は **iou_norm ≥ 0.90**。
2. 未達なら `feedback.md`、番号付きの `overlay.png`、上位のクロップを開く。橙は不足、赤紫は余分、青緑は一致。**今回は上位1〜2件だけ**、`bbox_svg` が示す位置の線・記号・文字を原図と比べて直す。画素位置から探すときは同ファイルの換算式を使う。文字と重なった領域には現在の文字列、文字の `bbox_svg`、推奨入力と実行コマンドが出る。原図で式と括弧を確かめる。文字枠内の `iou_norm_text` は診断用。局所移動の候補はクロップで確かめ、全体移動や全体の線の引き直しは行わない。
3. 各版の SVG を保存し、新しい `iter-N` に再採点する。後退したら最良 SVG に戻して別の修正を試す。後退した回も数える。**最高値を更新できない採点が2回続いた時点**、または初回後の修正8回で終了する。わずかでも最高値が伸びれば連続回数をゼロに戻す。未達なら「0.90 未達」と明記し、最良版の3指標、終了理由、残差の位置と内容を報告する。

Mode A の手描きにはこのループと 0.90 目標を適用しない。掲載幅での読みやすさ、印や関係が保たれているか、lint の結果で清書を判定する。

## 条件・式から新しく作図する場合

1. 本文で読ませる点・線・量と，掲載幅を決める。
2. [作図標準](references/standard.md) に従い，点や軸に名前を付けて作図する。交点・極値・垂線の足・像の位置は式から求める。図形は等縮尺，力は共通尺度である。縦横の倍率を変えたグラフには，数値目盛りか可視の注記を付ける。
3. Python 標準ライブラリで動く `scripts/hsfig.py` の `Figure` を使う。数学座標は右・上が正である。寸法と文字間隔は画面上の px で指定する。生成の実例は [make_examples.py](examples/make_examples.py) にある。
4. 次のコマンドで検査し，PNG を最終掲載幅で開く。文字・矢じり・接点・線種を確かめ，修正後は再生成する。ERROR は修正し，概算の WARN は該当箇所を目視する。

```sh
# S はこのスキルの scripts ディレクトリ
python3 "$S/lint_svg.py" --display-width=650 fig.svg
python3 "$S/render_png.py" --renderer chrome fig.svg
```

`--display-width` は実際の掲載幅に合わせる。Chrome が使えない場合は `--renderer auto` で代替できる。CairoSVG は混植ラベルの位置がブラウザと異なる場合がある。納品時に確認できたレンダラーと未確定条件を伝える。

## 図中の数式ラベル

数式ラベルは、手で `<text>` を書かず、まずこの道具を使う。新規作図では `fig.label(...)`、既存 SVG の編集と Mode A の清書では `math_label.py` を優先する。本文でも使える短い TeX 記法から text・tspan・path を生成する。MathJax・KaTeX は不要。次のコマンドは SVG 座標の基線に置く断片を標準出力に書く。点名の P は立体、添字の N と物理量は斜体になる。

```sh
python3 "$S/math_label.py" '$p_0+\frac{Mg}{S}$' --x 200 --y 80 --size 16
python3 "$S/math_label.py" '$\mathrm{P}_{2N-1}$' --x 40 --y 50
python3 "$S/math_label.py" '(張力 $T$)' --x 90 --y 70 --anchor middle
python3 "$S/math_label.py" '$V_A=A\{V(z)-V_L\}$' --x 20 --y 90
python3 "$S/math_label.py" '$\vec{F}$' --x 65 --y 30
```

## 図に応じて読む資料

- [数学](references/math-figures.md) にグラフ，領域，角・円，ベクトル，立体の構成例がある。
- [物理](references/physics-figures.md) に力の分解，ばね・滑車，回路，波，光，運動の作図例がある。
- [化学](references/chemistry-figures.md) に構造式・反応式、器具、エネルギー図、結晶、滴定・溶解度曲線、周期表の描き方と部品の使い方がある。構造式の原子名（C、H、O など）は立体の元素記号で組み、数式の斜体にはしない。
- [SVG と文字組み](references/conventions.md) に線種・寸法・引き出し線・分数の指定がある。点名は `"A"`，変数は `"$x$"`，角は `r"$\theta$"`，ベクトルは `r"$\vec{a}$"` とする。ラベルはヘルパーが解釈できる TeX の部分集合で入力し，SVG には text・tspan・線として出力する。本文の KaTeX / MathJax でも通る記法を選ぶ。
- [仕上げの点検](references/qa-checklist.md) に縮尺・文字・解答本文との照合と lint の読み方がある。図題，長い式，凡例はキャプションに置く。本文で使う点名・角・物理量・単位を図と照合する。
